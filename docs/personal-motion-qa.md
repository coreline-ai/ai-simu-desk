# 개인별 기립·착석·경청 v12 · P0 구현 검수

후속: 2026-10-23 [P1~P2 전체 구현·검수](personal-complete-qa.md). 아래는 P0 당시의 범위/수치다.

작성: 2026-10-22 KST. 대상은 [후속 계획](../dev-plan/implement_20261022_165655.md)의 **1~2번/P0**와 비교 웹이다. 3~7번 역할 업무 리듬·개인 음용 레시피·대화 순서/보드 설명 확장은 미착수다.

## 구현 결과

- `personalMotion` 옵션을 켠 선행 화면을 추가했다. 기본값은 꺼짐이며 현재 제품·기존 v11/v10은 기존 순서로 실행된다.
- v12는 기본 자세→자유 보행→생활 의도/개인 전환→최종 시선→좌석/테이블 지지→소품→손가락→가구 접촉 순으로 적용한다. 새 손짓을 접촉 솔버 뒤에 덧붙이지 않는다.
- 창가 variant 2의 팔 변주가 자유 팔 적용 뒤에 합성되어 최종 자세에 남는다. 제어/지지 중인 손에는 적용하지 않는다.
- 보드 접근/복귀가 다른 경로와 같은 `HUMAN_PROFILES`의 속도/주기를 사용한다. 경로가 계산한 골반 높이를 보존해 새 보폭이 다리 도달 범위를 넘지 않게 했다. 기존 v11 비교의 속도/높이 정책은 유지한다.
- 나라부터 실제 소파 왕복의 기립·착석·복귀를 검증한 뒤 5명으로 확장했다. 준비 기울기를 실제 상승보다 앞당기고, 작은 골반 체중 이동과 착석 뒤 정돈을 연결했다. 루트·발 위치·좌석 앵커·고정 관절 길이는 유지한다.
- 기립/제자리 정렬의 짧은 발 정리에서 바닥 아래로 내려가던 공통 공중 발 기울기를 명시적인 평평한 발로 보정했다. 경로의 뒤꿈치/발끝 회전은 유지한다. 바닥이나 발 목표 위치·신발 크기를 이동해 수치를 맞추지 않았다.
- 경청 반응은 상대/행동/대화 라운드가 바뀐 때부터 계산하며 짧게 반응한 뒤 멈춘다. 눈/머리 반응은 기존 최종 시선 제어 안에 합성한다. 컵을 마시거나 메모/문서를 제어할 때 양보한다.
- 착석 발언의 손짓 높이/완급은 기존 테이블/소파 지지 솔버의 안전한 목표 안에서 구분한다. 다른 손의 지지와 컵/펜/문서 소유권은 유지한다.

| 인물 | 전환·경청 |
|---|---|
| 나라 | 차분한 준비, 약한 앞으로 기울임, 한 번의 짧은 응답 |
| 소라 | 가벼운 정돈, 고개 기울임, 조금 열린 설명 손짓 |
| 준 | 절제된 전환, 작은 뒤늦은 끄덕임, 작은 설명 손짓 |
| 민 | 곧게 정돈, 두 번의 작은 확인 반응 |
| 레오 | 여유 있는 정돈, 부드러운 기울임·설명 |

이 값은 기존 스타일과 리그에 맞춘 연출이다. 모션캡처나 임상적으로 정상적인 인간 보행/자세를 재현했다는 뜻이 아니다. 새 외부 에셋·전신 모델·DB/AI·동적 노드를 추가하지 않았다.

## 재현 웹

[5명 착석·경청 비교](http://127.0.0.1:4180/demos/activities/personal/?play=1&demo=team) · [나라 소파 왕복](http://127.0.0.1:4180/demos/activities/personal/?play=1&demo=solo&actor=nara).

`개인별 전환·경청 · v12`와 `기존 동작 · v11`은 같은 GLB를 사용한다. 비교/시연 변경 시 활동을 다시 시작하고 카메라·배속·화질·조명·정지를 보존한다. 5명 회의·선택 동료 소파 왕복·2인 소파 대화, 창가·보드·컵·업무 주기/마치기·활동 정리를 제공한다. 상단 전체 둘러보기에서도 진입할 수 있다.

기기 동작 줄이기에서는 멈추며 x1/x1.5/x2/x3은 시각 시간만 조절한다. 공간 v9를 읽지 못하면 이전 공간으로 복구하고 개인별 비교 불가를 표시한다. 복구한 화면을 v12 검증 성공으로 표시하지 않는다.

## 자동 검증

증거: `product/evidence/personal-motion/`. 현재 사용자 DB·계정은 검수에 사용하지 않았다.

- P0 **19개 통과**(`p0-tests.tap`): 창가 최종 팔, 5명 보드 속도/주기·접촉·복귀, 컵 소유권, 나라 선행과 5명 전환, 실제 발 위치/신발 바닥/관절 길이, 2~5인 경청/손 지지, 단계별 업무 중단, 정지·재생성/해제.
- 장면 왕복 **1개 통과**(`frames.tap`): v12와 기존 v11의 노드/스키마가 같고, 새 상체/골반·손가락 인스턴스가 프레임 캡처/수신 뒤 일치한다. 실제 계정 간 새 v12 송신을 제품에 기본 적용한 검수는 아니다.
- 기존 v11 회귀 **32개 통과**(`v11-regression.tap`): 기존 보행·손·기립 휴식, 컵/회의/보드·중단/복귀, GLB 재로딩/5명×21=105클립을 확인했다.
- 관리 빌드 **5개 통과**(`build-release.tap`): 필수 페이지/무결성·전환·롤백·잠금·캐시 버전을 검사했다.
- 새 v12의 **22활동 묶음 통과**(`activities.json`): 15역할 변주, 개인 컵 5명, 휴식 15변주, 소파/창가 각 5왕복, 커피 5순환, 소파 대화 5쌍, 착석 2/3/4/5인, 서서 5인, 보드 5순서, 방문·문서 인계 5쌍, 세 시나리오, 기본 21상태×5명의 유한 변환을 검사했다. 종료 시 소품·예약 회수를 확인했다.
- 같은 시각의 실제 자세 비교(`comparison.json`): 나라의 기립 준비 0.667초 시점 상체 기울기는 기존 약 9.7도→새 약 15.5도다. 루트/발 위치는 같으며 모든 인물의 고정 관절 길이를 유지한다. 첫 발 정리 프레임의 실제 신발 최저점은 기존 약 -4.8mm→새 약 +1.0mm다. 이 수치는 특정 프레임의 기하 측정이며 모든 접촉/피부 충돌을 증명하지 않는다.

초기 보드 골반 높이와 나라 발/응답 시각 문제의 실패 TAP을 보존했다. 첫 웹 비교에서 준비 동작 차이가 작아 타이밍을 앞당긴 뒤 P0 19개와 활동 22묶음을 재검증했다. 이전 성공/화면은 `history/first-comparison/`에 구분하며 현재 결과로 혼합하지 않는다.

전체 프로젝트/모든 과거 스튜디오 테스트를 새로 전수 실행한 것은 아니다. 22묶음은 인메모리 시뮬레이션이며 실제 장시간 검수라고 주장하지 않는다.

임시 DB를 사용하는 분리 QA 서버 4193의 공개 페이지에서 검증했다(`browser.json`).

- 같은 공간의 v12/v11 기립 근접 비교, 카메라·배속·정지 유지.
- 5명 실제 컵 준비/이동/착석, 나라가 발언한 뒤 경청하는 장면, 업무 도착 시 회의 중단·전원 복귀·컵 반납/예약 정리.
- x1/x1.5/x2/x3, 일시정지·OS 동작 줄이기, 320/390/768/1440px의 단일 canvas와 가로 넘침 없음.
- 빠른 비교 전환에서 이전 장면 해제, 기존 v11/v10 페이지, 공간 v9 로딩 실패 시 솔직한 대체 안내. JS 오류 없음.

PNG 4개와 `browser-inspection.webm`에 실제 검수 화면을 저장했다. 영상은 검수 중의 재생/정지/비교·화면 크기 조절이 포함된 기록이다. 화면만으로 모든 삼각형의 접촉을 보증하지 않는다.

## 에셋·성능·로컬 적용

공간 v9 원본 GLB는 8,768,140바이트, SHA-256 `ff2187450fa2270e572ce0c5a16f532e252007afb973875e03c711427030249e`를 유지한다. 새 GLB나 105클립을 교체하지 않았다. 서버/DB 마이그레이션·인증·Fake AI·게스트 5명 정책은 변경하지 않았다.

1280×900/DPR1·balanced·같은 전체 구도·대기 5초×3회에서 프레임 p95 중앙값은 기존 16.7ms/새 16.8ms였다. 1,097 draw calls/773,350 triangles로 장면 비용은 같다(`performance.json`). 이는 짧은 데스크톱 대기 측정이며 활동 전체/장시간/모바일 성능 보장은 아니다. 실제 관리 빌드/4180 적용은 `delivery.json`에 기록한다. 실물 iPhone XS Max는 기존 결정대로 연결 불가/미완료이며 발열·배터리·모바일 GPU 메모리·실제 장시간 성능은 이번 검증 범위 밖이다.

## 실제 로컬 적용

기존 서버를 정상 종료하고 사용자 DB를 비공개 백업한 뒤 4180에서 검증 빌드를 실행했다. 원래 서버 번들과 GLB 지문이 동일하며 계정/업무 초기화나 새 마이그레이션은 없다. 실제 제품·개인 동작 번들/GLB의 해시를 준비본과 대조하고 PGlite/Fake AI 정상 상태, 공간 v9/활동 v12·5명 프로파일·x1.5 시간 진행·단일 canvas를 확인했다(`delivery.json`, `delivery-live.png`).

앱 브라우저에서 초기 컵 준비가 업무 자리로 표시되던 상태 문구를 수정했다. 최종 패키지에서 3D 동작 소스·서버·에셋의 동일성과 이 표시 보정을 구분해 기록한다(`release-equivalence.json`, `delivery.json`). 기본 제품은 기존 v11이며 새 v12는 선행 비교 화면에서 확인한다. 3~7번 개발은 이번 완료 범위에 포함하지 않는다.
