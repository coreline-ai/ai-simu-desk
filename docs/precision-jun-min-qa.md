## 결과 상태

초기 독립 실행과 확정 소스 재실행을 구분해 아래에 기록한다. 제품 결함이 확인되면 원래 실패 근거를 보존하고, 검사의 접촉 기준이나 고정 길이를 완화해 통과시키지 않는다.

### 선검토에서 확인한 사항

- 준·민의 소파/창가 왕복에서 최대 골반 이동은 30Hz당 약 33.70/32.90mm, 실제 발과 준비된 접지 목표의 오차는 약 `2e-15m` 이하였다. 실제 밑창 최소 높이는 각각 약 0.93/0.81mm로 바닥 위였다. 팔·다리 길이, 기립/착석·회전·복귀와 착석 중 업무 선점이 통과했다.
- 빈손 2인 회의에서 실제 손바닥 최저 정점과 회의 지지면 간격은 준 약 1.50~1.54mm, 민 약 1.50~1.58mm였다. 경청 중 정지 프레임이 각각 130/164, 102/159였고 컵은 책상에 유지됐다.
- 각 3종 업무와 양방향 문서 전달의 기존 목표 접촉/회수는 통과했다. 그러나 실제 표면을 별도로 측정하면서 **민의 대표 필기 동작이 종이/체크박스 밖에서 최대 5mm 뜨는 결함**을 확인했다. `use>1s`, `recipe.phase=act`, 변주 0에서 검사한 38프레임 중 35프레임이 실제 Checklist/Check0~3 삼각형으로부터 3mm보다 멀었다. 기존 `tipError≈0`은 작성 목표와의 일치여서 이 현상을 검출하지 못했다. 수정 전 재현은 [실패 근거](../product/evidence/motion-precision/jun-min/history/min-writing-pre-fix.txt)에 보존한다.
- 준 안경의 실제 얼굴 인스턴스 행렬까지 적용한 측정에서 검지 렌더링 캡슐과 기존 테의 정점 표본 간격은 약 0.010~0.444mm였다. 5단계 전체 표본의 얼굴 삼각형과 손가락 패드 최소 간격은 약 44.20mm, 손목 최소 간격은 약 88.93mm였다. 손목 최대 이동은 30Hz당 약 24.08mm였다. 테 부모/형상·고정 뼈 길이·발 위치와 5단계×10종 우선권, 정지/수동 회수를 통과했다.
- 기존 `personal-glasses.test.mjs`의 얼굴 거리 함수가 최적화된 `InstancedMesh`의 `Jun_Face` 인스턴스 위치/스케일을 적용하지 않는 QA 공백을 수정했다. 실제 세계 좌표 삼각형으로 거리 함수를 바꾼 뒤 기존 안경 검사 5/5가 통과했다. [실행 로그](../product/evidence/motion-precision/jun-min/glasses-instance-aware.tap). 제품의 얼굴 관통 결함은 재현되지 않았다.

초기 검사 도구 보정: 양손 지지가 완전히 안정화되기 전 `blend=0.99898`에서 약 0.036mm의 정상 보간 오차를 완전 접촉 기준 0.01mm와 비교했다. 안정화 접촉 측정을 `blend=1` 구간으로 명확히 나누고 진입 구간과 혼동하지 않도록 수정했다. 완전 지지 구간의 오차는 약 `1.5e-17m`, 실제 손잡이와 5개 패드의 최대 간격은 약 1.66mm였다. 초기 결과는 `history/initial-check-assumptions.json`에 보존한다.

### 첫 고정 소스 병렬 재검수

루트의 `qa:motion:precision` 병렬 실행 중 준·민 CLI는 2026-10-23 13:42:29~13:46:41 KST에 **8/8 통과**, 관찰한 소스 지문 변경 없음으로 완료했다. [측정 JSON](../product/evidence/motion-precision/jun-min/in-memory.json), [병렬 실행 로그](../product/evidence/motion-precision/integration/parallel.log).

- 민 필기 수정 뒤, 대표 작성 38프레임의 실제 종이/체크박스 간격이 전부 약 **0.4mm**로 줄었고 3mm 초과는 0이었다. 일부 변주의 의도적 펜 들기는 접촉으로 계산하지 않는다.
- 준·민의 양손 음용, 실제 손잡이 5패드, 새 운반 왕복·각 업무 중단, 3종 역할·양방향 문서·안경 실제 메시와 50종 선점 검사를 통과했다. 이 통과는 아래 추가 바닥/러그 경계 문제를 해결했다는 뜻이 아니다.

### 추가 실제 바닥·러그 탐침과 검사 가정 보정

초기 경로 검사의 `sole.y >= 0` 조건은 기본 바닥 관통만 검사했다. 실제 바닥·러그를 아래로 raycast한 별도 [접지 탐침](../product/evidence/motion-precision/jun-min/planted-ground-probe.json) 이후, 정점 중 절대 높이가 가장 낮은 표본만 접촉으로 보는 방식이 다른 정점의 정상 러그 지지를 놓칠 수 있음을 확인했다.

- 이 초기 탐침에서 준 +21mm/민 -19mm라는 경계값을 관측했다. 최종 판정에는 아래의 실제 자산별 지지면과 전체 정점 기준을 사용한다.
- 최종 독립 경로 검사는 v9 확장 사무실의 `RoomFloor`/`WovenRug`/`MeetingWovenRug`를 필수로 포함한다. 예전 공간의 `WorkWoolRug`가 실제 존재하는 자산에서는 이 메시도 포함한다. v9에는 없는 메시를 필수로 요구했던 초기 검사 가정은 보정했다. 실제 사용 목록은 결과의 `groundMeshes`에 기록한다.
- planted 밑창 **모든 정점의 signed gap 최소값**이 -0.1~3mm인지 판정한다. 정상 지지를 올바르게 판정하는 보정이며 허용치는 유지한다.
- 루트가 확인한 나라의 실제 러그 관통 결함은 제품 접지 보정 대상이며, 준·민도 같은 최종 소스와 보정된 4메시 검사를 재실행한다.

첫 8개 통과를 전체 최종 합격으로 확대하지 않고, 제품 접지 보정과 실제 지지면 판정 보강 이후 아래의 최종 재검수를 수행했다.

관찰한 이미지에는 명백한 팔 반전이나 상체의 큰 단절이 보이지 않았다. 가려진 동작·미세 접촉의 수치 통과를 이미지 검수 완료로 바꾸거나, 반대로 가림 자체를 캐릭터 관절 결함으로 분류하지 않는다.

초기 넓은 구도에서는 민의 걷기/업무가 전경 화이트보드에 가려 시각적 연속성을 판정할 수 없었다. 카메라의 focus/frustum과 관찰 각도만 보정해 재촬영했으며, 가구/제품 동작은 이 목적 때문에 변경하지 않았다. 이전 원본·영상은 [초기 구도 근거](../product/evidence/motion-precision/continuity/history-wide-camera/continuity.json)에 보존한다. 최종 근접 16장 모두 실제로 열어 검토했지만, 드문 x1 표본이므로 전체 프레임 비관통이나 미세 접촉 증명으로 해석하지 않는다.

## 검증 한계

- 손가락 패드·안경 테/얼굴/손잡이의 실제 삼각형 거리와 고정 뼈 길이를 검사한다. 표면 거리에는 부호가 없으며 렌더링되는 검지 메시의 정점 표본은 모든 피부 폴리곤의 비관통·물리 접촉 증명이 아니다.
- 민의 공중 펜 이동은 종이 접촉으로 표시하지 않는다. 연필 끝의 표면 거리는 접근/전환과 실제 필기/들기를 구분해 기록한다.
- 이 실행은 생성된 인메모리 모델을 사용한다. 실제 exported GLB의 텍스처 디코딩·카메라 근접 이미지·시각적 자연스러움은 루트의 브라우저 검수 근거와 함께 판단한다.
- 실물 모바일 터치·발열·배터리·OS 숨김이나 장시간 GPU/heap 검수 완료를 주장하지 않는다.
