# 나라 소파 활동 · Phase 1~2 로컬 검수

기준: main `96969b7`의 v6. [실행 계획](../dev-plan/implement_20261020_154155.md)의 목적지 이동·좌석 예약과 나라 소파 착석·휴식·업무 복귀를 구현했다. 컵·회의·5명 목적지 활동은 후속 Phase로 남긴다. 제품 `/`의 기본 v6는 유지하고 `/demos/activities/`에 비교 샘플을 제공한다.

## 구현과 경계

- 기존 v6 GLB를 그대로 로드하고 후보 화면의 모델 복사본에만 활동을 적용한다. 원본 SHA-256 `7d6addce4b58447bdc8d45c4c725fefb26df4986a96759e14c75cb1bb7dd1aab` 유지. 모델/환경 6, 기존 105개 클립과 skin 계약을 유지하며 새 활동은 `activityVersion: 1`의 절차적 런타임이다. 새 GLB 클립을 내보냈다고 주장하지 않는다.
- 책상→왼쪽 우회→소파 접근점 경로를 사용한다. 모델 좌표와 나라 StationAnchor 좌표를 변환하고 발은 같은 부모 좌표에서 접지한다. 공유 통로와 소파 왼쪽 1석을 원자적으로 예약한다. 다른 인물이 선점하면 6초 확인 후 책상에서 대기한다.
- 이번 1명 샘플은 다른 네 명의 자리 생활 동작을 유지하고 자동 보행을 억제한다. 다인 목적지/통로 공정성은 Phase 5 대상이며, 다섯 명 동시 목적지 이동을 구현했다고 표시하지 않는다.
- 후보 소파의 좌면/본체/등받이/팔걸이를 7.5cm 낮추고 다리 접지 위치는 유지했다. 왼쪽 쿠션을 오른쪽으로 정리해 사용 좌석을 확보했다. 실제 좌면 메시/인스턴스의 월드 bounds에서 좌면 높이를 읽어 골반을 맞춘다. 원본 v6 소파의 형상/장식 배치는 비교 전환으로 확인한다.
- 접근→디딤 회전→뒤로 디디기→앉기→10초 휴식→일어서기→복귀→책상 착석으로 연결한다. 두 발의 바닥 위치를 유지하며 앉고 일어난다. 휴식은 상체의 작은 이완/호흡·시선이며 등받이에 깊게 기대는 별도 변주는 아직 없다.
- 업무 도착 시 실제 업무 진행을 기다리게 하지 않는 시각 정책을 사용한다. 이동 중에는 발을 안전하게 모은 뒤 되돌아가며, 앉는 중에는 지지 가능한 착석 자세까지 마친 후 일어난다. 복귀 후 타이핑 자세를 적용한다. 샘플 업무 버튼은 서버 업무를 생성하지 않는다.
- 일시정지/문서 숨김에서는 렌더 시계가 멈추고 점유를 유지한다. 화면 폐기·재로드에서는 예약을 해제한다. 공유 통로 하나를 휴식 동안에도 보유하는 보수적 정책이며, 구간별 동시 이용은 다음 확장 대상이다.

## 자동 검사

기존 147개와 신규 11개, 총 **158개 통과**. 타입 검사, 관련 47개 모듈 구문 검사, 의존 경계 검사, 제품 클라이언트/서버 빌드 통과.

신규 검사는 다음을 확인한다.

- 예약의 전체 성공/전체 실패, 해제·dispose와 재획득.
- 실제 v6 가구/후퇴 의자/램프 bounds에 대해 0.025초 간격 경로 샘플링. 몸 반경 0.22m에 0.005m 여유를 더해 검사한다. 관절 도달 범위와 루트 위치의 연속성도 확인한다.
- 보행의 발이 공중에 있는 도중 업무가 도착한 경우 발 위치 연속성·안전한 디딤 후 역방향 복귀.
- 큰 dt 제한·코너·역방향 복귀·좌면의 실측 높이·반복 준비 시 중복 anchor/누적 높이 변경 방지.
- 전체 소파 왕복과 queued/stand/out/align/back/sit/rest/rise/forward/home/deskTurn/deskSit 각 단계의 업무 중단·책상 복귀·타이핑 재개.
- 좌석 잠금 실패·정지/재개·정지 중 업무 도착·예약 정리.
- **20회 왕복은 시뮬레이션 검사**다. 각 휴식에서 정지/재개하고 예약·완료 횟수의 일치를 확인했다. 실제 20회 분량의 벽시계를 실행했다고 표현하지 않는다.
- 렌더에 사용하는 실제 메시 bounds로 골반 하단과 좌면 차이 2mm 이내, 두 신발 밑창과 지지면(소파 러그 상면)의 높이 차이 0~4mm 범위를 검사했다. 근접 자세 캡처와 함께 판정하며 모든 옷/몸 메시 쌍의 완전한 충돌 증명은 아니다.

## 실제 웹 검수

`product/evidence/activities/`에 착석 근접/전체 화면과 진단 값을 보관한다. 낮·저녁과 측면에서 좌면/무릎/발을 확인하고, 실제 휴식 중 업무 입력 후 복귀·타이핑/점유 반환을 확인한다. 접촉 검수용 ‘착석 완료 시 일시정지’는 실제 시계가 휴식에 진입했을 때 멈추며 시간을 가속하지 않는다.

추가 브라우저 확인: 320/390/768/1440px에서 가로 넘침 0, canvas 1개, 주요 동작 버튼 높이 44px를 확인했다(`responsive.json`, `mobile-390.png`). 낮·저녁 근접 착석과 전체 장면을 캡처했다. 정지한 동작 시계 86.9592초는 12회 화질/4회 조명 전환과 실제 WebGL loss/restore 후 동일했고, 복구 후 ready/canvas 1·좌석 예약을 유지했다(`recovery.json`). 좌석 선점 상황에서 6초 후 안전 대기·방문자 점유 보존과 브라우저 JS 오류 0을 확인했다(`occupied-seat.json`). 원본 v6 전환도 실제 로딩 완료를 확인했다(`baseline-v6.png`). 이는 Phase 6 전체 성능/장시간 검수를 대신하지 않는다.

실기기 모바일·터치/발열·실제 OS 동작 줄이기·앱 백그라운드는 미검증이다. Phase 6의 10분 연속/30분 혼합·동일 조건 30초×3 성능 검사는 이번 1~2단계에서 새로 완료했다고 주장하지 않는다. 기존 v6의 장시간 통과 기록을 새 활동의 검증으로 대신하지 않는다.

## 발견과 보정

- 러그 두께를 실제 메시 bounds에서 읽어 발 지지면에 반영했다. 바닥 y=0만 사용해 밑창이 러그 안으로 들어가는 것을 보정했다.
- 처음 좌면 기준의 골반 높이가 약 1.5cm 높아 보이는 문제를 실제 골반 메시 하단으로 보정했다.
- 이동 중 업무가 오면 즉시 보행 방향을 바꾸는 대신 0.35초 디딤 정리를 거쳐 복귀 경로로 전환한다.
- 검수용 재로드에서 소파가 반복해서 낮아지거나 anchor가 쌓이지 않게 준비를 멱등적으로 처리했다.
- 초기 광범위 경로 탐색 대신 검증한 우회 경로를 사용하며, 불가능한 점유는 기다린 후 안전하게 취소한다.
