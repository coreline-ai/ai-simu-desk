- Blender가 설치되어 있지 않아 **승인된 코드 기반 재작성 대안**을 구현했다. Blender 제작 손 에셋이나 모델 재학습으로 표현하지 않는다.
- 타이핑 프레임: 손바닥 -Z, 손등 +Z, 손가락 -Y. 키보드 프레임에서는 손등이 위, 손바닥이 키 쪽으로 향한다.
- 네 손가락은 각각 다른 마디 길이와 너클 위치를 쓴다. 엄지는 CMC에서 시작하는 중수골 길이를 별도로 포함했다.
- 일반 손을 97% 직선 길이에서 보간하지 않는다. 편한 손/키보드 대기/키 누름/삼점 필기/마우스 자세/종이 집기를 분리했다. 손바닥·엄지 확인 포즈도 추가했다.
- 기존 팔 책상 회피의 후처리가 키보드 목표를 다시 움직이지 않도록 검수 손 제어 우선권을 예약한다. 후처리 이후 실제 pad world transform으로 검사한다.

## 구현 경계

- 실제 접촉 연결: 소라의 3가지 기존 필기 변형, 검수 모드의 키 누름. 펜은 엄지/검지/중지 세 패드만 접촉하며 약지/소지는 보조로 접힌다.
- 마우스/종이 옵션은 **빈손 정지 형태 확인용**이다. 실제 소라 마우스 작업이나 종이 전달을 새 리그로 구현했다고 주장하지 않는다.
- 컵·전달·공동 활동 소유권은 기존 v13 그립으로 명시적 복귀한다(`legacy-owned-contact`). 새 리그를 전 활동에 적용한 상태가 아니다.
- 실제 피부 전체 연속 충돌 솔버가 아니다. 캡슐 프록시와 실제 도구 목표를 검증하며, 작은 피부 압축/교차나 애니메이터 수준 품질까지 보장하지 않는다.

## 이전 실패를 반영한 검증

1. 콜백 직후 오차만 검사하지 않는다. 실제 후처리 완료된 손끝 위치를 키캡 목표와 비교한다. 초기 자유 팔 후처리로 최대 81mm 이동하던 문제를 수정했다.
2. 세 패드 접촉만 맞추지 않는다. 초기 검지/중지 프록시 겹침 5.8mm를 확인해 엄지 중수골 길이, 펜 둘레 3면 배치, 마디 각도 제한과 겹침 패널티를 함께 보정했다.
3. 현재 실제 스타일러스 캘리브레이션의 최대 패드 중심 목표 오차 약0.16mm, 최대 원위 마디 캡슐 프록시 겹침 약0.89mm. 이는 전체 피부 충돌 보장을 뜻하지 않는다.
4. 공유 프레임에 관절과 손톱 인스턴스 행렬을 모두 포함한다. v14와 v13은 다른 스키마이며 혼용을 명시적으로 거절한다.
