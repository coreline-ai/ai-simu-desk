# 다섯 동료의 컵·회의·소파 활동 · 로컬 QA

기준: main `b6be870`. [생활 동작 계획](../dev-plan/implement_20261020_154155.md)의 Phase 3→4→5를 구현했다. Phase 6의 실제 10분/30분·성능·제품/복구 회귀까지 완료했다. 변경 범위는 로컬이며 외부 서비스·DB는 연결하지 않는다.

## 구현 결과와 범위

- 기존 v6 GLB와 105개 클립을 유지한다. 새 상호작용은 `teamActivities.version: 2` 절차적 런타임이다. `/demos/activities/`는 나라 1명 선행 샘플, `/demos/activities/team/`은 원본 v6와 5명 보강 화면을 전환하는 비교 페이지다.
- 기존 인물별 컵 1개를 재사용한다. 손이 닿는 책상 앞쪽 위치, 왼손의 잡는 형상, 제한된 두 관절 팔 보정을 추가했다. 뻗기→잡기→들기→한 모금→내리기→놓기→손 떼기를 연결한다. 액체 물리·개별 손가락 리깅은 범위에서 제외했다.
- 컵 소유자는 desk/hand/meeting 중 하나다. 접촉 시점에만 부모를 바꾸며 월드 변환을 보존한다. 회의 탁자에 놓은 컵을 다시 집어 들고 책상으로 돌아와 놓는다. 업무 도착 시에도 소품을 순간 이동시키거나 현장에 영구 방치하지 않으며 서버 업무는 연출을 기다리지 않는다.
- 나라·준부터 2인 회의를 검증했다. 5명 중 유휴 동료 둘이 독립된 접근 경로와 낮은 스툴 2개를 이용한다. 컵을 가져와 탁자에 놓고 시선·설명 손짓·끄덕임을 교대한다. 참가자에게 업무가 오면 회의를 정리하고 각자 컵을 회수·복귀한다. 도착 대기 제한은 180초다.
- 소파 2자리를 사용할 수 있도록 쿠션·스로우를 양쪽 팔걸이로 옮겼다. 휴식 중에는 좌석만 점유하고 통로를 반환한다. 복귀 시 통로를 다시 요청한다. 휴식은 20~26초로 분산하며 2명이 함께 쉬는 시간이 2초 이상인 것을 검사했다.
- 공유 통로 1인, 소파 2인, 회의 2인을 넘지 않는다. 원자적 획득·실행 가능한 요청 간 순서·복귀 우선권을 사용한다. 다른 사람의 의자·식물을 포함한 고정 경유점 검수이며 범용 자유 경로 탐색은 아니다.
- 완료 횟수가 적은 활동부터 선택하고 회의를 원하는 두 사람을 짝지어 특정 인물이 계속 누락되지 않게 했다. 중단된 시도는 실제 활동 완료와 구분한다. 상체·시선·손 모으기·발언/경청도 분산한다. 5명 전원 동시 착석 회의는 현재 작은 회의 구역의 범위에서 제외했다.
- 제품 `/`에 실제 업무 상태를 읽는 보강 런타임을 연결했다. 생활 동작은 클라이언트 연출이며 사용자 사이의 프레임 동기화는 제공하지 않는다. 로그인·DB·Fake AI·승인/결과/인계 순서는 기존대로 동작한다.
- 활동 바인딩 실패는 원본 v6 기본 런타임으로, 모델 자체 실패는 기존 v5→v4로 복구한다. 렌더러·모델·활동을 함께 해제/재생성한다.

## 자동 검사

최종 전체 **169개 통과**(기존 158개 + 컵/목적지/팀 신규 11개). 타입 검사, 관련 54개 모듈 구문 검사, 의존 경계 및 제품 빌드도 통과했다.

검사 범위는 단일 컵 소유권·손 도달 오차·각 구간 업무 중단·임계 이벤트 중복 방지, 5명×소파/회의 2자리 경로, 예약 대기·복귀 우선·해제, 2인 회의 전체 왕복·컵 회수, 5명 시연 정원·신체 거리, 인물별 컵/소파, 정지 중 업무 도착, 자율 활동의 편중/중단 재시도다. 속도 변경 시 구간 시작 시각이 끊김 없이 이어지는 회귀 검사도 추가했다.

600초와 1,800초 분량의 **빠른 시뮬레이션**은 각각 통과했다(`simulated-coverage-continuous.json`, `simulated-coverage-mixed.json`). 후자는 5명 모두 소파·컵·회의·업무·완료 동작, 신체 위치 겹침 0을 확인한다. 이것을 실제 10분/30분 검사로 계산하지 않는다.

## 성능 비교 결과

각 회차 2,250프레임, 실제 30,000~30,005ms를 측정했다.

| 화면 | p50 | p95 3회 | 관측 호출 수 | 관측 삼각형 수 |
|---|---|---|---|---|
| 원본 v6 | 13.3ms | 14.1 / 14.3 / 14.5ms | 998 | 804,344 |
| 생활 동작 보강 | 13.3ms | 14.4 / 14.2 / 14.5ms | 1,000~1,006 | 803,000~805,240 |

p50≤20ms/p95≤33.3ms를 통과했다. 최대 관측 호출은 +0.80%, 삼각형은 +0.11%로 각각 +10% 관리선 이내다. 호출/삼각형은 움직이는 장면의 관측 스냅샷이며 모든 프레임의 절대 최댓값으로 표현하지 않는다. 프레임 값은 브라우저 애니메이션 프레임 간격으로 GPU 시간/다른 기기의 FPS를 뜻하지 않는다.

## 용량과 성능의 해석

원본 v6 GLB는 7,749,228 bytes, SHA-256 `7d6addce4b58447bdc8d45c4c725fefb26df4986a96759e14c75cb1bb7dd1aab`로 유지한다. GLB+제품 JS+대체 이미지의 필수 전송량은 약 10.29MiB로 15MiB 이내다(`initial-assets.json`). 새 손 형상과 스툴은 런타임 기하이며 추가 텍스처를 로드하지 않는다.

기존 26개 PNG의 RGBA+밉맵 추정은 약 15.04MiB로 동일하다. 환경 render target·shadow map·bone texture·기하·canvas 비용은 별도다. renderer.info의 자원 개수·프레임 간격은 GPU 시간/실제 GPU 메모리·JS heap 실측과 구분한다.

## 발견과 보정

- 컵의 기존 위치가 팔 도달 범위 밖이어서 책상 앞쪽으로 옮기고, 잡는 손·손잡이 방향·입 근처 목표를 함께 보정했다.
- 활동 종료 프레임에 대기 자세가 남던 문제는 실제 VM 상태를 다시 적용해 보정했다.
- 좌석 대기자가 통로/복귀를 막지 않도록 가능한 요청 선택과 복귀 우선권을 추가했다.
- 빠른 보행의 구간 길이와 다음 구간 시작 시각에 서로 다른 속도가 쓰이던 코너 정체를 수정하고, 연속 시간 검사를 추가했다.
- 회의의 컵 준비/정리가 내부 idle 상태로 표시되던 부분은 표시용 단계에 pickup/putback을 우선해 수정했다. 이동·소품 소유권·업무 동작에는 영향을 주지 않는다.
- 단순 순번이나 임의의 회의 상대 선택으로 일부 인물의 활동이 편중되는 경우를, 완료 횟수 기반 선택·회의 희망자 짝짓기·중단 재시도로 수정했다.

## 별도 미검증

실물 모바일 DPR 2·터치/발열, 실제 OS 동작 줄이기 변경·앱 백그라운드 복귀, 실제 GPU/JS heap 메모리는 미검증이다. 뷰포트·자원 개수·코드/정지 회귀 검사만으로 실물 환경 통과나 누수 없음을 주장하지 않는다. 기존 서버 다중 사용자 검사는 이번 생활 동작의 사용자 간 시각 동기화를 의미하지 않는다.

## 재현 방법

```sh
npm test
npm run typecheck
npm run check:product
npm run check:boundaries
npm run build:product
node scripts/activities-simulation.mjs continuous
node scripts/activities-simulation.mjs mixed
```

로컬 서버의 `/demos/activities/team/`에서 ‘5명 생활 시연’을 실행한다. 근접 검수는 ‘성능·중단·장시간 검수’의 자동 정지 구간을 선택한다. ‘10분 연속 검사’와 ‘30분 혼합 검사’는 실제 시간이 끝날 때 결과 JSON을 표시하며 중간 정지·재로딩·숨김이 있으면 통과하지 않는다. 실제 제품 `/`의 ‘생활 동작 보기’와 ‘5명 협업 시연 시작’은 각각 생활 연출과 서버 업무 실행이다.
