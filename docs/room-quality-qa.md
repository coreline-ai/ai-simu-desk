# 사무실 공간 품질 v6 · 로컬 검수

기준: main `e8ea38b`의 v5. [실행 계획](../dev-plan/implement_20261020_141148.md)의 순서대로 로컬 구현·검증을 완료했다. 외부 서비스·DB·유료 도구를 추가하지 않는다. 후속 사용자 요청에 따라 구현·에셋·검증 기록을 main 커밋·푸시 대상으로 확정했다.

## Phase 1 — 창가·소파·나라 자리

기존 105개 클립/다섯 관절 구조·고정 통로를 그대로 사용한다. 창 방향 directional key 하나와 fill/hemisphere, 로컬 RoomEnvironment 기반 반사를 사용한다. 그림자 광원은 한 개다. 노출과 카메라·DPR·shadow resolution은 v5와 동일 조건으로 비교한다. ‘동일 광원으로 재질 비교’에서는 후보에도 원래 v5 광원을 적용한다.

고정 책상 다리·소파 다리·책장·회의 테이블 접촉만 512² AO에 포함한다. 움직이는 캐릭터/의자는 포함하지 않는다. floor의 별도 UV1을 월드 좌표에 맞추고 clamp sampling을 사용한다. 이는 실시간 전역 조명이나 범용 ray-traced AO가 아니다.

발견/수정: RoundedBox 부동소수점 좌표 때문에 정규화한 UV가 극소량 0~1을 벗어나는 경우를 clamp했다. 해당 검사를 포함한 Phase 1 검사 3개 통과.

실제 화면: `product/evidence/room-quality/phase1-window-v5.png`, `phase1-window-v6.png`.

## 진행 정책

공통 재질·공간 구획·창밖/시간대·책상/카메라/상태를 순차 구현했다. 10분 연속·30분 혼합 동작과 로컬 통합 검수를 완료했다. 물리 모바일/OS 환경 미실행 항목을 실제 검증처럼 표시하지 않는다.

## Phase 2 — 재질별 표면

목재/돌 512², 천/린넨/벽 도장 256²의 색·normal·ORM 맵을 로컬 생성했다. ORM은 R=1, G=roughness, B=0이며, 색 맵만 sRGB로 로드한다. 목재 UV를 긴 축에 맞추어 다리/책장 측판의 결이 가로로 감기던 표현을 보정했다. 캐릭터 재질과 105개 동작은 유지했다.

5개 자체 검사와 실제 PNG 디코딩·렌더 통과. 20회 화질/조명 전환에서 textures 43/geometries 158, 정지 시계 유지. GLB 약 7.05MiB. 증거 `phase2-surfaces.png`, `phase2-quality-switches.json`.

## Phase 3 — 공간 구획과 마감

기존 방 안에 통로를 피하는 작업 러그와 회의 러그를 배치하고, 소파 러그를 분리했다. 쿠션/접힌 스로우, 두 벽 아트, 독서등, 책장 스택/도자기, 의자 봉제 마감을 추가했다. 러그에는 같은 정적 접촉 AO 좌표를 연결했다. 카펫 표면은 바닥에서 1cm 이내이며 움직이는 발을 굽지 않는다.

다섯 자리 통로를 신규 램프 AABB와 함께 0.025초 간격으로 검사했다. 6개 검사와 실제 전체 화면 검수 통과. 기하 약 412,030개, 기존 대비 약 1.4% 증가. 증거 `phase3-zones.png`.

## Phase 4 — 창밖/시간대

하늘 그라데이션·원경 언덕·중경 수목·근경 관목을 구성했다. 창 영역 stencil 마스크로 카메라 비스듬한 시점에서도 외부 풍경이 끊기거나 방 밖으로 튀어나오지 않게 한다. 로컬 renderer는 후보에 stencil buffer를 사용한다. 유리는 절제된 환경 반사이며 실제 거울 반사/실시간 ray tracing은 아니다.

저녁에는 하늘/수목/외부 지면 색과 독서등 발광 및 무그림자 점광원 하나를 함께 변경한다. 그림자 광원은 여전히 하나다. ‘동일 광원’ 비교는 후보의 환경 반사/추가 점광원 없이 v5 광원을 사용한다.

보정: 외부 지면/배경의 parallax 빈 부분, 인스턴싱으로 손실되던 noShadow/vertexColors/time metadata를 수정했다. v5 기본 optimizer 동작은 유지하고 후보만 metadata 보존 옵션을 사용한다. 하늘 color BufferAttribute를 매번 재할당하지 않고 재사용한다. 7개 검사·실제 낮/저녁 검수. `phase4-day.png`, `phase4-evening.png`, `phase4-time-switches.json`.

## Phase 5 — 역할별 표현·가림

5종 역할 그래픽을 256×160 PNG로 생성해 노트북/해당 보조 기기에 공유했다. 실제 답변/사용자 정보는 텍스처에 넣지 않는다. 현재 활동의 발광/작은 LED만 바꾸며 진행률을 추정해 표시하지 않는다. 복귀 중 업무는 사용자 보조 문구로 구분한다. 동작 정지 중에는 서버 상태를 추정하는 진행 문구 대신 ‘동작 정지 · 자리 복귀 대기’를 표시한다.

카메라가 왼쪽/뒤 벽 밖으로 가면 해당 벽·창·벽 장식을 cutaway로 숨긴다. 복귀하면 원상 복원한다. 단순 모델 검수 연출이며 건물 물리 시뮬레이션은 아니다. 좁은 화면 이름표는 선택한 동료를 우선하고 겹침을 피한다. 자체 검사 9개, 실제 rear 시점 left/back 확인. `phase5-room.png`, `phase5-cutaway.png`.

### 같은 조건의 성능

macOS 내장 브라우저, 1280×720 viewport, 1149×608 canvas, DPR 1, 자동→균형/1024 shadow, 동일 camera/노출 1.03, 낮. v5는 원래 광원, v6는 개선 광원/환경 반사를 포함한 전체 결과이며 ‘동일 광원’ 재질 비교도 별도로 제공한다. 다른 장면은 정지하고 30초×3회 측정했다. 장시간 시험은 이후 별도 두 세션에서 실행하므로 그 중의 프레임 수를 아래 성능으로 대체하지 않는다.

| 장면 | 1회 p50/p95 | 2회 | 3회 | 그림자 포함 호출/삼각형 |
|---|---|---|---|---|
| v5 | 13.30/13.70ms | 13.30/14.00ms | 13.30/13.60ms | 935 / 810,548 |
| v6 | 13.30/13.70ms | 13.30/13.50ms | 13.30/13.40ms | 998 / 804,344 |

데스크톱 목표 p50≤20/p95≤33.3ms 통과. 호출 약 6.7% 증가(관리선 10% 이내), 그림자 포함 삼각형 감소. 브라우저 약 75Hz 공급 한계 안의 프레임 간격이며 GPU 시간이 동등하다는 뜻은 아니다. `performance-v5.json`, `performance-v6.json` 원본 기록.

후보 GLB 7,749,228 bytes(약 7.39MiB), 내부 26개 PNG의 RGBA+밉맵 추정 15,772,348 bytes(약 15.04MiB), 이 중 기존 5종 맵 제외 추가분 약 13.38MiB(제안 상한 16MiB 이내). 첫 필수 자산은 GLB+앱 JS+대체 이미지 합계 약 10.25MiB로 15MiB 이내다. PMREM 환경 render target·shadow map·bone texture·geometry/skin·canvas 비용은 별도이며 GPU 실측 메모리로 표현하지 않는다.

### 남은 검증과 범위

물리 모바일·DPR 2 실기기·터치/장시간 발열·OS 설정/앱 백그라운드 절전은 미검증이다. 8폭 뷰포트 검사나 설정 입력에 대한 자동 검사를 해당 실기기 통과로 표현하지 않는다. 새 범용 경로 찾기·소파 착석/컵 잡기/회의 동작·천/모발 물리·개별 손가락 리깅은 포함하지 않는다.
