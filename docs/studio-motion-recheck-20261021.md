# 스튜디오 동작 재검토와 남은 항목

2026-10-21 기준 main `cd7aca4`의 데스크톱 로컬 검토 결과다. 보행·착석·소품·인계·업무 복귀 회귀 **145개가 통과**했다. 11개 데모 화면과 제품 스튜디오를 확인한 범위에서 새로운 공간 이탈·몸 겹침·복귀 불능은 재현되지 않았다. 방문 상대의 이동 상태 표시, 필기 손의 약지 접촉, 소파 대화의 대칭적인 팔 자세는 후속 보완 대상으로 남는다.

## 확인된 보완 항목

### 방문을 받는 동료의 이동 표시

**P2 표시 오류.** 나라가 준의 자리로 걸어갈 때 준은 자기 자리에 앉아 있지만 비교 화면에는 두 사람 모두 `동료 자리 · 이동`으로 표시된다. 결정적 재현에서 준의 세계 위치 변화는 0mm, 실제 action은 `idle`인데 진단의 stage는 `out`이었다.

`pilot-3d/activities/interaction-scheduler.mjs:80`이 방문자와 호스트 모두에게 방문자의 trip stage를 넣고, 비교 화면이 이를 이동 문구로 표시한다. 방문자/호스트 역할과 실제 이동·자리 대기를 구분하는 표시 데이터가 필요하다. 인계·회수 중에도 상대의 이동 단계를 복사하지 않게 해야 한다. 캐릭터가 실제로 두 명 모두 걸어가는 오류는 재현되지 않았다.

완료 기준은 20개 방향 방문의 출발/대기/도착/문서 회수/복귀마다 호스트의 실제 자세와 문구가 일치하고, 기존 방문 예약·업무 우선권이 유지되는 것이다.

### 필기 손의 약지 접촉과 검사 범위

**P2 근접 품질 및 검수 보강.** 5명×역할 3종·컵의 20개 경우, 소품을 잡은 4,320개 표본에서 손가락 5개의 목표점 거리를 추가 측정했다. 나라·민의 필기 약지는 최대 **5.80mm**, 소라의 스타일러스 약지는 **4.08mm** 떨어졌다. 엄지·검지·중지와 컵의 기존 목표점 검사는 통과했다.

`pilot-3d/activities/hand-grips.mjs:56`의 `padError`는 앞 3개 손가락만 합산한다. 약지의 목표점이 고정된 두 마디의 도달 길이를 넘는 경우가 기존 3mm 검사에 포함되지 않는다. 손가락 길이를 늘리는 대신 손바닥·손목 각도와 약지의 자연스러운 받침 목표를 함께 보정하고, 손가락별 거리를 진단해야 한다.

위 수치는 **손 로컬 좌표의 관절 목표점 거리**다. 피부 메시의 관통량이나 실제 물리적인 잡는 힘을 뜻하지 않는다. 완료 기준은 앞 3개 손가락의 필수 접촉과 약지·소지의 역할을 따로 정하고, 도달 가능한 목표·관절 제한·근접 화면·펜 끝 접촉·기존 소유권을 함께 검사하는 것이다.

### 소파 대화의 팔 대기 자세

**P3 시각 품질 제안.** 두 사람이 소파에서 대화를 시작하는 근접 화면에서 양팔을 비슷한 높이로 모아 든 자세가 대칭적으로 보인다. 이는 예약/착석 실패와 구분한다. `pilot-3d/activities/team-runtime.mjs`의 `sofaPair` 팔 목표가 양손에 같은 높이를 기본으로 사용하는 점과 일치한다.

듣는 사람은 한 손을 무릎·팔걸이에 두고, 말하는 사람은 한쪽 손만 사용하도록 인물별 지지 자세를 추가하면 더 편안해 보인다. 동작 전환 때 손이 좌면·팔걸이를 뚫지 않고, 인계·컵·업무 복귀가 해당 팔을 우선 사용할 수 있어야 한다.

## 남은 작업의 우선순위

| 순서 | 후속 작업 | 완료 기준 |
|---|---|---|
| 1 | 방문자와 호스트 상태 표시 분리 | 20방향 방문·중단에서 실제 위치/자세와 문구 일치 |
| 2 | 5명 필기 손의 약지·소지 목표와 진단 보강 | 나라 선행→나라/소라/민→5명, 고정 손가락 길이·필수 접촉·소유권 보존 |
| 3 | 소파·회의의 지지 자세와 비대칭 대기 동작 | 무릎/팔걸이 접촉, 한쪽 손짓, 시선/응답·복귀 회귀 |
| 4 | 보행·회전의 시각 품질 개선 | 뒤꿈치/발끝·골반 선행·감속 변주를 기존 접지/코너/중단 검사와 근접 화면으로 비교 |
| 5 | 팔·몸·가구의 메시 간 접촉 검사 확대 | 현재의 몸 중심 거리·목표점 검사에 팔/책상/소파의 보수적 체적 검사를 추가 |
| 6 | 실물 모바일 검수 | 터치·카메라·20분 발열·실제 OS 모션 축소/백그라운드, 기기별 품질 예산 기록 |

전체 프로젝트에는 GPU 메모리·20명 부하·1시간을 넘는 반복 사용 측정, 누적 데이터 보관/수동 정리 절차의 실제 운영 검수가 남아 있다. 60분 JS heap 검수는 이미 완료되어 잔여 작업으로 다시 세지 않는다. 기존 raw 백업·격리 복구·권한·저장 결과 보존은 후속 개선에서도 유지한다.
