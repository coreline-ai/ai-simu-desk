# 실물 모바일 검수 기록

2026-10-21: 연결 목록의 iPhone XS Max는 접근 불가였고 사용자가 현재 연결 불가로 답했다. **실물 검수는 미완료**다. 데스크톱의 viewport/모션 설정·터치 모의 입력은 실제 iOS/Android·열·GPU 메모리 측정과 별개로 기록한다.

## 기기 연결 후 수행

- [ ] 모델·OS·브라우저·해상도/DPR·선택 화질·전원/저전력 설정을 기록한다.
- [ ] 격리된 합성 DB의 로컬 검수 호스트에 접속한다. 사용자 DB/비밀을 노출하는 공개 터널은 만들지 않는다.
- [ ] 세로/가로에서 상단·비교 메뉴 넘침, 손가락으로 동료 선택·카메라 회전/확대·버튼 터치를 확인한다.
- [ ] 각 인물의 걷기·회의·컵·소파·업무 복귀와 정리 후 예약/소품 회수를 확인한다.
- [ ] 실제 OS 모션 축소를 켜고 시작 정지/명시적 재생·표시 일치를 확인한다.
- [ ] 화면 잠금·앱 전환·백그라운드 복귀 후 중복 canvas/시계 급진행/입력 중단을 확인한다.
- [ ] 동일 화질로 20분 실행해 시작/종료 프레임 시간·열 경고·화면 어두워짐·배터리 변화를 기록한다. 온도 센서가 없으면 수치를 만들지 않는다.
- [ ] 초기 목표 p95 33.3ms 이하와 오류 0/회수 기준을 확인하고 기기별 화질을 결정한다. 미달이면 품질/비교 결과를 남긴다.
- [ ] GPU 메모리를 직접 측정할 수 있는 경우만 사용 도구·단위·수치를 기록한다. JS heap·geometry/texture 개수를 VRAM으로 환산하지 않는다.
