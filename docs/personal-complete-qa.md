# 각자의 리듬으로 함께하는 하루 · 활동 v12 P1~P2

후속 요청으로 준 안경 정돈과 실제 숨김·복귀·장시간 검수를 추가했다. 아래는 당시 P1~P2 기록이며, 최신 실행 상태는 [잔여 검수·안경 보강](personal-final-qa.md)을 확인한다.

작성: 2026-10-23 KST. [실행 계획](../dev-plan/implement_20261022_165655.md)의 3~7번을 대상으로 한다. [P0 기록](personal-motion-qa.md)은 당시 근거로 보존한다.

## 구현 범위

| 항목 | 적용 |
|---|---|
| 역할별 업무 15종 | 인물·변주마다 관찰→행동→멈춤→확인의 리듬. 정지 구간에는 실제 소품 목표의 시간도 정지한다. 준의 대표 동작은 짧은 입력→화면 확인이다. |
| 컵·커피 | 5명별 준비·들기·음용·내려놓기·손 회수 시간. 컵과 오른손 받침은 같은 0~1 위상을 사용한다. 추출 3.2초·기계 예약·대기 순서는 보존한다. |
| 대화·초대·휴식 | 발언 전 준비와 끝의 손 회수, 개인별 응답 완급·방문 시선·창가 반응·희소한 인사. 기존 턴 확인/대기 종료와 소파 외측 팔걸이·내측 무릎 지지를 보존한다. |
| 보드·문서·업무 결과 | 검증된 작은 보드 영역에서 개인별 가리키기/멈춤, 문서를 받았을 때 읽기/확인. 업무 결과는 책상 위 손과 작은 머리 반응으로 표현한다. 서버 시간을 지연하지 않는다. |
| 필요한 에셋 | 기존 손가락에 개인별 이완/벌림 프리셋, 개인 컵 회수 시간과 손 펴기 위상 정합, 펜 대기점·페이지/컵의 기존 실제 접촉 기준 재사용. 새 동적 노드·외부 에셋·GLB 증설 없음. |
| 비교·제품 연결 | `/demos/activities/personal/`에 15종 업무·컵·커피·방문/문서·보드·3시나리오·자동 하루를 제공한다. 기본 제품의 공간 v9에 v12를 연결하며 기존 v11 비교와 이전 데모는 보존한다. |

나라=짧은 메모와 재독, 소라=탐색과 비교, 준=입력과 화면 확인, 민=항목 확인과 재확인, 레오=정렬과 읽기로 구분한다. 임의 흔들림이나 중복 소품 소유권을 추가하지 않는다.

안경 조정은 이번 필수 에셋에서 제외했다. 현재 얼굴/손 지지 앵커로 유효 접촉을 보장할 필요성이 확인되지 않았으며, 머리 접촉 전용 선행 검증 없이 넣지 않는다. 기존 페이지 모서리·컵 받침이 충분해 새 메시를 중복 생성하지 않는다.

## 검증 현황

증거는 `product/evidence/personal-complete/`. 현재 사용자 DB를 검사 데이터로 사용하지 않는다.

- 단계 3~6 각 3개 검사 통과: 업무 15종·단계별 취소, 컵 5명·단계별 업무 중단/반납/커피 순환, 대화 20개 좌석 순서·방문/업무 복귀, 보드 5순서·문서 5명 수신/전환 단계 취소·빠른 업무 결과.
- 에셋 보강 후 업무/프레임 왕복 4개 통과. v11/v12의 장면 스키마와 노드 수 동일, 상체·손가락 인스턴스까지 왕복한다.
- 실제 독립 계정 3개: 역할/컵 공동 관찰, 정지 중 손·소품·위치 일치, 늦은 입장, 보기 전용 제어 거절, 제어권 전환, 권한 강등, 로그아웃 임대 해제 통과 (`shared-browser.json`).
- 정적 문법·타입·의존성 경계 검사 통과. 관리 빌드 준비 성공, 공간 v9 8,768,140 bytes / 기본 105클립 유지.
- 인메모리 전체 활동 22묶음 통과 (`activities.json`): 기본 21상태×5명, 15업무, 컵/휴식/창가/커피, 2~5인 회의·보드·방문/문서·세 시나리오. 시뮬레이션 시간이며 실제 장시간 결과와 구분한다.
- 전후 성능 (`performance.json`): 데스크톱 1280×900/DPR1/기본 화질/동일 카메라/각 5초×3회 대기. p95 중앙값 v11 16.8ms / v12 16.8ms, 동일 1,097 draw calls / 773,350 triangles. 다른 로컬 QA도 실행 중이던 환경이며 모바일 벤치마크가 아니다.
- 공개 브라우저 12항목 통과 (`browser.json`): 15종 역할·컵/양손 지지·2인 회의 직렬화·방문/문서·소파 업무 중단·네 배속/정지·320~1440px·모션 축소·6회 비교 재생성·GLB 실패 복구·자기 방문 방지.
- 실제 벽시계 10분 이상 통과 (`soak.json`): 세 시나리오 모두 완료, 8회 비교 재생성, 연속 생활 동작 뒤 전원 업무 자리·소품/예약 회수. JS heap은 강제 GC 뒤 측정하며 GPU 메모리는 측정하지 않는다.
- 전체 자동 회귀와 로컬 적용은 아래 최종 결과를 확인한다.

초기 실패는 `*-initial.tap`, `*-initial.log`에 보존한다. 새 방문 시선 함수 참조 오류는 수정했다. 컵 취소 뒤 기존 결과 반응 대기와 비동기 화면 재생성을 검사 코드가 기다리도록 보정했다. 책상 접촉 후 어깨 Euler 각 단독 기준 대신 고정 길이·실제 접촉·반응/입력 상태를 검증한다. 2인 회의의 순환 참조는 적용 ID Set으로 제거하고 준비/대화/복귀 JSON 회귀 검사를 추가했다. 커피 단계 변경 시 주의 반응 시각을 초기화하며, 자신을 방문 대상에서 제외한다. option의 실제 DOM disabled=true를 일부 Playwright 판정이 false로 반환해 실제 DOM 값으로 검사한다.

## 검증 한계

- 실물 iPhone XS Max: 사용자 결정에 따라 연결 불가·미완료 유지.
- 브라우저 viewport 검수는 실물 터치·발열·모바일 GPU 검수를 대신하지 않는다.
- JS heap/렌더러 리소스 추세와 GPU 메모리 측정은 구분한다.
- 절차적 스타일라이즈드 동작이며 모션캡처·실제 인간 완전 재현을 주장하지 않는다.
- 외부 DB/AI/클라우드·유료 서비스·배포·커밋/푸시는 이번 범위에 없다.

연속 검수: 실제 610.9초, GC 후 JS heap 35.74 → 35.56MiB. 측정 구간 geometry 314~316, texture 45~45. 상태에 따른 최초 가시 형상 업로드와 지속 누수를 구분하며 이 구간을 전체 10분 heap 측정으로 확대 주장하지 않는다.

## 로컬 적용

기존 로컬 PGlite를 비공개 0600 백업 후 그대로 사용했다. 이전 서버 프로세스는 이미 종료된 상태였고, 백업 도구가 기존 잠금을 확인/정리했다. 관리 릴리스 `1792711769919-c4f84597-7123-4017-8e57-447c24b54547`을 첫 적용했다. 최종 문서 포함 현재 릴리스는 `application.json`의 release와 `delivery.json`을 기준으로 한다.

`application.json` / `delivery.json`: 기존 서버 번들 해시 동일, 실제 HTTP 앱/비교/GLB 해시와 릴리스 manifest 일치, PGlite·Fake AI·공간9/활동12·5명·x1.5 시간 진행·단일 canvas 확인. `/start`와 검수 문서 라이브러리 연결도 확인했다. 실제 앱 브라우저에서 재생과 자기 방문 비활성을 확인했다.

전체 `npm test`의 최종 집계와 보정한 검사의 재실행 결과는 아래에 구분해 기록한다.

비교본 분기 점검: v11 보드의 고정 시선, 기존 잉크 표시와 구형 컵 손 회수의 원래 값을 유지하도록 조건을 분리했다. 새 v12 연출은 바꾸지 않았다. `legacy-isolation.tap`의 구형 컵 2개·문맥 2개 검사 통과. 전체 회귀 이후 최종 문서를 포함한 관리 빌드로 갱신한다.

연속 시각 기록: 실제 4180의 5명 근접 업무 주기(x1)와 나라·소라 소파 이동/대화/복귀(x3)를 각각 기록했다(`video.json`, `sofa-video.json`). 15프레임 업무 접촉 시트와 소파 근접 프레임을 확인했다. 역할 영상은 `motion-inspection.mp4`(50초), 소파 영상은 `sofa-inspection.mp4`다. 최초 소파 카메라가 레오에 유지된 검수 캡처는 history에 분리하고 나라 근접 카메라로 다시 기록했다. 제품은 시연 변경 시 기존 카메라를 보존한다.

## 최종 회귀 집계

- 전체 `npm test`: **399개 실행, 398개 통과·1개 실패**. 원본 로그 `all-tests.tap`과 exit 1을 그대로 보존한다.
- 실패 207번은 P0의 “5명 동시 완전 컵 지지” 조건이었다. P1에서 음용 시간이 달라 공통 시점이 없어졌으므로 각 인물의 완전 지지 순간에 동일한 손 우선권·소유권·오차 기준을 확인하도록 검사했다. 제품 접촉 기준을 완화하지 않았다.
- 해당 실패를 포함한 **7개 영향 검사 재실행 모두 통과**(`cup-regression.tap`). 나머지 398개와 합쳐 전체 399개 사례의 미해결 실패는 **0**이다. 전체 묶음을 처음부터 다시 실행한 exit 0 기록으로 표시하지 않는다.
- 추가 문맥 2개(커피 단계 반응·v11 보드 고정 시선)는 `legacy-isolation.tap`에서 구형 컵 2개와 함께 4개 통과. 총 고유 검사 범위는 401개다. 최종 요약은 `regression-summary.json`.
- 최종 문법·타입·의존성 경계 검사 통과(`final-checks.log`).
- 실제 탭 숨김은 headless 브라우저가 비활성 탭도 visible로 보고해 검수 불가(`visibility.json`). 숨김 시 시간 제외는 기존 MotionClock 조건 단위 검사와 코드 검토로 확인했으며 실제 숨김 결과로 주장하지 않는다. 실물 모바일 미완료와 함께 남긴다.

원본 에셋·기본 105클립과 서버 번들은 유지하고, 개인별 레시피/손 프리셋 및 기본 제품/비교 웹만 확장했다. 배포·DB 전환·커밋/푸시는 수행하지 않았다.
