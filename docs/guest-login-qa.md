# 클릭 한 번으로 게스트 로그인

검증일: 2026-10-20 KST.

## 구현

- 로그인 폼 아래에 ‘게스트로 바로 시작하기’ 버튼을 제공합니다. 이메일·비밀번호 없이 서버의 고정된 공용 게스트 계정 하나로 로그인합니다.
- 게스트 계정은 첫 클릭에서 생성되고, 이후 모든 게스트 방문자가 같은 체험 공간과 업무 기록을 사용합니다. 로그인 전·후에 공용 계정임을 안내합니다.
- Better Auth 플러그인의 서버 전용 계정 생성·세션 생성·쿠키 발급을 사용합니다. 계정 비밀번호와 credential 레코드는 만들지 않으며 로그인 응답은 success만 포함합니다.
- 일반 사용자 로그인과 동일한 HttpOnly·SameSite 쿠키, 원격 HTTPS의 Secure 쿠키, 서버 DB 세션, Origin 검사와 로그아웃을 적용합니다. 게스트 로그인은 60초당 10회로 제한합니다.
- 게스트 이메일은 일반 회원가입에 사용할 수 없습니다. 게스트의 프로필·자격 증명 변경을 차단하고, 로그인한 일반 사용자를 게스트로 몰래 전환하지 않습니다.
- 게스트의 공간은 일반 사용자의 개인 공간과 기존 권한 체계로 분리됩니다. 기존 계정·기록을 수정하거나 초기화하지 않습니다.

## 검증

- 전체 테스트 55개 통과. 신규 검사는 동시 최초 접속 시 계정 하나 유지, 세션별 로그아웃 격리, 기존 사용자 공간 접근 차단, 이메일 예약, 프로필·비밀번호 변경 차단, 세션 만료, 잘못된 Origin 차단, Secure 쿠키와 DB rate limit을 확인합니다.
- 타입·JS 구문·의존성 경계 검사 통과.
- 실행 중인 로컬 웹에서 로그인 하단 버튼 클릭 → 게스트의 스튜디오 진입 → 실제 3D 장면 로딩을 확인했습니다.
- 원격 쿠키·rate limit 검사는 HTTPS 요청과 일회용 PGlite DB를 사용한 자동 테스트입니다. 실제 Vercel/Neon 배포 검증은 아직 수행하지 않았습니다.
