# 5인 에셋·생활 동작 v10 검수 기록

## 범위와 상태

P0~P2 보강, 공간 v8 / 활동 v10, 나라·소라·준·민·레오 5명 기준이다. 기존 공간 v7 / 활동 v9를 보존하고 비교한다. 로컬 환경만 사용하며 실제 사용자 DB와 분리한 검수 서버에서 합성 계정/업무로 검사한다.

P0~P2 구현과 313개 전체 회귀, 실제 브라우저·새 설치·10분/30분/60분 검수가 완료됐다. 사용자 DB 비공개 백업 후 4180 로컬 웹에 적용하고 실제 5인 화면·재생을 확인했다. 실물 기기 항목은 아래 미완료 범위로 구분한다.

## 구현 근거

- [상세 실행 계획](../dev-plan/implement_20261022_110041.md), [P0~P2 에셋 명세](ensemble-assets-catalog.md).
- 비밀값·실제 DB를 제외한 이전 소스 스냅샷: `.data/ensemble-baseline-20261022T020055Z`.
- 소스/자산 고정 지문: `product/evidence/ensemble-activities/source-freeze.json`.
- GLB v8: 8,516,844 bytes, 5명·105클립. 15MiB 예산 이내다.
- 새 메타데이터 `ensembleOffice`로 신체·역할·컵·회의·커피·디테일·출처를 구분한다. 새 기능은 이전 모델의 동작 계약에 강제로 연결하지 않는다.

## 실제 브라우저 동작

- 네 배속의 실측 비율: x1 약 1.0000, x1.5 약 1.5028, x2 약 2.0000, x3 약 3.0001. 업무/인증/DB 시간을 바꾸지 않는다.
- 320/360/375/390/414/768/1024/1440px에서 가로 넘침 없이 canvas 1개를 유지했다. 이는 데스크톱 viewport 검사이며 실물 모바일 검사가 아니다.
- 커피 5명 모두 버튼/추출/회수/복귀를 완료했다. 5인 회의는 5명 모두 실제 착석하고 컵을 놓은 뒤 시작한다. 전원이 발언과 메모를 마친 뒤 소품을 정리한다.
- 음향은 기본 꺼짐이다. 사용자 클릭 후 단일 AudioContext를 만들고, 정지/음소거/뷰 폐기 때 재생 자원을 정리한다.
- 신규 바인딩 실패 시 공간 v7/활동 v9로 함께 복구한다. 이후 기존 공간 v6/활동 v8과 하위 복구 단계도 보존한다. 복구 뒤 지원하지 않는 신규 버튼은 비활성화한다.

## 수치 검사와 한계

- 손가락 접점 최대 3mm, 팔/펜촉 IK 오차 최대 1mm를 검사한다. 종이 접촉은 휜 표면의 실제 국부 높이를 사용한다.
- 컵은 책상/회의 코스터 또는 드립 트레이 위에 0.5mm 간격으로 놓는다. 손 지지는 기존 1.5mm 간격을 유지한다.
- 인물 중심의 0.44m 겹침 검사와 통로 반경 0.5m를 유지한다. 새 회의 테이블은 실제 타원 거리로 경로를 검사한다.
- 팔/몸통 캡슐과 가구 AABB의 접촉 진단은 보수적 후보 검사다. 양성 행을 실제 피부 관통으로 단정하지 않으며 전체 물리/천 시뮬레이션을 의미하지 않는다.
- 실물 iPhone XS Max는 사용자 응답에 따라 연결 불가다. 실물 터치·발열·VRAM·실제 오디오 청취 균형은 별도 미완료로 남긴다. JS heap 검사를 GPU 메모리 검수로 대신하지 않는다.

## 최종 형상·제품 회귀 보강

- 컵 손잡이/손목/접점은 revision 2 메타데이터를 사용한다. 실제 손바닥 정점의 책상 상판·컵 벽 검사는 5명 75개 단계 표본에서 통과했다(`prop-volume.json`).
- 회의 메모의 실제 25개 인물/좌석 조합 검사에 착석 중 손 올리기·탁자 지지를 추가했다(`palm-volume.json`, `palm-seated-supports.json`). 최종 결과는 해당 파일의 `passed`를 기준으로 한다. 수정 전 실패·중단은 `before-palm-contact/`에 보존했다.
- 게스트 5명 참여와 6번째 거절은 `five-guest-collaboration.json`, 결과/설정/댓글/알림의 응답 순서 회귀는 `ui-races.json`에 기록했다. 기존 검수 파일을 보존해 새 폴더에 별도로 저장한다.
- 4배속 빠른 혼합의 관찰 간격은 짧은 완료 동작을 놓치지 않도록 8/30초다. 이는 실제 x1 장시간 검사의 합격 기준이나 동작 시간을 변경하지 않는다.

- 새 설치 compiled 검수 초회에는 뷰어의 댓글 표시를 기다리다 30초 제한을 넘었다. 페이지 오류는 없었고, HTTP POST 응답·작성자 표시 확인을 분리한 재검수에서 댓글/뷰어 권한을 포함한 전체 절차를 통과했다. 제품 런타임은 고정 상태를 유지했다. 초회 기록은 `before-palm-contact/compiled-comment-timeout.json`에 보존한다.

- 추가 취소 검수에서 손 지지 종료가 소품 정리보다 먼저 끝나는 문제와 초기 필기 보간의 손/연필 간격 손실을 수정했다. 5명×필기 초기/중간/후기·반납의 20개 검사에서 소유권/손가락/실제 손바닥/복귀를 확인했고 전부 통과했다. 이전 장시간 실행은 중단으로 보존했으며 최종 소스로 재검수를 통과했다. `before-cancelled-note-support/`와 `cancel-contact-tests.tap`을 참고한다.

## 60분 결과와 적용 근거

- 5분×12주기, 공동 공간 3개, 15분마다 로그아웃/재로그인과 최종 로그아웃을 실제 시간으로 수행했다. 각 주기의 5역할 업무·저장·댓글·생활 동작을 확인했다.
- 강제 GC 후 JS heap의 안정 구간 중앙값은 약 21.88MiB, 후반 중앙값은 약 22.39MiB로 증가량 약 0.51MiB였다. 로그아웃 heap 증가는 약 0.69MiB이며 합격 기준(20% 또는 8MiB)을 통과했다. 활성 canvas 1개·로그아웃 canvas 0개, 페이지 오류 0, 소스 불변 검사를 통과했다.
- 검수 호스트 JS, 새 설치의 컴파일 JS, 적용 후보 JS는 동일한 SHA-256이다(`compiled-app-match.json`). 서버 번들은 현재 제품과 같으며 DB 스키마/인증 계약 변경은 없다.
- 최종 검수 요약은 `acceptance.json`, 로컬 적용과 실제 화면 증거는 `delivery.json`에 기록한다. 실물 모바일·GPU 메모리·발열·오디오 청취 균형은 이 결과에 포함하지 않는다.

- 실제 적용 주소: `http://127.0.0.1:4180/demos/activities/ensemble/`. 5인 전원 착석·근접/전체 보기와 x1.5 재생·자율 생활을 확인했다. 효과음 기본 꺼짐을 유지하며, 기존 v9 비교와 x1/x1.5/x2/x3 제어를 제공한다. 기존 사용자 DB는 비공개 백업 후 같은 경로로 재사용했다.
