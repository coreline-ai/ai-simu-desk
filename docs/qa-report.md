## 발견 사항과 수정

1. 모바일에서 기록이 업무 폼보다 먼저 나옴: DOM과 grid 영역을 조정해 오피스 → 업무 → 기록 순서로 수정하고 390px에서 재확인했습니다.
2. 직원 이름 조사 `준와`: `준과`로 수정하고 직원 메타데이터에서 관리합니다.
3. 오래된 표시 기록 제거와 중복 방지 수명 결합: 별도의 탭 수명 요청 키 집합을 유지하도록 수정하고 회귀 테스트를 추가했습니다. 이 집합은 서버 영속 중복 방지를 대체하지 않습니다.
4. 요청 크기 2048px와 반환 아틀라스 1254px 차이: 실제 크기와 백분율 그리드를 manifest에 기록했습니다.

## 이전 v1 책상 바닥 경계 수정 검증

사용자 제보로 나라·준의 책상 앞다리가 사무실 바닥 상판을 벗어나는 문제를 확인했습니다. 기존 데스크톱 30%, 모바일 31% 크기와 화면 기준 좌표가 원인이었습니다. 기존 이미지 로딩·합성 확인에 바닥 지지 영역 검사가 빠져 있었습니다.

- 너비를 공통 25%로 조정하고 나라 `(21%, 32%)`, 준 `(51%, 39%)`로 이동했습니다. 모바일의 별도 확대·위치 덮어쓰기는 제거했습니다.
- 단일 파일 `demo/preview.html`도 다시 생성하고 열린 미리보기를 갱신했습니다.
- 데스크톱 1280px, 태블릿 768px, 모바일 390px 및 사용자가 보고 있던 319px에서 실제 DOM 좌표와 화면을 확인했습니다. 모두 가로 넘침이 없고 직원 선택 영역은 44px 이상입니다.
- 바닥 상판 안쪽의 보수적인 안전 다각형과 모든 16프레임의 하단 불투명 영역을 대조했습니다. 네 화면 크기의 총 64개 프레임 검사에서 바닥 밖 지지 영역 픽셀은 0입니다. 같은 검사로 기존 데스크톱 CSS의 배치는 실패함을 확인했습니다.
- 이 검사는 현재 생성 이미지의 지지 영역 배치를 확인하는 검사이며 실시간 3D 충돌 판정은 아닙니다.
- `npm test` 10/10 및 `npm run check` 통과.

## 현재 v2 크기·원근·그림자 보정 검증

이전 수정은 바닥 경계만 확인했고 책상 모서리 방향·가구 두께·광원 정합 검토는 충분하지 않았습니다. 배경을 우선 참조로 직원 에셋을 다시 생성하고, 실측 원본 영역과 공통 바닥 앵커를 사용하는 캔버스 렌더러로 교체했습니다. 현재 배치는 너비 20%, 나라 바닥 `(34%,67%)`, 준 바닥 `(66%,74%)`입니다. 전체 외곽 CSS 그림자는 제거했습니다.

- 16프레임의 불투명 경계가 모두 원본 읽기 영역 안에 있고 공통 캔버스에도 잘리지 않습니다.
- 1280/768/390/319px의 실제 DOM 좌표 × 16프레임 = 64개 검사. 불투명 경계 하단 25%, 알파 128 이상 지지 픽셀의 바닥 이탈 0, 캔버스 잘림 0입니다.
- 네 화면에서 가로 넘침 없음. 가장 작은 직원 선택 영역 약 56.59px.
- 에셋 모달의 작업 동작에서 행 1/3 정상 렌더링과 정사각형 미리보기 확인. 준 업무 진행 중 행 3, 비실행 나라 행 0 확인.
- 움직임 정지 시 모든 프레임 0. 정지 중에도 모의 업무 완료, 완료 후 휴식 행 복귀 확인.
- `npm test` 13/13, 네 모듈 구문 검사 및 단일 HTML 빌드 통과.
