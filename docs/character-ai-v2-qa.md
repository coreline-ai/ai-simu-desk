# 캐릭터 상태 동작·Fake AI v2·후속 수정과 인계

검증일: 2026-10-20 KST. [실행 계획](../dev-plan/implement_20261020_091244.md).

## 구현한 기능

### 캐릭터
- idle/thinking/typing/waiting/success/error 6개 상태 동작과 blink 클립을 실제 GLB에 포함했다.
- 나라·준의 독립 클립, 동료별 대기/눈 깜빡임 위상, 약 0.25초 블렌딩을 적용했다.
- 분석/검토는 사고 동작, 작성은 타이핑, 승인 대기는 시선을 올리는 자세를 사용한다.
- 완료/실패 반응은 관측한 새로운 상태 전이에서 한 번 재생한 뒤 idle로 복귀한다. 초기 로딩·과거 기록 선택은 완료 반응을 다시 발생시키지 않는다.
- 정지 시 클립 시간을 보존하고 숨김 탭에서 렌더를 멈춘다. 발·가구·책상 치수와 고정 좌표를 유지한다.

### Fake AI v2
- 분야와 산출물을 분리하고 기간·인원·예산·무료/제외 조건·항목 수·줄 수·표 형식을 추출한다.
- 실제 일정 구간/작업/완료 기준, 역할별 기획·개발 계획, 문구/본문 초안, 제공 원문 요약, 비교 틀을 생성한다.
- 기간을 일차/시간으로 배분한다. 예: 2주·3개 항목은 1~5일차 / 6~10일차 / 11~14일차.
- 부족한 원문·충돌한 조건·지원 범위 밖 요청은 확인 사항을 표시한다. 원문은 명령문과 분리해 데이터로 처리한다.
- 새 실행 때 엔진 버전·조건·완성 답변을 DB에 고정한다. 원격 서버 인스턴스/생성 함수가 바뀌어도 부분 스트림과 완료 답변은 동일하다.
- 고정 답변 전체는 API에 노출하지 않는다. 승인 전 output은 비어 있고, 분석 조건 메타데이터만 제공한다.
- 실제 LLM 추론·웹 검색은 수행하지 않는다. 지원 유형별 규칙으로 결과를 만드는 제한된 엔진이다.

### 이전 결과 수정·나라/준 인계
- 완료 결과에서 ‘3줄로 줄이기’, ‘표로 정리하기’, ‘다른 동료에게 인계 검토하기’를 선택한다.
- 선택한 원본·버전·동료를 입력 패널에 표시한다. 사용자가 확인 후 업무를 맡기며 원본 연결을 해제할 수 있다.
- 원본은 같은 공간의 접근 가능한 완료 답변만 허용한다. 읽기 전용·철회된 사용자·다른 공간의 결과는 거절한다.
- 원본 요청/결과/본문·조건을 제한된 스냅샷으로 저장한다. 후속 수정 체인과 재시도에서도 원래 조건을 보존한다.
- 인계는 서버에서 approvalRequired를 강제한다. 다른 동료를 지정해야 하며 소유자의 승인 후 실행한다.
- 답변에 원본 버전·요청·미리보기를 제공한다. 긴 기존 원본은 앞 4,000자 사용 사실을 표시한다.
- 수정은 줄 수 지정 요약/표 변환을 지원한다. 임의 의미 재창작은 지원한다고 가장하지 않는다.

## 검증

- 전체 자동 검사 **94/94 통과**. 모델·동작·출처·조건·계정·공동 공간·승인·취소·스트림·백업 복구·마이그레이션 회귀를 포함한다.
- Fake AI 고정 평가 **30개** 포함. 2주/1명/무료/3개 항목, 숫자·단위·원문·요약 줄 수·역할 차이·네트워크 0회·버전 고정·승인 전 결과 비노출을 검사한다.
- 실제 TLS PostgreSQL/HTTPS 통합 **4개 통과**. 서로 다른 앱 인스턴스의 인계 요청/승인/완료, Secure 게스트 세션과 일반 공간 접근 차단까지 확인했다.
- 원격 생성 진행에 800ms 분석 구간을 반영해 짧은 대기 시간 없이 20회 즉시 조회하던 기존 통합 검사를 유한 시간 폴링으로 조정했다.
- DB 마이그레이션 006(답변 고정/phase), 007(원본 문맥)을 추가했다. 기존 DB 업그레이드·계정/세션/답변/요청 키 보존과 백업 복구 검사를 통과했다.
- 적용 전 로컬 DB를 서버 종료 상태로 비공개 .data/backups 아래에 백업했다. DB 초기화/덮어쓰기는 수행하지 않았다.
- 타입·구문·의존성 경계·제품/Vercel 로컬 빌드를 통과했다.
- 파일럿 브라우저의 3초 렌더 측정은 75fps, 활성 형상 214/텍스처 3. 전체/확대 시점의 상태 클립을 확인했다. 실제 휴대폰 성능 측정은 아니다.
- 최종 제품 브라우저의 수정·인계 흐름과 반응형 화면 결과는 아래 증거 및 계획의 마지막 기록을 참조한다.

## 최종 화면 확인
- 1280/390px에서 가로 넘침 없음. 표는 자체 영역 안에서 가로 스크롤할 수 있다.
- 3줄 요약의 실제 줄 수, 연결한 원본 버전, 인계 승인 전 빈 답변과 waiting 동작, 승인 후 조건 보존·준의 개발 계획, 표 결과와 새로고침 후 기록 유지를 확인했다.
- 최종 표 UI 연결 중 CSS 파일을 잘못 저장한 문제가 있어 기존 스타일과 추가 스타일을 복구했다. 빌드의 CSS 파싱/경고 검사와 실제 스타일 적용·표 영역 overflow를 재확인했다.
- 짧은 기간의 계획에서는 작업을 생략하지 않고 묶어서 모든 필수 단계와 검증이 남도록 했다.

## 제한
- 외부 LLM·검색·음성·보행·전신 스키닝·물리 IK는 제공하지 않는다.
- 요약은 제공 원문에서 문장을 추리는 방식이고, 비교는 사양 자료 없이 사실·우열을 만들어내지 않는다.
- 실제 Vercel/Neon 계정 연결·공개 배포·실물 원격 기기 검증은 이번 로컬·통합 검사의 완료 범위에 포함하지 않는다.
