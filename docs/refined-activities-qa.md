# 편안한 교감 활동 v7 구현과 검수

2026-10-21 · main `cd7aca4` 이후 로컬 구현. [개발 계획](../dev-plan/implement_20261021_170900.md)에 따라 방문 표시, 손가락 접촉, 소파 대화 자세를 순서대로 보완했다. 전체 자동 **250개 통과/실패 0**와 브라우저 후보 검수를 완료했다. 기존 활동 v6는 비교 프로필로 보존한다. 기존 DB·설정을 보존해 4180의 제품 기본 동작과 비교 웹에 적용했다.

## 구현

| 범위 | 개선 내용 |
|---|---|
| 방문 표시 | `visit-presentation.mjs`가 방문자/호스트의 자리 대기·이동·검토·문서 제어·복귀를 구분한다. 호스트에게 방문자의 이동 단계를 복사하지 않는다. 제품/비교 화면이 같은 문구를 사용한다. |
| 손 | 손가락 길이를 유지한 채 펜 원통 표면을 따라 받침 위치를 찾는다. 최소/최대 도달 범위를 모두 고려한다. 5개 손가락의 필수 쥐기/보조 받침, 목표·실제 좌표, 도달 여부·오차를 진단한다. 먼 목표가 존재하면 실패 값도 그대로 남긴다. |
| 소파 | `sofa-support.mjs`가 실제 팔걸이·접힌 천과 자세가 적용된 바지 메시의 표면을 측정한다. 바깥 손은 팔걸이에, 안쪽 손은 무릎에 놓고 발언 때만 안쪽 손을 올린다. 인물별 높이·위치를 다르게 적용한다. |
| 전환 | 직전 손·팔꿈치 위치를 이어받고 팔꿈치 굽힘 방향의 변화 속도를 제한한다. 업무가 오면 손을 들어 표면에서 거둔 뒤 기존 복귀 자세로 연결한다. 컵/문서/역할 소품의 팔 제어가 우선한다. |
| 비교 | `/demos/activities/refined/`의 **v6 · 손과 협업** / **v7 · 편안한 교감** 전환. 구도·선택 인물·화질·조명·정지를 유지하고 활동을 초기화한다. 기존 모든 데모 경로를 유지한다. |

공간 모델 v6/105개 클립·소품 단일 소유권·2명 이동·소파/회의 각 2석을 유지한다. 서버/DB/Fake AI의 업무 계약과 저장 답변은 변경하지 않는다.

| 전환 보정 | 대화 진입에서 246mm 손 이동을 재현·보정했다. 팔꿈치 방향 보간의 반전도 검사해 프레임별 방향 변화 속도를 제한했다. |
| 빠른 혼합 | 1,800초 분량을 50ms 간격으로 계산한 시뮬레이션. 전원 역할 3변주·방문·컵·소파·회의·휴식·typing/success, 오류 0·완전 회수. 실제 30분 실행은 아니다. |
| 실제 브라우저 | 5명 동시 역할 사용 정지·개별 손 근접, v6/v7 동일 구도 비교, 소파 지지 완료 후 정지, 방문 호스트 표시·업무 연동 확인. |
| 복구 | 소파 지지 중 WebGL 손실/복원 후 v7/canvas 1, 후보 오류 후 기존 v6/canvas 1 확인. |

| 전체 자동 | `npm test`: 250개 통과/실패 0, 약 509초. 타입·의존 경계·구문 검사와 비교 화면 timer 회귀 통과. |

5명 근접 캡처에는 기획 메모·스케치·코드 설명·체크·문서 정리를 각각 기록한다. 소파 손바닥은 지지 완료 시 측정한 표면에서 1.5mm 위에 있으며, 발언하는 안쪽 손은 지지 상태로 표시하지 않는다. 자동 정지는 v7의 팔걸이 지지가 완료된 뒤에만 작동한다.

## 웹에서 확인하기

[v6와 v7 비교](http://127.0.0.1:4180/demos/activities/refined/?play=1)를 연다. **동료 자리 방문**, **손 가까이**, **소파에서 함께 대화**를 사용한다. 성능·중단·장시간 검수의 **자동 정지 구간**에서 역할 소품/소파 대화를 선택하면 접촉 자세를 자세히 볼 수 있다. 정지된 상태에서 다른 시연을 시작했으면 **재생**으로 진행한다. 시연을 마칠 때는 **활동 정리**로 복귀시킨다.

## 근거와 범위

근거는 `product/evidence/refined-activities/`의 자동 로그·접촉 비교·빠른 혼합·브라우저 JSON/PNG에 보관한다. 제품 통합 검수에는 4191의 임시 DB와 합성 계정을 사용한다. 실제 사용자 DB·세션·비밀값을 근거에 저장하지 않는다.

목표점 오차와 손바닥 지지는 관절·표면 기준이다. 모든 피부 메시의 비관통, 마찰·압력·천 변형을 의미하지 않는다. 실물 모바일/발열·GPU 메모리·새 실제 30/60분 검수는 이번 결과에 포함하지 않는다. 이전 안정화의 실제 장시간 기록은 해당 버전의 근거로 유지한다.

## 로컬 적용 결과

비공개 raw 백업 후 기존 4180 서버를 정상 종료/재시작했다. 안전 전체 빌드의 후보와 검수한 브라우저 앱의 SHA-256이 일치했다. 공간 GLB와 서버 바이너리는 이전 정상본과 동일하며 제품 DB/설정의 경로를 유지했다. 신규 비교를 포함한 공개 경로 15개가 모두 200이고 PGlite/Fake AI 로컬 상태를 확인했다. 기존 v6 경로와 신규 v7 전환을 함께 제공한다.
