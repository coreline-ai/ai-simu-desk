# v11 전체 동작 자체 검토와 5명 동작 차별화 제안

검토 일시: 2026-10-22 KST. 기준: main `6b60551`, 공간 v9·생활 동작 v11의 보행 보강본.

## 판정

기존 활동의 완료·복귀·소품 회수는 이번 범위에서 통과했다. **인물별 연출을 확장하려면 일부 설계를 수정한 뒤 진행하는 것이 적합하다(needs revision).** 보행·서서 하는 대화에 들어간 개인차가 착석 회의·컵·응답 순서까지 충분히 연결되지는 않는다. 기능 결함과 연출 개선을 구분한다.

이번 요청은 자체 검토와 구현 추천이다. 제품 동작은 수정하지 않았고, 재실행 가능한 QA와 검토/후속 계획을 추가했다. 현재 v11이 이전 버전에서 이어받은 동작을 함께 검토했으며, 모든 과거 스튜디오를 새로 전수 실행한 결과는 아니다.

## 5명별 추천 동작

다음은 제품 연출을 위한 성격 설정 제안이며 실제 인간의 성별·직업적 특성에 대한 주장이나 이미 완료된 구현 목록이 아니다. 모든 인물이 모든 공통 활동을 할 수 있고, 아래 습관의 빈도/크기만 다르게 한다.

| 캐릭터 | 연출 성격 | 업무 동작 심화 | 대화·휴식 습관 |
|---|---|---|---|
| 나라·기획 | 차분하게 생각하고 정리 | 제목 재독→펜을 잠깐 멈춤→짧은 두 메모→상대 확인 | 발언 전 작은 시선 이동·짧은 손짓·한 번 끄덕임, 컵을 들기 전 짧은 정지 |
| 소라·디자인 | 시각적으로 탐색하고 설명 | 곡선 스케치→펜을 띄워 비교→다른 방향으로 짧게 수정 | 접촉하지 않는 손의 열린 손바닥 설명, 듣는 동안 가벼운 고개 기울임·쉬는 구간 |
| 준·개발 | 조용히 집중하고 핵심 확인 | 타이핑 묶음→마우스/화면 확인→특정 영역 짧게 가리킴 | 작은 한 손 설명·한 박자 뒤의 끄덕임·등을 편하게 둔 휴식. 안경 올리기는 얼굴 접촉 앵커가 필요한 P2 선택 항목 |
| 민·QA | 순서대로 확인하고 재검토 | 행을 읽음→한 번 체크→잠깐 멈춤→이전 항목 재확인 | 설명을 들은 뒤 두 번의 작은 확인, 컵/펜을 놓고 다시 보는 짧은 시선 |
| 레오·정리 | 차분하게 흐름을 정돈 | 기존 모서리 정렬 심화→페이지 읽기→정돈된 묶음으로 놓기 | 상대를 받아주는 작은 손바닥·확인 후 요약, 컵을 받침 위에 놓고 손을 천천히 회수 |

공통 품질 규칙: 준비→주요 동작→정리의 완급, 움직이지 않는 구간, 상대 반응을 기다리는 턴, 실제 발/엉덩이/손 지지. 더 많은 손짓 자체를 목표로 하지 않는다.

## 에셋 보강 판단

- P0/P1은 기존 관절·연속 손 메시·5명×21 기본 클립과 노트/펜/태블릿/체크리스트/문서/컵/보드를 재사용한다. 신규 이미지나 전신 모델을 만드는 것보다 최종 자세와 리듬 연결을 먼저 개선한다.
- P2에서 손목/손가락 자세 프리셋, 펜 대기 위치·문서 모서리·컵 받침 목표를 역할별로 다듬는다. 이미 있는 소품을 복제해 장면 비용을 늘리지 않는다.
- 준/민의 안경 조정은 선택 사항이다. 머리의 안경 앵커·손 접근 경로·얼굴 접촉/중단 회수가 검증될 때만 추가한다. 머리카락 만지기/다리 꼬기/의자 흔들기는 이번 우선 구현에서 제외한다.
- 새 노드/동적 소품을 실제 추가하면 공동 관찰 스키마·버전·해제/대체 경로를 함께 검토한다. 보간 수치를 바꾸는 것과 동일하게 취급하지 않는다.

## 이번에 새로 수행한 검증

증거 경로: `product/evidence/character-motion-review/`.

1. `node scripts/qa/character-motion-review.mjs`: **22개 활동 묶음 통과**(`runtime.json`). 21기본 상태×5명의 2,950개 자세 샘플에서 유한 변환 확인, 역할별 15변주, 개인 컵 5명, 휴식 15변주, 소파/창가 각 5왕복, 커피 5순환, 소파 대화 5쌍, 착석 2/3/4/5인, 서서 5인, 보드 5순서, 방문·인계 5쌍, 시나리오 3개를 확인했다. 각 활동 종료 시 예약 잔류 없음·컵/책상 소품/문서/마커 회수를 검사했다.
2. `node --test --test-concurrency=1 product/tests/living-{cup,meetings,review,resume}.test.mjs`: **24개 통과**(`regression.tap`). 컵 받침 실제 손바닥·보드 손/끝 접촉, 회의 참가자/중단, 보드 접근/사용/반납/복귀 중 취소, 5명×소파/창가/휴식/커피 업무 중단·재개를 검사했다.
3. `STUDIO_QA_ORIGIN=http://127.0.0.1:4180 node scripts/qa/character-motion-browser.mjs`: 공개 데모의 **4개 화면**—나라 노트·컵·소파 대화·착석 회의—를 촬영했다(`browser.json`, PNG 4개). 공간 v9/활동 v11·단일 canvas·JS 오류 없음. 가까운 화면에서 소품을 사용하는 손/컵 받침·소파의 지지 자세가 보인다. 노트 사용의 공통 굽힌 팔 형태와 대화의 제한된 상체 연출은 남아 있다.

약 4,240초는 인메모리 시뮬레이션 시간을 합한 값이며 실시간 70분 장시간 검수라는 뜻이 아니다. 수학적 손 목표 오차가 작아도 손가락/피부의 모든 삼각형 충돌이나 자연스러움을 보장하지 않는다. 회귀 테스트 24개와 활동 묶음 22개는 다른 수준의 검증이며 46종 신규 동작으로 세지 않는다.

이번에는 전체 프로젝트 테스트, 전체 과거 스튜디오, 새 성능/장시간/공동 관찰 회귀를 다시 실행하지 않았다. 이전 검증은 [보행 검수](human-motion-qa.md)에 별도로 기록돼 있다. 실물 iPhone XS Max는 기존 결정대로 연결 불가·미완료다. 사용자 DB·계정·현재 서버 설정은 변경하지 않았다.
