# 1차 시각 데모 명세

## 목적과 사용자 흐름

직원 선택 → 짧은 업무 요청 → 상태 확인 → 필요 시 승인 또는 취소 → 결과 확인을 실제 생성 이미지와 움직이는 직원 에셋으로 보여줍니다. 첫 진입은 작은 사무실, 직원 둘, 실행 가능한 업무 패널로 구성합니다.

임시 제품명은 **AI Simu Desk**, 공간명은 **오후의 스튜디오**입니다. 직원은 나라(기획·리서치)와 준(개발·설계)입니다. 원본 서비스의 이름, 로고, 코드와 에셋을 사용하지 않습니다.

## 시각 방향

- 따뜻한 아이보리, 세이지, 옅은 오크와 테라코타. 모의 상태는 색과 텍스트를 함께 사용합니다.
- 불투명한 읽기 좋은 UI, 여유 있는 간격, 시스템 한글 글꼴, 조용한 그림자.
- 실제 생성한 사무실 PNG 위에 두 직원의 투명 워크스테이션 스프라이트를 배치합니다.
- 업무 진행 중에는 타이핑 프레임, 그 외에는 휴식 프레임을 재생합니다. 승인 대기는 별도 상태 라벨로 표시합니다.
- 사용자 동작으로 움직임을 멈출 수 있고 시스템의 `prefers-reduced-motion`을 존중합니다. 업무 타이머는 시각 애니메이션과 독립입니다.

## 상호작용

- 두 직원은 사무실과 명단에서 모두 선택할 수 있습니다.
- 업무 입력은 공백 제거 후 2~400자입니다. 입력은 HTML로 해석하지 않습니다.
- 정상 완료, 승인 대기, 연결 실패의 세 가지 **모의 시나리오**를 제공합니다.
- 실행 중 취소, 승인 대기 중 승인/거절, 실패/취소 후 새 실행 ID로 재시도를 제공합니다.
- 모의 결과는 직원 역할별로 미리 작성한 예시입니다. 입력을 실제 모델이 분석했다고 주장하지 않습니다.
- 작업 기록은 현재 탭의 종료된 실행을 보여줍니다. 기록 최대 10개, 영속 저장 없음.
- 에셋 보기에서 실제 PNG, 4×4 프레임 구성, 두 직원의 휴식/작업 애니메이션을 확인합니다.
- 모바일에서는 사무실과 업무 패널을 세로로 배치하고, 핵심 버튼을 최소 44px 터치 영역으로 제공합니다.

## 에셋 계약

배경 v1과 보정된 RGBA 아틀라스 v2를 사용합니다. 요청한 크기와 반환된 크기가 다를 수 있으므로 실제 메타데이터를 기록합니다. 반환된 아틀라스는 1254×1254이며 논리적으로 4×4입니다. 실제 행 경계는 균등하지 않으므로 `demo/src/scene-frames.mjs`의 실측 원본 영역으로 읽습니다. 360×360 논리 캔버스에 원본 비율을 유지해 그리고, 불투명 영역의 바닥 기준점을 `(180, 322)`로 맞춥니다. 원본 PNG 픽셀은 수정하지 않습니다.

행 0: 나라 휴식 / 행 1: 나라 타이핑 / 행 2: 준 휴식 / 행 3: 준 타이핑. 각 행은 4프레임입니다. 손·머리의 미세한 변화가 있는 반복 에셋이며 보행·리깅·360도 회전은 제공하지 않습니다. 알파 0~3 구간의 RGB 잡음은 일반 알파 합성에서 거의 보이지 않으나, 원본 RGB만 출력하는 뷰어에서는 색 잡음처럼 보일 수 있습니다. 원본은 보존합니다.

## 제외와 후속 연결점

실제 AI, Hermes 연결, 비밀키 입력, 로그인, DB, 파일 업로드, 다중 사용자, 회의, 예약 실행, 공개 배포는 이번 데모에 포함하지 않습니다. 후속 실제 실행기는 현재 상태 이벤트 계약에 연결하고, 도메인 테스트를 유지한 상태로 별도 계획에서 도입합니다.

## 책상 배치 계약

현재 배경·아틀라스 조합의 배치 좌표는 `demo/styles.css`가 소유합니다. 3:2 배경 좌표를 기준으로 두 논리 캔버스의 너비를 20%로 고정하고, 나라의 바닥 기준점은 `(34%, 67%)`, 준은 `(66%, 74%)`에 둡니다. `translate(-50%, -89.444444%)`는 360px 캔버스의 `(180, 322)`를 이 좌표에 놓습니다. 기존 v1의 25%·좌상단 좌표 계약은 v2에서 대체되었습니다. 모바일에서 별도로 크기와 위치를 덮어쓰지 않습니다.

방 전체 이미지의 사각 경계뿐 아니라 바닥 상판 안쪽에 정의한 안전 다각형을 기준으로 책상 다리·의자·발의 지지 영역을 확인합니다. 현재 PNG의 모든 16프레임에서 불투명 영역 하단 25%의 픽셀(알파 128 이상)이 안전 영역에 들어오는지 대조했습니다. 1280/768/390/319px 총 64개 검사에서 바닥 밖 지지 픽셀과 캔버스에 잘리는 불투명 픽셀은 0입니다. 전체 외곽에 적용하던 CSS 그림자를 제거하고 v2 이미지의 접지 그림자를 사용합니다. 배경이나 카메라, 아틀라스를 교체할 때에는 이 좌표를 그대로 재사용하지 않고 다시 검증합니다.
