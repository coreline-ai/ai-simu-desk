# 자연스러운 5명 생활 동작 · 로컬 검수

기준은 main `94ebf29`의 현행 활동이다. [후속 계획](../dev-plan/implement_20261020_183507.md)의 Phase 1~6을 순차 구현·검수했다. 현행 활동은 natural 옵션 없이 유지하며 후보는 `teamActivities.version: 3`으로 구분한다.

## Phase 1 · 나라 선행

루트와 발을 같은 거리 함수로 계산하는 출발/감속, 기립·착석의 상체 체중 이동, 이동 전 시선과 자유 관절 보간, 동작 전환과 분리된 깜빡임 시계를 추가했다. 루트·발·컵의 소유권을 일반 관절 보간에 섞지 않는다. 컵 IK는 마지막에 적용한다.

접지 중 발 이동 <1cm, 나라 소파 왕복·컵 도달 오차 <1mm·정지 시계 검사를 통과했다. 기존 경로/컵 검사도 통과했다. 격리된 실제 Chrome에서 나라 1명 후보를 착석까지 재생했고 JS 오류 0, canvas 1을 확인했다. `product/evidence/natural-activities/nara-phase1.{png,json}`에 근거를 보관한다.

## Phase 2 · 전신 휴식

서서 한 팔 뻗기·가벼운 등 펴기·옆으로 뻗기·어깨 이완의 준비/유지/마무리와 인물별 2개 선호 변주를 구현했다. 별도 컵/소파/회의 활동과 동시 배정하지 않으며 업무 도착 시 팔을 거두고 착석한다. 5명별 변주 구분·업무 중단 검사는 통과했고 실제 5명×2개 근접 캡처를 완료했다. 목표 quaternion을 제자리에서 보간하며 팔 동작이 작아지던 문제를 clone 목표로 고쳤고, 한 팔 뻗기 2rad 이상 검사와 10장 캡처를 다시 통과했다.

## Phase 3~5 · 대화·반응·리듬

컵을 든 경청→한 모금→탁자에 놓기, 빈손 설명→컵 회수→복귀를 추가했다. 설명 팔은 먼저 들어 올린 뒤 내밀어 탁자를 피한다. 실제 양쪽 한 모금과 업무 중단·컵 회수·예약 정리를 확인했다. 10가지 2인 조합 및 역순 1개에서 인사→응답→공동 노트→설명→확인 전 과정과 종료를 통과했다. 상대의 자세 적용 시간을 확인하며 준비/응답 시간 제한·반복 cue 배제·상대 제거/업무 도착 시 정리를 포함한다.

인물/seed 기반 휴지·눈 깜빡임·전신 휴식 선호와 활동 완료 횟수의 공정성을 함께 사용한다. 한 번에 자율 전신 휴식은 한 명이며, 자동 회의·휴식 간 동시 배정을 막는다. 빠른 1,800초 혼합 실행에서 5명 각각 2개 휴식 변주·휴식 4~7회·공동 확인 1~2회, 컵·소파·회의·업무/완료를 관찰했다. 이것은 실제 30분 경과 검사를 대신하지 않는다.

회의에서 먼저 복귀한 참가자에게 상대 복귀 중 새 전신 휴식이 배정되던 충돌을 발견했다. 세션 전체 종료까지 참가자를 재배정하지 않게 하고 회귀 검사를 추가했다. 이 안전 보정은 기존 v2 비교 경로에도 적용한다. 기존 v2의 포즈·보행·회의 리듬은 유지한다.

신규 12개 검사 통과. 나라만 보강하는 모드에서 적용 대상이 아닌 동료와 공동 확인을 시도하며 회의가 재시도되지 않던 예외를 수정했다. 5명 모드의 1,800초 빠른 혼합 보고서는 수정 전후 byte 단위로 동일하다(`subset-guard-regression.json`). 같은 seed 재현, 정지 중 예약/시계/상호 반응 불변, 정지 중 업무 도착 후 복귀, 모든 짝 조합과 소품/팔 접촉을 포함한다. 나라의 출발 가속·도착 감속·회전·소파 착석·기립·책상 착석 도중 정지 상태에서 업무를 보낸 뒤 재개해, 매 25ms 위치 이동 <3cm·최신 typing 복귀·예약 반환을 확인했다.

## 성능 비교

Chrome 격리 프로필, 1280×900 viewport / 1149×608 canvas, DPR 1, balanced, 낮, 전체 구도, 같은 초기 시연에서 기존과 후보를 번갈아 각각 30초×3회 측정했다. 각 회차 1,801 프레임, 실제 30,002~30,009ms다.

| 화면 | p50 | p95 3회 | 관측 최대 호출 | 관측 최대 삼각형 |
|---|---|---|---|---|
| 현행 생활 동작 v2 | 16.7ms | 16.8 / 16.7 / 16.7ms | 994 | 800,760 |
| 자연스러운 동작 v3 | 16.7ms | 16.7 / 16.8 / 16.7ms | 994 | 800,760 |

프레임 관리선 p50≤20ms/p95≤33.3ms 및 호출/삼각형 +10% 이내를 통과했다. 호출/삼각형은 1초 간격 관측의 최댓값이며 모든 프레임의 절대 최댓값이 아니다. 다른 격리 프로필에서 장시간 검사를 병행한 환경으로, 두 모드를 같은 설정/순서로 교대했다. 브라우저 프레임 간격은 GPU 시간이나 실물 모바일 성능을 뜻하지 않는다.

## 로컬 기본 적용과 초기 용량

동작·업무·복구·성능·실제 장시간 게이트 통과 후 제품 `/`의 기본 설정을 자연스러운 동작으로 전환했다. 후보 런타임 실패→현행 생활 동작→원본 v6→v5→v4 순서로 복구한다. 새 검수 조작은 비교 페이지에서 제공한다.

기존 v6 GLB 7,749,228 bytes와 SHA-256 `7d6addce4b58447bdc8d45c4c725fefb26df4986a96759e14c75cb1bb7dd1aab`를 유지한다. GLB+제품 JS+대체 PNG+CSS+HTML은 10,851,216 bytes(약 10.35MiB)로 초기 15MiB 관리선 이내다(`initial-assets.json`). 새 런타임 때문에 추가 이미지·텍스처를 로드하지 않는다. `/start`에서 새 자동 시연·현행 비교·기존 샘플로 이동할 수 있다.

## 재현

```sh
npm test
npm run typecheck
npm run check:product
npm run check:boundaries
npm run build:product
node scripts/activities-simulation.mjs continuous --natural
node scripts/activities-simulation.mjs mixed --natural
```

`/demos/activities/natural/?play=1`은 동작 줄이기 설정이 없을 때 5명 생활 시연을 자동 시작한다. 상단에서 ‘현행 생활 동작’과 ‘자연스러운 동작’을 전환한다. ‘나라 선행 검수’는 나라의 보정만 적용하고 다른 동료는 기존 동작을 사용한다. 전신 휴식·공동 노트 확인·업무 중단은 해당 버튼으로 재현한다. 장시간 검사는 진단 영역에서 실행하며 중간 재로드·비교 모드·정지 조작을 잠근다.

근거는 `product/evidence/natural-activities/`에 저장한다. 브라우저 검수 코드는 설치된 Chrome·번들 Playwright를 사용하며 앱의 새 운영 의존성을 추가하지 않는다.

## 검수 환경과 경계

이번 환경에는 이전 in-app 브라우저 제어 도구가 제공되지 않아, 설치된 Chrome과 번들 Playwright를 임시 프로필로 실행해 로컬 페이지를 검수한다. 개인 브라우저 프로필/기존 로그인은 사용하지 않는다. 후보 UI는 `/demos/activities/natural/`이며 현행 활동과 원본 v6로 전환 가능하다.

실제 10분/30분과 성능 근거는 이번 후보에서 새로 측정했다. 기존 장시간/성능 수치를 새 후보의 근거에 재사용하지 않았다. 실물 모바일·실제 OS 설정/백그라운드·GPU/heap 실측은 별도 미검증이다.
