# 배경·가구·직원 시각 검토와 보정

검토일: 2026-10-19. 대상: `office-background-v1.png`와 나라·준 워크스테이션. 아래 결과는 실제 합성 화면과 에셋을 기준으로 한 시각 검토입니다. 배경 PNG에는 카메라·실제 치수·광원 정보가 없으므로 물리적으로 정확한 3D 카메라 보정값을 의미하지 않습니다.

## 발견과 적용

| 검토 항목 | 기존 문제 | 적용한 보정 |
|---|---|---|
| 원근과 방향 | 기존 책상 전면 모서리의 기울기가 방의 전면 모서리와 반대여서 별도 장면처럼 보임 | 방을 1순위 참조로 v2 재생성. 책상 전면이 오른쪽 아래로 향하도록 정리 |
| 책상·의자 비례 | 두꺼운 판형 다리와 큰 책상 덩어리가 배경의 가느다란 가구와 충돌 | 얇은 오크 상판·다리, 세이지 의자, 앉은 성인과 노트북의 상대 크기를 함께 조정 |
| 화면 내 크기 | 바닥 경계 수정 후에도 기존 가구 형태가 무겁게 보임 | 논리 캔버스 너비를 장면의 20%로 조절. 동일 비율 축소로 인체·가구를 찌그러뜨리지 않음 |
| 광원·그림자 | 전체 실루엣의 CSS drop-shadow가 인물 둘레의 후광을 만듦 | 창 쪽 상부 오른쪽 빛을 참조한 에셋 사용. CSS 필터 제거, 발·가구 아래의 부드러운 이미지 접지 그림자 사용 |
| 동작 전환 | 생성 결과의 비균등한 행 간격을 균등 그리드로 읽으면 발 잘림·높이 이동 가능 | 16개 원본 영역 실측, 공통 바닥 앵커로 캔버스에 렌더링. 원본 픽셀 보존 |
| 깊이와 겹침 | 화면 좌상단 좌표만으로는 발 위치 판단이 어려움 | 나라 바닥 `(34%,67%)`, 준 `(66%,74%)`. 앞쪽 준을 나중에 그리는 고정 시점 순서 |

두 직원은 같은 공간의 미니어처 표현으로 보이며 책상·의자·몸의 비율과 색온도가 함께 맞춰졌습니다. 기존 얼굴·머리·옷의 정체성은 참조로 유지했습니다. 생성된 포즈의 작은 형상 차이는 남아 있고, 관절 리깅이나 실시간 그림자 계산은 제공하지 않습니다. 직교 시점에 가까운 합성이므로 앞쪽 준을 과장해서 확대하지 않았습니다.

## 검증

- 원본 v2: 1254×1254 RGBA. 논리 4행×4열, 실제 행 경계 `0/331/635/945/1254px`.
- 모든 16프레임의 불투명 영역을 포함하는 원본 사각형과 공통 바닥 기준점 확인.
- 1280×900, 768×1024, 390×844, 319×892에서 실제 DOM 배치 측정. 총 64개 프레임 대조에서 바닥 밖 지지 픽셀 0, 잘리는 불투명 픽셀 0. 지지 영역은 불투명 경계 하단 25%, 알파 128 이상으로 정의했습니다.
- 가로 넘침 없음. 가장 작은 직원 선택 영역 약 56.59px.
- 휴식/작업 미리보기와 모의 업무 전환, 움직임 정지, 에셋 로드·실패·해제 회귀 확인.
- 새 렌더러는 프레임이나 행이 달라질 때만 캔버스를 다시 그립니다.
