# 5인 생활·상호작용 v11 검수 기록

공간 v9 / 활동 v11, 나라·소라·준·민·레오 5명. 외부 DB/AI/에셋/배포를 사용하지 않고 로컬에서 검사한다. 기존 v8/v10 비교, 로그인·공동 공간·Fake AI·게스트 최대 5명과 실제 사용자 DB를 보존한다.

## 검수 중 수정한 사항

- 보드의 처음 목표가 일부 팔 도달 범위를 벗어났다. 실제 어깨 높이에 맞춰 목표를 1.16m로 내리고 팔 길이는 유지했다.
- 런타임 재생성 때 소품 추출/반환으로 자식 순서가 달라졌다. 노드를 안정된 계층 주소로 정렬해 프레임 식별을 유지한다.
- 관찰자가 송신자가 될 때 원격 프레임에서 컵이 손에 붙어 있으면 기존 내부 소유권과 달랐다. 원래 장면과 부모 관계를 복원한 뒤 런타임을 다시 만들도록 보정했다.
- 정적 인스턴스까지 전송하지 않도록 동적 손/잉크와 실제 변형 종이를 구분했다. 필수 동작 정보는 전달하며 큰 프레임은 5초 DB 체크포인트로 제한한다.
- 접근성 변경/모델 준비/업무 종료 후 소품 정리의 비동기 경계를 검수 스크립트에서도 기다린다.

- glTF는 숨김 노드의 초기 표시를 그대로 보장하지 않으므로 v9 런타임에서 보드 주제와 단일 표정을 명시적으로 초기화한다.
- 관찰 화면에 없는 내부 역할/컵 객체를 안내 문구가 직접 참조하던 부분을 최소 공유 정보로도 표시하도록 보정했다. 공유된 활동을 기준으로 관찰자 자동 카메라를 선택하고 일반 상태 표시는 한국어로 표시한다.
- 주기적인 조회와 제어 버튼 클릭이 경쟁하던 부분은 직렬화했다. 조회 중에도 버튼은 안정적으로 입력을 받고, 중복 제어/공간 전환은 재설정이나 뒤늦은 적용을 만들지 않는다. 렌더러 복구 시에는 송신 제어권을 반환한다.

## 증거와 최종 상태

`product/evidence/living-activities/`에 원본 검사 결과와 화면을 보존한다. 단계별 결과는 개발 계획 체크박스와 함께 최종 기록으로 갱신한다.

- 실제 브라우저 제어: `browser-controls.json`.
- 공동 관찰: `shared-browser.json`.
- 새 폴더·오프라인 의존성 설치·전체 빌드·5계정 업무/복원: `compiled-smoke.json`.
- 고유 자동 검사 항목 **359개**의 최종 결과가 통과다(`validated-tests.json`). 전체 348개 실행에서 기존 마이그레이션 수를 11로 기대하던 3개 검사가 실패했다. 기대값을 12로 갱신하고 새 테이블/기존 자료 보존 확인을 추가한 뒤 관련 7개를 재실행해 통과했다. 초기 실패 TAP은 `history/`에 보존하며 합격으로 덮어쓰지 않는다. 새 에셋/양손 컵, 공유 캡션·복구·동시 제어·공간 전환의 추가 검사와 변경 부분 재검증을 합쳐 집계한다.
- 실제 3배속 약 **149초** 동안 역할 업무→4인 회의→5인 보드 검토→업무 복귀를 완주하고, 이어서 5명이 모두 양손 컵 동작을 수행했다(`actual-rounds.json`). 최종 초기 표시/안내 보정은 `final-presentation.json`, `shared-browser.json`으로 재검수했다.
- 기존 v10과 v11을 1280×900/DPR1·balanced·낮·전체 구도에서 각 10초×3회 측정했다. p95 중앙값은 모두 약 **16.7ms**다. v11 기본 장면은 1,097 draw calls/773,350 triangles, 실제 시나리오 완료 장면은 1,139/782,350으로 1,200/950,000 예산 이내다(`performance.json`, `actual-rounds.json`).
- GLB v9는 **8,768,140 bytes**, 105클립으로 15MiB 예산 이내다. v6/v7/v8 파일 지문을 보존했다.
- 타입·경계·구문 검사, 공개 경로/개인 경로 차단과 단일 canvas를 확인했다. 최종 코드·자산 지문은 `source-freeze.json`에 기록한다.
- 기존 v10의 10/30/60분 결과를 v11 결과로 옮겨 적지 않는다. 이번 v11은 위 실시간 시나리오·여러 계정 검수와 자동 시뮬레이션/회귀 결과다.
- 로컬 적용과 실제 사용자 DB 보존 결과는 `delivery.json`, `db-preservation.json`에 별도로 기록한다.

## 남은 실물 검수

기존 사용자 결정에 따라 연결 불가인 iPhone XS Max 검수는 미완료다. 실물 터치, 기기 발열·배터리·GPU 메모리와 실제 효과음 청취 균형은 데스크톱 viewport/자동 검사로 대신하지 않는다.

## 실제 DB와 로컬 웹 적용

- 기존 실제 DB를 서버 정지 상태에서 비공개 gzip/0600으로 백업했다.
- 012 적용 전후 기존 **19개 테이블**의 행 수·내용 지문을 비교해 변경이 없음을 확인했다. 마이그레이션 기록은 11→12이며 `scene_rooms`만 새 테이블로 추가됐다(`db-preservation.json`).
- 실제 4180 앱 번들의 SHA-256이 오프라인 새 설치 검증 번들과 일치한다. 새 v11/기존 v10 경로와 GLB 제공, 단일 canvas, x1.5 자동 시나리오의 시간 진행을 실제 브라우저로 확인했다(`delivery.json`, `delivery-live.png`).
- 문서 패키지 갱신은 검증한 후보와 런타임/서버/에셋 파일을 대조한다(`release-equivalence.json`). 실제 계정·기록·설정·서버 전용 환경변수를 초기화하지 않았다.

## main 커밋 전 확인 · 2026-10-22

- 실행 소스 230개와 v6~v9 GLB 지문이 위 검증본과 일치한다. 마이그레이션 검증 테스트 두 곳에 조회 결과의 행 타입을 명시했으며 실행 코드에는 변경이 없다.
- 보정 후 관련 DB 테스트 5개, `typecheck`, 의존 경계 검사, 시각 모듈 114개와 안정화 모듈 48개의 구문 검사를 통과했다(`precommit-validation.json`, `precommit-db-tests.tap`).
- 기존 전체 실행이 약 26분 걸렸으므로 동일 실행 코드에 대한 중복 전체 검사는 중단했다. 부분 실행은 `history/precommit-full-repeat-stopped.tap`에 보관하며 새 전체 통과로 집계하지 않는다. 앞서 359개 고유 항목의 최종 결과와 이번 변경 부분의 재검증을 적용한다.
- 서버 환경변수·사용자 DB·비공개 백업·빌드 출력은 Git 제외 설정을 유지한다. 과거 원본 TAP 로그의 공백은 보존하며 소스 파일의 공백 오류는 없다.
