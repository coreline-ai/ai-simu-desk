# 업무 도구·독립 게스트 로컬 QA

2026-10-20. 외부 제공 DB 금지·로컬 개발·유료 업그레이드 금지 결정에 따라 구현했다. 클라우드 DB 연결/결제/실배포는 수행하지 않았다.

## 적용 내용
- 로컬/배포용 공통 runtime: 요청 기반 Fake AI, DB presence, 공통 SQL migration. 현재 실제 제품은 기존 PGlite 데이터 폴더를 유지한다. DB 주소가 없으므로 외부 PostgreSQL 통일 완료를 주장하지 않는다.
- 기획/개발/문구 3개 템플릿. 목표/대상/기술/제외 조건은 공간별 소유자만 버전 확인 후 저장한다. 저장 조건을 업무 입력에 명시적으로 넣고 검토할 수 있다. 기존 실행의 답변은 고정된다.
- 전체 기록 검색은 요청·이미 공개된 답변을 대상으로 단어를 문자 그대로 검색한다. 상태·동료 필터, 20개 단위 cursor 페이지, 오래된 결과 열기를 지원한다. 미승인 생성 본문은 반환하지 않는다.
- 원본 비교는 현재 원본을 다시 읽지 않고 당시 저장한 최대 4,000자 스냅샷과 선택 결과를 나란히 표시한다. 각 400줄까지 LCS 줄 비교로 변경을 표시하고 제한을 안내한다. 실행 상태 버전을 수정 횟수로 오인하지 않도록 비교 제목을 보완했다.
- 댓글은 1~1000자, 작성자별 분당 10개, 중복 키 재전송 방지, 50개씩 과거 조회. 보기 전용은 읽기만 가능하다. HTML은 텍스트로 표시한다.
- 승인 요청은 공간 소유자, 완료/실패는 요청자·소유자, 댓글은 작성자를 제외한 참여자에게 알린다. 알림은 공간·계정별로 분리하며 최근 20개와 전체 미읽음 수, 해당 공간 모두 읽음을 지원한다. 권한 철회 후 댓글/알림 조회도 거절한다. 외부 메시지를 발송하지 않는다.
- 통합 sync 한 요청에 업무·접속·알림·선택 업무 댓글을 반영한다. 활성 2.5초/숨김 30초, 즉각적 WebSocket 전송은 아니다.
- 독립 게스트 최대 5개의 고정 2시간 세션. [게스트 정책](guest-login-qa.md).

## 검증
- 자동 회귀와 타입·구문·의존성 경계·제품/배포용 로컬 빌드.
- 동일 시각 25개 기록의 두 페이지에서 중복·누락 없음, 특수문자 그대로 검색, 필터·잘못된 cursor 거절, 공간 권한 확인.
- 프로젝트 버전 충돌과 권한/길이 경계, 원본 변경 후 비교 스냅샷 보존, 승인 전 결과 미노출.
- 댓글 중복 키·길이·권한·철회·알림 대상·읽음 분리·완료 중복 방지.
- 실제 기기 내부 PostgreSQL TLS/HTTPS 5개 검사 통과: 서로 다른 앱 인스턴스의 설정 경합·댓글·알림·5명 게스트 수용 제한 포함. 시험 DB 이름과 loopback 주소를 검사하며 외부 DB를 사용하지 않는다. 시험 서버는 검증 후 종료했다.
- 제품 DB는 정상 종료 후 `.data/backups/pre-worktools-20261020-1040`에 비공개 복사하고 migration 008~010만 적용했다.

## 화면 검수 중 수정
프로젝트 조건을 여러 줄로 넣었을 때 앞줄의 기술 `DB`가 다음 줄 `제외:`에 붙어 제외 조건으로 오인되고, `1명,`의 쉼표 때문에 인원이 빠지는 문제를 실제 화면에서 발견했다. 규칙 버전 2.1에서 제외 조건은 줄별로 분석하고 인원 뒤 구두점을 허용했다. 전용 회귀 테스트를 추가했으며 이전 고정 답변은 보존한다.

자동 검사 101개와 기기 내부 PostgreSQL/TLS/HTTPS 5개가 모두 통과했다. 제품/배포용 빌드와 타입·구문·경계 검사를 통과했다. 화면 증거: [데스크톱](../product/evidence/work-tools/desktop.png), [비교](../product/evidence/work-tools/comparison.png), [모바일](../product/evidence/work-tools/mobile.png).

최종 브라우저 검증: 저장 설정과 세션의 재시작/새로고침 보존, 조건 분석 1명/무료/제외 정확성, 검색 결과 열기, 알림 모두 읽음, 원본 줄 비교, 댓글 재조회 확인. 모바일 390px/문서 390px로 가로 넘침이 없고 비교는 한 열로 배치된다. 최종 콘솔 경고/오류 0개. 제품 탭은 로컬 4180에서 계속 실행 중이다.
