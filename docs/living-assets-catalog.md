# 5인 생활·상호작용 에셋 · 공간 v9 / 활동 v11

나라·소라·준·민·레오 5명과 승인된 크림·오크·세이지 사무실을 유지한다. 원본 21클립×5명=105개를 보존하고 새 생활 동작은 절차적 제어로 연결한다. 외부 에셋·DB·AI·유료 서비스는 추가하지 않는다.

| 우선순위 | 구현 | 5명 기준 동작과 에셋 |
|---|---|---|
| P0 · 1 | 생활 변주 | 개인별 기울기·호흡·시선과 소파 3변주, 창가·기립 휴식. 양손 컵 사용에는 기존 도자기 바닥의 실제 오른손 지지점 5개/인물을 추가했다. 왼손이 컵을 소유하고 오른손은 마실 때만 바닥을 받친다. |
| P0 · 2 | 활동 재개 | 소파/창가/기립 휴식의 남은 시간과 커피 준비 의도를 기록한다. 업무로 중단하면 먼저 정리·복귀, 업무가 끝나면 안전한 시작 API로 다시 예약한다. 완성 전 커피는 안전한 준비 단계부터 재시작하며 이미 추출을 마친 커피는 다시 만들지 않는다. |
| P1 · 3 | 가변 모임 | 기존 2인/5인 회의를 유지하며 3인/4인 착석 회의와 2~5인 서서 대화를 추가했다. 전원 도착 뒤 발언을 시작하고 각자가 발언한 뒤 복귀한다. |
| P1 · 4 | 보드 검토 | 오크 지지대·세이지 테두리·보드 면·5개 검토 주제·트레이·마커. 한 명씩 보드에 접근하고 실제 길이의 팔/손가락으로 마커를 잡아 가리킨 뒤 반납·원래 위치 복귀, 다음 동료가 설명한다. 기존 문서 인계·회의 노트도 유지한다. |
| P1 · 5 | 이동 반응 | 근처 동료를 바라보고 작은 인사, 대기 중 반응. 소품 손·예약·경로는 유지하고 인사 사이 25초 휴지를 둔다. |
| P2 · 6 | 시나리오/카메라 | 집중/짧은 회의, 공동 검토, 커피/재충전의 세 흐름. 업무 우선·제한된 재시도·취소, 선택형 사건 추적 카메라와 직접 조작 우선을 제공한다. |
| P2 · 7 | 로컬 공동 관찰 | 공간별 한 송신자의 자세·부모 관계·손가락 인스턴스·종이 형상을 전달한다. 다른 접속은 독립 생활 스케줄러를 멈추고 같은 장면을 보간한다. 카메라·화질·개인 모션 축소는 각 화면에서 조절한다. |

## 보존 조건

- `studio-room-v8.glb`와 v10 `/demos/activities/ensemble/`은 원본 비교용으로 보존한다. 새 웹은 `/demos/activities/living/`이다.
- 공간 크기 13.2×10.2m, 5명, 고정 팔·다리 길이, 몸 중심 최소 0.44m, 통로 반경 0.5m와 동시 이동 최대 3명을 유지한다.
- 보드는 고정 장애물로 경로에 포함한다. 서서 모인 동안 다른 생활 이동을 시작하지 않으며, 각 접근은 다른 정지 자리도 피한다.
- 소품/회의/이동 중단은 예약·손 소유권을 회수한 뒤 끝난다. 중단된 다인 모임을 자동으로 다시 소집하지 않는다.
- 양손 컵은 들어 올린 컵에만 오른손을 대고 내리기 전에 회수한다. 손바닥 형상과 컵 바닥의 간격, 고정 손가락 길이와 단일 소유권을 검사한다.
- 보드의 새 주제 표시는 설명 진행 연출이다. 필기 인식·외부 문서 편집·자유 드로잉 기능은 포함하지 않는다.

## 공동 관찰 계약

- 공동 공간의 owner/member만 명시적으로 새 송신 주기를 시작하며 viewer는 읽기만 한다. 개인 공간은 기존 자율 생활을 사용한다.
- 접속별 비밀 제어 토큰은 해시로 저장하고 공개 응답에 넣지 않는다. 세션/공간 권한, 세대, 증가하는 순서 번호와 15초 제어권을 검사한다.
- 최대 약 4Hz로 전달하고 0.22초 동안 보간한다. 최신 프레임은 최대 64공간 메모리 캐시에 두고 DB 체크포인트는 5초 간격으로 저장한다. 프레임 이력을 쌓지 않는다.
- 송신 종료/로그아웃/권한 상실/만료 시 마지막 장면을 표시한다. 서버 급종료 시 최근 전달보다 최대 약 5초 앞선 저장 장면이 남을 수 있다. 새 송신자는 기존 소품/장면을 복원한 뒤 새 생활 주기를 시작한다.
- 모델/노드 명세 불일치, 순환 부모 관계, 유효하지 않은 수치, 과대한 데이터, 이전 순서의 프레임은 적용하지 않는다. 카메라나 서버 업무 시간은 프레임으로 덮어쓰지 않는다.
