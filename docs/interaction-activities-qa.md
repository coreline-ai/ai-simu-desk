기준 main `2f5a98c`의 **활동 v5 / 공간 모델 v6**. [개발 계획](../dev-plan/implement_20261021_111326.md)에 따라 나라 손동작 선행 → 5명 손동작 → 책상 방문 → 문서 전달 → 초대/응답 → 생활 흐름을 구현했다. 최종 통합 게이트를 통과해 로컬 제품 `/`의 기본 동작에도 적용했다.

## 구현과 비교

후보 `/demos/activities/interaction/?play=1`의 **v5 · 움직임과 교감** / **v6 · 손과 협업**으로 같은 구도·화질·조명·정지 상태에서 비교한다. 기존 `/demos/activities/expressive/` v5를 보존한다. 공간 모델 v6/105개 클립은 재제작하지 않았다.

## 업무·소유권 경계

서버/DB/AI 계약을 바꾸지 않았다. 실제 preparing/typing/reviewing/완료/인계는 기존 ViewModel에서 읽는다. 시각적 문서 전달은 실제 업무 승인·결과 인계나 AI 대화를 만들지 않는다.

생활 동작 중 업무가 도착하면 안전한 소품 정리와 복귀를 우선한다. 팔을 제어하는 동안 같은 팔의 새 역할 소품 동작을 시작하지 않으며, 호스트가 손을 거둔 후에는 방문자의 복귀를 기다리지 않고 업무 자세를 표시한다. 서버 완료·승인·저장 시각은 연출 종료까지 늦추지 않는다.

문서는 하나의 부모/소유자만 가진다. 수신과 반환 때 같은 메시를 attach해 세계 좌표를 유지한다. 취소 후 문서가 다른 책상에 있으면 해당 책상의 위치/소유권을 유지하며, 다른 활동을 시작하려고 원래 자리로 순간이동시키지 않는다. 공간 폐기에서는 임시 문서·손 메시/instance buffer·전용 잉크 재질을 회수한다.

## 발견과 보정

- 방문 정지점의 2차원/3차원 좌표 처리로 점유 셀이 비어 회의 복귀자와 겹친 사례를 재현했다. 세계 좌표를 통일하고 실제 셀 수/혼합 충돌 검사를 추가했다.
- 새 방문이 기존 회의 미참여자의 파트너를 가져가는 편중을 재현했다. 사용 가능한 미참여 동료의 기존 목적지 기회를 먼저 준다.
- 문서를 잡기 전 취소하고 곧바로 돌아서면서 팔 도달 범위를 넘는 사례를 보정했다. 손을 거두거나 안정된 휴대 자세를 만든 후 출발한다.
- 문서 수신 중 실제 업무가 오면 이미 손을 거둔 호스트의 팔이 수신자의 복귀 종료 때 다시 제어되는 사례를 보정했다. 각 해제 직후에만 해당 팔을 거두며, 같은 팔을 새 역할 소품과 공유하지 않는다.
- 취소 후 다른 자리에 놓인 문서 때문에 반복 시연이 기다리던 사례를 보정했다. 이용 가능한 문서가 없으면 화면 검토로 진행하며, 실제 업무는 시연 대기열을 해제한다.
- 고정 높이로 문서가 뜨던 것을 실제 GLB 표면 측정으로 보정했다. 펜/움직이는 문서 소품과 겹치지 않는 위치를 사용하고, 같은 자리에 모인 문서는 겹치지 않게 쌓아 맨 위부터 집는다.
- 손 근접/동료 확대 비교에서 카메라의 직교 투영 범위를 함께 저장·복원해 구도가 달라지지 않도록 보정했다.
- 768px에서 늘어난 비교 메뉴가 넘치는 것을 줄바꿈으로 보정했다.

## 검증 범위의 한계

손가락 패드 목표 오차는 관절 끝과 목표 접촉점의 거리다. 모든 피부 폴리곤의 비관통이나 물리적인 마찰/힘을 검증한 수치가 아니다. 근접 화면을 함께 검수하며, 전체 손가락/얼굴 스키닝·립싱크·정밀 물리는 추가하지 않았다.

실물 모바일의 터치/발열, 실제 OS의 모션 축소/백그라운드, GPU 메모리와 장시간 JS heap 누수는 미측정이다. Chrome 에뮬레이션·단기 강제 GC 비교와 renderer 자원 수를 그 대체값으로 완료 처리하지 않는다. 좁은 통로의 자유 교행/3명 이상 동시 보행/5인 착석 회의도 이번 범위가 아니다.
