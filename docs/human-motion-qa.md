# v11 자연스러운 팔·보행·개인별 동작 보정

## 원인과 보정

5명 실제 이동을 측정했을 때 책상 접촉용 IK가 빈손에도 매 프레임 적용되어, 자유 팔의 최종 도달 길이와 팔꿈치가 거의 같은 값(약 12.745도)으로 재계산됐다. 기존 개인차는 작은 진폭/주기와 기울기에 머물렀고 손바닥이 허벅지를 향하는 회내와 편한 손가락 모양도 부족했다.

공간 v9/활동 v11과 원본 GLB·105클립을 유지한다. 보행/팔·손·대화/휴식 보강은 기존 리그와 연속 손 메시를 사용하는 런타임 동작이다. 새 모션캡처나 실사 모델을 도입한 결과가 아니다.

- 실제 발의 앞뒤 차이로 반대쪽 팔을 흔들어 곡선 이동/도착 감속에서도 위상을 맞춘다. 발/골반 지지·경로·예약은 기존 제어가 맡는다.
- 가까운 가구를 벗어난 자유 팔은 책상 IK로 다시 묶지 않는다. 컵/문서/마커 소유 손, 소파/회의 테이블 지지 손과 가까운 책상 보정은 기존 접촉 솔버가 우선한다.
- 손바닥을 몸 쪽으로 돌리고 손목이 약하게 뒤따른다. 기존 손바닥/손가락 메시의 관절로 편한 굽힘을 만들며 지골 길이·소품 접촉 목표는 보존한다.
- 개인별 상체/시선 반응 사이에 휴지를 주고, 대화의 손짓·첫 휴식 동작을 구분한다. 업무/인증/DB 시간은 바꾸지 않는다.

| 인물 | 보행·대화 | 첫 휴식 |
|---|---|---|
| 나라 | 차분한 팔 흔들림·짧은 손짓 | 한 팔 기지개 |
| 소라 | 경쾌한 걸음·열린 양손 설명 | 옆구리 스트레칭 |
| 준 | 느긋한 걸음·작은 반응 | 어깨 풀기 |
| 민 | 곧은 자세·확인하는 끄덕임 | 손목 풀기 |
| 레오 | 여유로운 보행·넓은 설명 | 가슴 펴기 |

걸음 주기 0.84~1.00초, 장면 이동 속도 0.53~0.60m/s와 팔 각도는 이 스타일·리그에 맞춘 연출값이며 의학적 정상 범위가 아니다. 해당 보행의 자유 팔꿈치는 실제 검사에서 약 13~21도로 연속 변화했다. 운반 중에는 소품을 든 팔을 굽힌 상태로 유지하고 다른 팔만 자유롭게 움직인다.

## 근거

- [Yegian 등, 2019 · Straight arm walking, bent arm running](https://pubmed.ncbi.nlm.nih.gov/31289110/): 걷기와 달리기의 팔꿈치/에너지 실험을 참고했다. 보행에서 달리기처럼 팔을 크게 접는 연출을 기본으로 하지 않는다.
- [Mirelman 등, 2015 · Effects of Aging on Arm Swing during Gait](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0136043): 팔 교대 위상, 몸통 회전과 동작 조건의 관련성을 참고했다. 논문의 집단/연령 차이를 캐릭터의 성별·건강 상태로 적용하지 않는다.
- [Three.js Quaternion](https://threejs.org/docs/pages/Quaternion.html): 관절 회전 보간 API를 사용한다.

## 검증

증거: `product/evidence/human-motion/`.

- 관련 고유 자동 검사 **37개 최종 결과 통과**(`validated-tests.json`). 첫 37개 실행 중 접촉 전환 2개 문제가 있었고, 수정 후 영향 16개를 재실행해 모두 통과했다. 초기 실패 기록은 `history/`에 보존한다. 전체 프로젝트 359개를 새로 전부 실행했다고 주장하지 않는다.
- 5명 실제 이동의 팔/다리 반대 위상, 팔 길이·손가락 길이, 자유 손/운반 손 구분, 서로 다른 보행 주기/휴식, 정지/재생성/기존 v10을 검사했다. `baseline-arms.json`, `after-arms.json`에 비교 수치를 보존했다.
- 보드에 도착하기 직전의 이전 프레임 손을 사용하던 문제는 현재 자세 적용 뒤 시작점을 캡처해 수정했다. 컵을 다시 집을 때는 자유 팔에 작은 여유 굽힘을 두어 도달 범위를 넘지 않는다. 소품을 움직이거나 팔 길이를 늘려 수치를 맞추지 않았다.
- 실제 브라우저에서 기존/보강 v11, 5명 이동·대화·복귀, x1/x1.5/x2/x3, 일시정지, OS 동작 줄이기, 320~1440px·단일 canvas, v10 전환을 통과했다(`browser-controls.json`). 모델 로딩 중의 준비 상태를 기다리도록 QA 스크립트도 보정했다.
- 합성 계정 3개의 실제 공동 관찰에서 5명 자세와 손/컵, 늦은 입장, 정지, 제어권 전환·권한 하향·로그아웃을 통과했다(`shared-browser.json`). 현재 사용자 DB와 실제 계정은 QA에 사용하지 않았다.
- 보강한 손 모양은 기존 동적 손가락 인스턴스와 손 메시를 통해 그대로 공유되며 장면 노드/프로토콜/DB 마이그레이션을 추가하지 않는다.
- 타입·경계·시각 115모듈/안정화 50모듈 구문 검사를 통과했다. 같은 공간의 보정 전/후를 1280×900/DPR1·balanced·5초×3회 측정한 p95 중앙값은 약 16.8ms/16.7ms다(기본 장면 1,097 draw calls/773,350 triangles). 이는 대기 장면 측정이며 장시간/모바일 성능을 대신하지 않는다. 실제 4180 적용은 별도 `delivery.json`에 기록한다.

## 웹 비교

[5명 보행·대화](http://127.0.0.1:4180/demos/activities/living/?play=1&activity=walk)에서 `보강한 팔·걸음`과 `기존 v11 팔·걸음`을 비교한다. 전환은 같은 공간에서 활동을 초기화하고 5명 이동을 다시 시작하며 카메라·배속·화질·정지를 보존한다. 기존 v10도 별도 버튼으로 유지한다.

실물 iPhone XS Max는 기존 결정대로 연결 불가/미완료다. 발열·배터리·GPU 메모리·실제 음향 균형, 모션캡처 수준의 자연스러움은 이번 데스크톱 검사로 보장하지 않는다.

## 실제 로컬 적용

기존 서버를 정상 종료하고 사용자 DB를 비공개 백업한 뒤 4180에 적용했다. 서버 번들과 GLB 지문이 같으며 새 마이그레이션·계정/기록 초기화는 없다. 실제 앱 번들의 지문을 준비한 빌드와 대조하고, 5개 보강 프로파일·단일 canvas·공간 v9/활동 v11·x1.5 실제 보행과 시간 진행을 확인했다(`delivery.json`). 개발 계획/검수 문서의 마지막 상태를 담은 패키지는 이 실행 검증본과 코드/서버/에셋의 동일성을 다시 대조한다.
