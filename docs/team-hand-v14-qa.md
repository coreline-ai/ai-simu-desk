# 다섯 명 손 v14 확대 적용·검수

> 이 문서는 해당 구현 당시의 검수 기록입니다. 이후 사용자 요청으로 main 전달 문서/커밋을 준비했습니다. 최신 배포 인계는 [HANDOFF](../HANDOFF.md)와 [전달 검증](local-release-20261024.md)을 따릅니다.

2026-10-24. 사용자가 소라 손의 현재 품질을 기준으로 나머지 네 명에게 확대 요청했다. **사실적 손으로 다시 조형하거나 자연스러움 문제가 모두 해결되었다고 주장하지 않는다.**

## 적용 범위

- 기본 제품과 개인별 하루 데모 모두 `nara/sora/jun/min/leo`의 좌우 손에 소라 기준 v14 리그/피부를 설치한다.
- 나라·소라·민: 실제 펜 크기에 대한 삼점 필기. 기존 펜 경로·멈춤·시선·상체·왼손 표현을 유지한다.
- 준: 기존 짧은 입력→화면 읽기→짧은 수정의 타이밍을 유지하며 손가락별 curl을 새 관절로 옮긴다. 기존 검지 가리키기와 상대 확인을 보존한다.
- 준의 마우스 탐색/스크롤 cue에서 실제 `JunMouseShell` 삼각형 표면을 raycast하여 접촉한다. 손 접근/이탈은 블렌딩한다. 나머지 포즈는 기존 입력과 생각의 멈춤으로 돌아온다.
- 레오: 새 자유 손/왼손 표현과 기존 문서 정렬·읽기·분류 경로를 유지한다. 오른손 문서 소유 접촉은 소라의 컵 처리와 동일하게 **기존 v13 접촉 리그**로 명시적으로 전환한다.
- 컵·문서·안경·전달·공동 활동의 소유 접촉은 기존 v13 경로를 사용한다(`legacy-owned-contact`). 전원 v14 설치와 모든 활동의 v14 피부 사용은 다르다.
- 기존 v13 손 비교와 v11 활동/실패복구를 보존한다. v14 전체 프레임과 과거 소라만 v14인 프레임은 서로 다른 공유 스키마로 혼용을 거절한다.

## 검사 기준과 한계

- 펜: 엄지·검지·중지의 실제 후처리된 pad world 좌표를 도구 목표와 비교. 지지 약지/소지를 펜에 강제로 붙이지 않는다.
- 키: 실제 키캡 상면 내부와 pad 간 nominal4mm 피부 여유를 제외한 오차. 준의 검지/중지·좌우 입력 타이밍은 기존 presentation에서 가져온다.
- 마우스: 실제 렌더 메시 raycast 지점 +4mm 패드 중심(중지 스크롤 최대1mm 여유), 검지/중지 및 약지/소지 지지. 가상의 AABB 위 평면에 맞춘 것으로 대신하지 않는다.
- 컵/페이지/안경: 실제 기존 소유권·접촉 리그 유지 및 반납 회귀. 새로운 세 관절 그립으로 변경한 것으로 표시하지 않는다.
- 숫자는 pad/목표 및 제한된 캡슐 프록시 기준이다. 피부 전체의 연속 충돌/압축, 모든 카메라에서의 무관통, 의학적 정확성·모바일 FPS는 보장하지 않는다.

## 발견 후 수정

준의 기존 스크롤 의도 위치를 그대로 사용하면 실제 마우스와 검지77mm/중지61mm 간격이 있었다. 실제 마우스 표면을 연결해 수정했다. 고유 cue/phase와 원래 정지 시간은 그대로 두었다. 접근/이탈 구간과 안정 접촉 구간을 구분한다. 원인/근거/분류는 `dev-plan/implement_20261024_101511.md` OCC-006에 보존한다.

## 수치 검증

- 15개 업무 변형 모두 고유 cue 시퀀스와 2종 이상의 phase 유지. 시작→사용→반납 완료, 소품 소유권 desk 복귀 및 위반 없음.
- 나라·소라·민의 9개 필기 변형: 후처리 후 3개 패드 최대 오차 약0.159mm, 펜 끝/손목 목표1mm 미만.
- 준의 실제 입력: 대표 입력48샘플/보조 수정14샘플, 키캡 최대 오차 약0.664mm/0.652mm(고정30Hz 자동 회귀).
- 마우스 안정 접촉의 한 대표 시점: 검지/중지 약0.07mm, 약지0.06mm, 소지0.79mm 목표 오차. 전체 동작은 신규 회귀에서3mm 상한 확인.
- 5명 컵, 준 안경, 레오→나라 문서 전달, 실제 업무 선점 후 소품 반납, 정지 초기화, 공유 프레임/구버전 거절, 자원 해제를 자동 검사한다.

## 실제 화면 검수

원본 캡처와 툴 로그는 `.data/hand-v14-team-qa/` 및 `.data/hand-v14-team-*.log`에 보존한다. 생성 이미지나 보정 이미지를 증거로 사용하지 않는다. 아래는 최종 검수 후 이어 기록한다.

### 직접 확인한 화면

| 대상 | 확인 장면 / 원본 캡처 |
|---|---|
| 나라 | 대표 메모의 삼점 필기와 자유 왼손 (`nara-work-0.png`), 컵 (`nara-cup-verified.png`) |
| 소라 | S곡선 스케치 (`sora-work-0.png`), 컵 (`sora-cup-final.png`) |
| 준 | 교대 입력 (`jun-work-0.png`), 실제 마우스 (`jun-mouse-final.png`), 가리키기/상대 확인 (`jun-point-verified.png`), 컵 (`jun-cup-final.png`), 검지-안경 테 접촉 (`jun-glasses-verified.png`) |
| 민 | 항목 비교 중 펜 유지 (`min-work-0.png`), 컵 (`min-cup-final.png`) |
| 레오 | 문서를 든 채 긴 문장 읽기 (`leo-work-1.png`), 컵 (`leo-cup-final.png`) |

대표 필기·입력은 실제 연속 재생 중 정지해 관찰했다. 컵/안경과 재확인은 앱에 있는 **동작 정밀 관찰**의 구간 재생으로 동일 런타임을 고정60Hz 단계로 해당 시점까지 재생한 뒤 실제 WebGL 화면을 관찰했다. 15종 모두를 사람처럼 매 프레임 육안 검사했다는 의미는 아니다. 15종의 전체 시작/사용/반납과 cue·phase는 자동 회귀로 검사했다. 문서 전달은 자동 회귀로 확인했으며 별도 전달 순간 근접 화면은 이번 검수에 포함하지 않았다.

검수 중 중단된 캡처의 `jun-point-final.png`는 다른 장면이 기록되어 판정 근거에서 제외했다. `nara-cup-final.png`는 화면 갱신 중 부분 캡처라 `nara-cup-verified.png`로 재확인했다. 검수 근거는 위 표의 검증본을 사용한다.

5명 컵 사용 시점 모두 기존 접촉 리그 활성, pad 목표3mm 미만·손목 목표1mm 미만·owner=hand·위반 없음 확인. 준 안경은 adjust0.35초, 기존 검지 패드와 테 표면 목표 오차1mm 미만 확인. 실제 화면에서 컵/문서의 손은 여전히 단순한 주먹형 그립으로 보인다. 이는 사용자가 수용한 기존 접촉 경로이며 v14로 자연스러워졌다고 판정하지 않는다. 손목/손 크기와 일부 피부 겹침의 스타일상 어색함도 이번 확대에서 재조형하지 않았다.
