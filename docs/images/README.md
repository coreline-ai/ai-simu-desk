## 출처와 촬영 조건

- 앱 소스: `67962c17099e176d0f66fd24feaa2fc23678361e` (`main`).
- 실제 제품 빌드를 별도 loopback 서버에서 실행해 브라우저로 촬영했습니다.
- 기존 사용자 서버·DB를 사용하지 않고, 독립된 임시 PGlite DB와 임시 게스트 계정을 만들었습니다.
- 예시 요청: “지역 도서관 예약 서비스의 첫 화면 구성과 핵심 문구를 제안해 줘.”
- 실제 UI에서 5명 협업을 실행하고 답변 저장 완료 및 업무 기록 1개를 확인했습니다.
- 답변은 규칙 기반 Fake AI 결과입니다. 실제 LLM 호출·도서관 구축·외부 서비스 연동을 뜻하지 않습니다.
- 공개 호스팅 화면이 아니며, 계정명 `게스트 4eb4`는 촬영을 위해 생성한 임시 계정입니다.
- 브라우저 네이티브 영역 캡처만 사용했습니다. 합성·생성형 이미지·픽셀 수정·UI 스타일 변경은 하지 않았습니다.
- 전체 장면은 OS의 동작 줄이기 설정을 존중한 정지 프레임입니다. 정지 이미지로 애니메이션·모든 손가락 접촉의 품질을 증명하지 않습니다.
- 이미지는 문서용이며 동작 코드·설정·DB·비밀키는 포함하지 않습니다.
