# 5인 보강 에셋 명세 · P0–P2

나라·소라·준·민·레오, 공간 모델 v8 / 활동 v10 기준이다. 승인된 크림·오크·세이지 사무실과 5명의 정체성을 유지한다. 원본 기본 클립은 21개×5명=105개이며, 새로운 생활·소품 동작은 그 위에 절차적으로 연결한다.

## 품질 단계와 불변 조건

- 전체 보기와 근접 보기의 디테일을 구분한다. 동료를 가까이 보거나 확대하면 손톱·봉제·주름·파이핑 등을 표시한다. 낮은 화질은 전체 보기 수준으로 제한한다.
- 디테일 전환은 발·손·소품·좌면의 접촉이나 활동 진행을 바꾸지 않는다. 역할 소품과 표정은 전체 보기에서도 유지한다.
- 13.2×10.2m 공간을 유지하고 회의 가구의 간격과 접근만 조정했다. 회의 의자는 옆에서 접근한 뒤 앞에 정렬한다.
- 통로 정원은 신규 프로필에서 최대 3명이다. 기존 통로 반경 0.5m·격자 0.4m·인물 간 최소 0.44m를 줄이지 않았다. 실제 3명 동시 보행을 별도 검사한다. 기존 v9 이하의 정원은 2명이다.
- 효과음은 외부 파일/마이크/음성 대화를 사용하지 않는다. AudioContext는 한 뷰당 최대 1개, 동시에 합성되는 음은 최대 12개로 제한한다.
- 생활 연출은 각 브라우저의 시각 상태다. 실제 로그인·업무·승인·저장·댓글·협업의 서버 시간과 DB 계약은 유지한다.

## 실제 형상 접촉 보정 · revision 2

- 컵 손잡이 평면·5개 손가락 접점·손목 오프셋을 함께 정의해 손바닥과 도자기의 여유를 확보한다.
- 필기구를 집거나 반납할 때 손바닥을 들어 탁자·노트를 피하며, 필기 종료 후 노트 지지면으로 복귀한다.
- 회의 손 지지는 탁자와 실제 노트 윗면을 구분한다. 손을 무릎 쪽에서 먼저 올린 뒤 탁자 위에 놓고, 복귀는 반대로 정리한다.
- 별도 검수에서 실제 손바닥/엄지 받침 메시 정점과 탁자 부피를 확인한다. 손가락 접점 진단만으로 전체 메시 관통이 없다고 단정하지 않는다.
