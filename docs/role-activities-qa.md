# 역할 소품과 교감 · v4 로컬 검수

기준 main `49c276d`의 v3를 보존하고 [실행 계획](../dev-plan/implement_20261021_075508.md) Phase 1~5를 완료했다. 외부 DB/API, 새 운영 의존성, 서버 업무 계약은 바꾸지 않는다. 실제 장시간 검사와 로컬 기본 적용 게이트를 통과했다.

## 구현 범위

| 동료 | 실제 사용 소품/동작 | 확인점 |
|---|---|---|
| 나라 | 기존 노트·연필, 손 뻗기 → 잡기 → 기획 메모 → 놓기 → 복귀 | 나라 선행 후 확장, 손과 펜 끝의 지정 작업면 접촉 |
| 소라 | 기존 스타일러스·태블릿, 짧은 스케치 | 화면 작업점, 연필과 다른 소품 크기 |
| 준 | 기존 코드 모니터 방향 가리키기 | 손가락 방향과 화면 시선, 화면에 닿는 동작으로 표시하지 않음 |
| 민 | 기존 체크리스트·연필, 항목별 확인 | 지정 항목의 펜 접촉, 안경/얼굴 시선 |
| 레오 | 기존 문서 1장 집기·정렬·원위치 | 인스턴스의 기존 문서를 꺼내 사용하고 중복 표시 방지 |

필요한 고정 손모양을 한 번 만들고 사용 중에만 표시한다. 전체 손가락 리그·손가락 충돌 물리·실제 노트 데이터/잉크 저장은 범위 밖이다. 기존 v6 GLB/105개 클립을 재사용하는 절차적 동작이며 새 GLB 클립을 생성했다고 표시하지 않는다.

소파 대화는 두 사람이 모두 착석하고 실제 자세가 적용된 뒤 인사 → 응답 → 경청 → 확인 → 함께 쉬기로 진행한다. 양쪽의 응답 시간과 도착 제한을 확인하며, 업무/상대 종료 때 함께 정리한다. 먼저 복귀한 참가자도 짝 전체가 종료될 때까지 다른 활동에 배정하지 않는다. 빈손 작은 손짓이며 골반·좌면·발은 기존 제약을 유지한다.

눈동자가 먼저 움직이고 머리가 따라가며 소품/컵 → 상대 → 주변 순서로 목표를 고른다. 기존 Iris/EyeGlint/Brow/Smile 노드를 재사용한다. 한 모금 중 머리 회전은 제한하고 팔/펜/컵 접촉은 이후에 적용한다. 얼굴 노드의 작은 변주이며 립싱크/새 표정 리그가 아니다.

창가 정지점은 세계 좌표 `(x=0.4, z=-3.1)` 한 곳이다. 5명 경로를 1cm 간격으로 검사하고, 정지/회전점은 반경 0.34m로 가구·조명·식물·당겨진 의자를 확인했다. 서서 바깥 보기·작은 체중 이동·왕복과 중단을 포함한다. 소파 2명, 회의 2명, 창가 1명, 통로 전체 1명 제한을 유지한다.

## 상태·소유권과 반복

서버의 preparing/typing/reviewing을 읽어 역할 동작을 표시한다. 업무 완료·승인·인계나 저장 시각을 연출 때문에 늦추지 않는다. 새 업무가 오면 안전하게 소품을 정리하며 최신 상태로 돌아간다. 정지 시 활동 시계는 진행하지 않으며 재개 때 최신 업무를 따른다.

오른손이 업무 소품을, 기존 왼손이 컵을 소유한다. 동일 인물을 소품/컵/여행/짝 세션에 중복 배정하지 않는다. 종료·취소·공간 변경·폐기에서 손모양·소품·인스턴스·예약을 복원한다. 이동 중 런타임을 재생성할 때 소품은 이동한 인물이 아닌 원래 책상 기준점으로 배치한다.

새/기존 자율 선택기를 동시에 돌리면 기다리는 짝을 다른 활동이 계속 사용했다. v4는 기존 여행/응답/예약/정리를 재사용하면서 완료 횟수·휴지·seed를 하나의 선택기에 공유한다. 짝을 기다리는 동료는 대기할 수 있다. 새 소파 대화가 아직 없는 동료에게 기회를 주고 시도 횟수도 고려한다. 실제 업무가 반복 도착하면 대화를 취소하는 것이 정상이며 완료를 강제하지 않는다. v3 옵션의 선택기는 그대로 보존한다.

## 실제 시간 검사 프로토콜

10분 연속은 최종 v4에서 5명 시연과 자율 동작을 실제 600초 동안 실행한다. 장시간 검사는 실제 브라우저 시계로 재생하며 업무 ViewModel을 주입한다. 서버의 실제 로그인·5역할·인계·DB 저장은 별도의 제품 검사로 확인했다. 30분 혼합은 6분 자율 활동 → 20분 업무 도착 혼합 → 4분 자율 회복이다. 새 행동에 도달하는 가용 시간과 실제 업무에 안전하게 중단되는 시간을 모두 둔다. 90초 업무만 계속 주는 별도의 빠른 스트레스는 취소/복귀 안전성을 확인하며 모든 대화 완료를 요구하지 않는다.

30분 통과 기준은 5명 각각 역할 소품·소파 대화·창가·기존 소파/컵/회의/전신 휴식 및 typing/success 관측, 접촉 오류 0, canvas 1, 숨김/정지/재시작 0, 실제 시간의 97% 이상 활동 시계 진행이다. 종료 후 자동 활동을 끄고 정리해 모든 소품 desk·예약 {}까지 확인한다. 빠른 시뮬레이션을 실제 경과 검사로 대체하지 않는다.

## 한계와 후속

실물 모바일/터치·발열, 실제 OS의 모션 축소/백그라운드 동작, GPU·heap 메모리는 실측하지 않았다. Chrome 에뮬레이션과 소프트웨어 숨김 분기는 해당 범위로만 기록한다. renderer textures/geometries 수는 GPU/heap 누수 전체 검사의 대체값이 아니다.

통로 구간 예약·양보·최대 2인 이동은 Phase 6의 별도 P2다. 책상 방문, 전원 착석 회의, 다른 사람에게 소품 직접 전달하기, 전체 손가락/표정 리그는 추가하지 않았다.

로컬 비교: `/demos/activities/roles/?play=1`의 **기존 v3** / **v4 · 역할과 교감**. 동작 줄이기를 사용하면 자동 재생을 멈춘다. 로컬 기본 제품 `/`에도 v4를 적용했다. 기본 오류 복구는 v3 → v2 → 원본 v6 → v5 → v4 모델 순서다. 시작 화면 `/start`에서 새 비교 웹과 기존 체험으로 연결한다.
