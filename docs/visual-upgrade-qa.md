## 동작과 소유권

`product/src/scene-state.mjs`의 실제 업무 상태 → `AmbientScheduler` → 전신 포즈/이동 → 렌더/머리 위치 이름표 순서다. 시각적 복귀는 서버 업무 실행을 멈추지 않는다. 실행/승인/답변/권한/댓글/알림/게스트 상한 로직은 변경하지 않았다. 실제 시각 검수에서 소라가 기지개 중 업무 시작을 받아 복귀·착석 후 typing으로 전환하고 interruptions=1이 기록됐다 (`interrupt-live.json`).

- ActorRoot만 자리 기준 이동/yaw를 소유한다. 하위 RigRoot의 관절·의상 변형을 GLB에 저장한다. 보행 클립에 ActorRoot 이동을 중복 저장하지 않는다.
- 보행은 `.45m/s`, 1초 stride이며 디딤 중 발 위치를 고정한다. 관절 길이 `.37/.405m`, 바닥 침투 1cm, 디딤 미끄러짐 2cm 허용 기준을 자동 검사한다.
- 의자를 뒤로 빼고 옆 통로를 이용한다. 통로의 이동 소유자는 한 명이다. 대기 중 짧은 동작이 끝날 때까지 순번을 보존해 특정 동료의 휴식 누락을 막는다.
- 새 업무는 현재 위치를 보존하고 발 정리→회전→복귀→착석 후 작업 자세로 전환한다. 같은 snapshot은 시계를 초기화하지 않는다.
- 일시정지/동작 줄이기 정책은 몸과 루트 이동을 함께 정지한다. 숨김에서는 렌더·이동 진행을 멈춘다. 공간 전환/종료 시 예약과 이전 runtime을 해제한다.
- 완료/인계 cue는 중복 소비하지 않는다. 휴식 후 이미 소비한 완료 반응을 재생하지 않는다. 상체 상태 전환은 0.25초 보간한다.

## 에셋·재현·복구

원본은 `pilot-3d/sample/`의 기하/재질/전신·부분 스키닝/역할 키트/환경·포즈 소스다. `scripts/sample-textures.mjs`가 원본 PNG 5개를 생성하고 GLB bufferView에 포함한다. Three.js는 기존 설치 버전을 사용한다. 외부 에셋 다운로드가 없다.

`product/assets/manifest-v5.json`에 파일 크기·해시·actor/anchor·클립·실제 메시/삼각형 비용을 기록한다. 검수와 제품은 동일한 `studio-team-v5.glb`를 읽는다. 필수 클립/단위/anchor 누락은 실패 처리한다. TextureLoader로 내장 PNG를 읽으며 기존 CSP는 유지한다.

`production-view.mjs`는 실패 시 v5 장면/자원을 해제하고 원본 `studio-team-v4.glb`와 기존 렌더러를 함께 복구한다. 카메라·정지·업무 표시 상태를 전달하고, 미지원 생활 동작/조명 버튼을 비활성화한다. 늦은 load/status는 dispose/제품 scene epoch로 무효화한다. InstancedMesh 버퍼·공유 기하/재질/텍스처·skin bone texture·shadow map·이벤트/루프를 소유한 장면에서 정리한다.

## 성능과 예산

macOS 내장 브라우저, 1280×720 CSS viewport, 1149×608 canvas, 실제 DPR 1, balanced(1024 shadow), 같은 OrthographicCamera·낮 광원·ACES exposure 1.03·sRGB. 다른 제품 탭은 일시정지했다. 워밍업 후 30초씩 3회 프레임 간격을 측정한다. 브라우저의 약 75Hz 공급 한계가 있으므로 GPU 시간이 같다는 의미가 아니다.

| 장면 | p50 / p95, 1회 | 2회 | 3회 | 그림자 포함 비용 |
|---|---|---|---|---|
| v5 전체·생활 동작 | 13.30 / 13.60ms | 13.30 / 14.30ms | 13.30 / 13.60ms | 935 calls / 810,548 triangles |
| v4 전체·동일 조건 비교 | 13.30 / 14.30ms | 13.30 / 13.60ms | 13.30 / 14.30ms | 784 calls / 255,420 triangles |

v5는 초기 데스크톱 목표 p50≤20ms / p95≤33.3ms를 통과했다. 신규 GLB 약 6.6MiB, 앱 JS 약 .70MiB, 제품 fallback 이미지 약 2.15MiB로 주요 초기 자산 합계 약 9.5MiB(15MiB 이내). 원본 v4는 실패/명시적 비교 시 로드한다. 5×256² PNG RGBA+밉맵 추정 1.67MiB이며 shadow/render target·bone texture·geometry 비용은 별도다. balanced shadow는 color/depth를 4byte씩 잡으면 약 8MiB 추정이며 GPU 실측 메모리로 표현하지 않는다.

렌더러의 texture 개수는 전체 v5 28개, geometry 158개로 관측했다. texture 수에는 bone/shadow도 포함하므로 PNG 용량과 동일하지 않다. 모델 전환 중의 실제 자원 수와 폐기는 아래 안정성 기록으로 구분한다.

## 발견 이슈와 보정

1. 단순 기하 병합은 용량을 7MiB 이상으로 키웠다. 같은 형상의 인스턴싱으로 바꿔 삼각형/외형과 용량을 유지하며 호출을 줄였다. 자식이 있는 mesh는 통째로 제거하지 않는다.
2. 일부 동료의 짧은 동작 주기와 휴식 예약 시점이 겹쳐 소라가 계속 빠졌다. 순번을 유지하며 동작 종료를 기다리도록 수정했다.
3. 종료 cue를 가진 동료가 휴식 후 다시 완료 반응을 하는 문제를 수정했다. 소비된 cue와 경과 시간을 복귀 후에도 보존한다.
4. 자리마다 부모 좌표가 다르므로 접지 좌표를 자리 anchor에서 세계 좌표로 변환해 다리 IK에 전달했다. 원점만 시험하는 것으로 끝내지 않았다.
5. 정지 중에는 반복 렌더를 줄이되 카메라·광원 조작 시 한 번 그린다. 그래픽 조절은 업무/모션 시계를 초기화하지 않는다.

6. 강제 실패 검수에서 v4 로딩 초기의 null action을 검수 화면이 읽다가 오류를 내던 부분을 수정했다. 준비 전 상태도 안전하게 표시한 뒤 자동 복구를 다시 통과했다.

## 남은 한계

물리 모바일 기기 GPU/DPR 2 화면, OS 동작 줄이기 설정 변경과 실제 앱 백그라운드 절전은 미검증이다. 모바일 목표 p50≤33.3ms/p95≤50ms는 아직 실기기 통과로 표시하지 않는다. 스타일은 따뜻한 미니어처이며 사실적인 인체/모발·천 물리·개별 손가락 리깅·말하기는 포함하지 않는다. 회전은 단순화한 제자리 방향 전환이다. 고정된 검증 통로를 사용하며 임의 자유 이동/일반 길찾기 엔진은 없다.
