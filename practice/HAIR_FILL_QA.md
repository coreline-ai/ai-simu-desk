# 나라·소라·레오 머리 틈 보완 — 2026-10-24

## 적용

현재 practice 4198의 앞머리와 뒷머리 사이로 두피가 띠처럼 보이던 부분을 연결 면으로 메웠다. 나라의 단발, 소라의 포니테일, 레오의 낮은 번·가르마는 그대로다. 머리 자체를 다른 스타일로 교체하지 않는다.

- `src/assets/hair-fill.mjs`: 세 명의 Head에 연속 두피 메시를 추가한다. 기존 머리 재질을 공유해 색·조명 반응을 유지한다. 이마/눈썹/귀를 위한 헤어라인은 열어 둔다.
- 원본 노드의 위치·회전·크기·메시·재질·가시성을 변경하지 않는다. 민 보강본과 준은 그대로다. 손·IK·소품·개성·배속 코드도 변경하지 않는다.
- 메시 **각1개·736 triangles**, 합계 **3개·2,208 triangles**. 새 재질/텍스처/외부 다운로드/업데이트 루프/물리 없음. 기존 Head의 회전·이동을 상속한다.
- 해제 시 추가 geometry만 반납하며 공유한 원본 재질은 해제하지 않는다. 전체 세 명의 조건을 먼저 검사해 일부만 설치되는 오류를 막는다.
- 빌드 manifest의 practiceAssets에 세 식별자를 추가했다. canonical GLB와 대체 포스터는 그대로다. 이 변경은 practice의 실제 WebGL 화면에만 적용된다.

## 실제 화면

Ego Lite에서 세 명의 수정 전/후 확대, 정면·측면·뒷머리·저녁을 확인했다. 기존에 보이던 두피 띠가 닫히고 눈/눈썹·귀·단발/포니테일/번 실루엣이 유지됨을 확인했다.

각자 업무와 스트레칭을 2배에서 실행하여 **6회 모두 완료·원위치·소품 반납·예약 해제·violations=[]**를 확인했다. 작업/휴식 중 고개가 움직여도 연결 면이 따라간다. 실제 WebGL에서 동일 MotionClock/런타임을 제어된 wall-frame으로 전진한 검수이며 실시간 FPS/CPU/체감 배속 검사는 아니다. 대표 화면의 결함 확인이지 모든 프레임·모든 기기·모든 각도의 무관통 보장은 아니다. 의도한 이마/귀의 피부 노출은 머리 구멍으로 간주하지 않는다.

일반 주소에서 1배 자동 재생·balanced·손14·세 명 연결 면과 기존 민 에셋을 확인했다. WebGL 손실 시 캔버스 해제/대체 안내/장면 제어 비활성화, 새로고침 후 3D 재실행을 별도로 확인했다.
