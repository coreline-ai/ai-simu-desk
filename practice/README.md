# Simu Desk · 로컬 실습 화면

기존 **ai-simu-desk 저장소 안의 `practice/` 폴더**에서 실행하는 실습 화면입니다. 원본 앱과 같은 3D 소스를 사용하되, 별도 로컬 포트에서 실행합니다. 다른 웹사이트에 연결하지 않습니다.

## 바로 실행

기존 프로젝트 루트에서:

```sh
npm run build:practice
npm run serve:practice
```

화면: **http://127.0.0.1:4198/**

`practice/` 폴더 안에서도 `node build.mjs`, `node serve.mjs`로 실행할 수 있습니다. 의존성은 기존 루트의 것을 재사용합니다. 별도 설치·별도 저장소·로그인·DB 설정은 필요하지 않습니다. Node.js 22를 사용하세요. 서버를 끝내려면 실행한 터미널에서 Ctrl-C를 누릅니다. 로컬 서버는 `127.0.0.1`에만 바인딩하며 자동으로 외부에 공개하지 않습니다.

## 무엇을 할 수 있나요?

- 다섯 동료의 개별 업무 리듬과 사무실을 관찰합니다. 접속·새로고침 시 자동으로 움직입니다.
- 동료 선택, 전체/동료/손 카메라, 낮/저녁, 일시정지·재생을 사용할 수 있습니다.
- **0.5× · 1× · 1.5× · 2×**로 캐릭터 동작 속도를 바꿉니다. 속도 변경은 실습 결과 생성 시간이나 렌더링 품질을 바꾸지 않습니다.
- 동료에게 요청을 입력하면 분석 → 작성 → 확인 → 역할별 예시 결과가 이어집니다.
- 초기화하면 진행 중 작업과 입력·결과를 비웁니다.
- WebGL을 표시할 수 없으면 실제 사무실 이미지와 안내를 표시하며 2D 실습은 계속 사용할 수 있습니다.

**실제 생성형 AI가 아닌 규칙 기반 시뮬레이션**입니다. 입력·결과는 이 탭 메모리에만 있고 새로고침하면 사라집니다. 외부 AI 호출·서버 API·서버 저장은 하지 않습니다. 개인정보는 입력하지 마세요. 캐릭터 자율 동작과 예시 결과 생성은 별개입니다. 장면 일시정지는 3D에만 적용되며 예시 결과 생성은 계속됩니다.

## 장면 시나리오

기존 빠른 실행 3개(각자의 업무·선택 동료의 커피·자유로운 하루)를 유지합니다. 아래 카드를 업무/협업/휴식/하루 흐름으로 분류해 고를 수 있습니다.

| 분류 | 추가 장면 |
|---|---|
| 업무 | 선택 동료의 업무, 준의 안경 정돈 |
| 협업 | 둘이 소파에서 대화, 짧은 팀 회의, 함께 보드 검토, 동료에게 자료 전달 |
| 휴식 | 창가에서 생각 정리, 가벼운 스트레칭 |
| 하루 흐름 | 집중하는 오전, 함께 검토하는 오후, 커피와 재충전 |

대화와 자료 전달은 ‘함께할 상대’를 고릅니다. 회의는 선택 동료를 포함한 3명, 보드 검토는 5명, 안경 정돈은 준 전용입니다. 시작 당시 참가자를 고정하므로 실행 도중 선택을 바꿔도 현재 참가자가 바뀌지 않습니다.

- **다시 시작**: 마지막 선택 당시 동료/상대 그대로 재실행합니다.
- **중단 후 복귀**: 현재 동작·컵·문서·안경을 정리하고 원래 자리로 돌아옵니다.
- 다른 카드를 연속으로 누르면 복귀 후 **마지막으로 선택한 장면만** 시작합니다.
- 시나리오·배속 변경은 실습 입력과 결과를 지우지 않습니다.
- 일시정지 중에는 복귀도 멈춥니다. 다시 재생하면 이어집니다. 배속과 수동 정지는 새 시나리오에도 유지됩니다.
- 그룹 이동/커피 순환은 통로와 기기를 차례로 사용하므로 대기가 있을 수 있습니다. 순간이동·강제 소품 초기화로 대기를 없애지 않습니다.

새 장면 추가는 `src/scenarios.mjs`의 카탈로그와 허용된 기존 동작 연결부에서 합니다. UI별 타이머나 새 3D 렌더러를 만들지 않습니다. 연속 하루는 기존 ScenarioDirector를 재사용합니다.

## 품질과 리소스

사무실 v9, 캐릭터 개성 v13, 다섯 명의 손 v14를 그대로 사용합니다. 기반 GLB는 바이트 단위로 같습니다. **practice의 민 머리**는 짙은 곱슬머리 에셋으로 보강했습니다. 나라·소라·레오는 기존 헤어스타일을 유지하면서 앞머리–정수리 사이의 틈을 연결 면으로 채웁니다. 준·얼굴·안경·손·개성 동작은 유지합니다. 민 머리는 병합 메시 2개·7,940 triangles·텍스처 0개, 세 명의 연결 면은 각1개·736 triangles이며 고개를 그대로 따라갑니다. 간략화·품질 자동 하향·새 FPS 제한은 없습니다. balanced DPR/그림자와 기존 60Hz 동작·IK·접촉 코드를 재사용합니다.

화면은 브라우저에서 3D를 처리하므로 CPU/GPU를 사용합니다. 잠시 쉴 때는 일시정지를 누르세요. 현재 로컬에서는 정적 파일 제공용 Node 프로세스 하나를 사용하며, 별도의 AI 서버나 DB 프로세스를 추가하지 않습니다.

### 품질 유지 최적화

팔 접촉 계산의 불필요한 전신/손 반복 갱신과 키 위치 반복 변환, 변화 없는 시나리오 직렬화·주기적 진단을 줄였습니다. 손 정밀도·60Hz·개성·화질은 그대로입니다. 실패한 3D 상태 참조도 해제합니다. 동일 WebGL 업무 작업량 CPU 시간 중앙값 약13% 감소를 관찰했지만 표본 변동이 있으며 RAM 절감을 확인한 것은 아닙니다. 상세 수치와 한계는 [최적화 검수](OPTIMIZATION_QA.md)를 참고하세요.

## 실제 화면 검수 모드

일반 주소는 자동 RAF로 실행합니다. 로컬 전용 `?review=1`은 자동 RAF 대신 동일한 MotionClock/런타임을 고정 wall-frame으로 전진시켜 결과 포즈를 실제 WebGL로 렌더하는 검수 모드입니다. localhost에서만 검수 진입점을 제공합니다. 검사 마커·낮은 LOD·다른 손/소품 동작을 사용하지 않습니다. 이 모드의 캡처/소요 시간을 FPS·CPU·실시간 체감 속도로 해석하면 안 됩니다.

## 현재 범위

**웹 실행은 로컬 전용입니다.** 직전 main 인계는 2f9bd21입니다. 이후 세 명 머리 틈 보완과 품질 유지 최적화는 현재 로컬에만 적용했으며 아직 커밋·푸시하지 않았습니다. Git 소스 동기화는 사이트 배포와 별개이며 Hostinger 업로드·도메인/DNS 변경·다른 웹사이트 연결은 하지 않습니다. 실행·검수 결과와 과거 취소 작업은 DEPLOYMENT.md에 구분해 기록합니다.

검수 상세: [속도·시나리오](SCENARIO_QA.md), [민 머리 보강](MIN_HAIR_QA.md), [세 명 머리 틈 보완](HAIR_FILL_QA.md).
