## 개발 목적
배경·나라·가구를 같은 카메라·단위·광원에서 그리는 실제 3D 파일럿으로 크기·접지·애니메이션 전환과 웹 실행 가능성을 검증한다.

## 개발 범위
- `pilot-3d/`에 기존 2.5D와 독립된 로컬 미리보기 한 개. 사무실 한 곳, 나라 한 명, 책상·의자·노트북.
- 자체 절차형 형상을 실제 GLB로 내보내고 파일을 다시 읽어 렌더링한다. 원본 모델 생성 코드·치수·출처 기록을 포함한다.
- 휴식/타이핑은 GLB 노드 애니메이션 두 개로 표현한다. 기존 순수 업무 도메인을 재사용해 정상·승인·실패·취소와 연결한다.
- Three.js 렌더러와 GLTF 입출력, esbuild 번들만 추가하고 실제 버전을 잠근다. 런타임 CDN 의존성을 두지 않는다.

## 제외 범위
- 제품 서버·인증·DB·실제 AI·다중 사용자·공개 배포·준 모델·보행·고품질 인체 리깅.
- PNG의 자동 3D 변환과 사진 수준의 기존 이미지 재현. 대표 모델 검증을 위한 자체 스타일화 모델이다.
