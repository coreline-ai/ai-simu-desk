## 개발 목적
캐릭터 5명이 같은 사무실에서 협력하는 모습을 실제 웹에서 확인한다. 게스트 5명 제한과 캐릭터 수는 별개다.

## 개발 범위
- 기존 방 7.2×5.6m를 제품용 v3에서 9.6×7.6m로 확장하고 같은 실척 책상/의자/캐릭터 5개와 여유 동선을 배치한다.
- 나라(기획)·소라(디자인)·준(개발)·민(QA)·레오(정리)를 구분하고 5명 카메라/개별 초점/이름·역할·동작을 지원한다.
- 5명 협업 업무를 하나의 DB 실행으로 저장하고 각 단계가 앞 단계 산출물을 참고하는 규칙 기반 결과를 생성한다. 개별 업무도 5개 담당자를 지원한다.
- UI는 공동 작성·확인·인계 상태를 표현한다. 협업 시연 버튼으로 예제 업무를 실행하며 승인·취소·저장·새로고침을 유지한다.

## 제외 범위
외부 DB/실제 LLM/유료 업그레이드/공개 배포/게스트 제한 변경/걷기·스키닝·음성·다중 실제 AI 병렬 실행. 자동 커밋·푸시는 이번 요청에 포함하지 않는다.
