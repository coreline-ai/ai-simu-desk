## 개발 목적
다섯 동료가 동작 사이에서 자연스럽게 무게를 옮기고, 서로의 시선·손짓에 반응하며, 인물별로 다른 휴식과 대화 흐름을 보이도록 보강한다. 현재의 접촉·점유·업무 우선 정책을 유지하면서 움직임의 질과 활동 다양성을 함께 높인다.

## 개발 범위
- 나라 1명의 전환·접촉 선행 검수를 통과한 뒤 소라·준·민·레오로 확장한다.
- 기존 기지개·어깨/손목 풀기·소파·컵·회의의 연결과 변주를 보강한다.

## Phase 2. 5명별 휴식과 전신 변주 — P1
### 구현 태스크
- [x] 기존 기지개·어깨/손목 풀기를 준비→유지→마무리로 보강하고, 한 팔 뻗기·가벼운 등 펴기 등 식별 가능한 전신 변주를 추가한다. 컵을 든 손에는 적용하지 않는다.
- [x] 소파의 기존 기대기·몸 바로 세우기·주변 보기 변주를 전환 보정에 연결하고, 새 전신 휴식은 5명별 선호·진폭·휴지 길이로 구분한다. 무릎 위 손 IK를 유지하기 위해 새 큰 팔 동작은 기립 휴식에서 수행한다.
### 자체 테스트
- [x] 5명×각 변주를 전신/근접으로 비교해 의자·등받이·책상·조명과의 관통, 손/발 도달 한계, 동일 위상의 집단 반복을 검사한다.
- [x] 변주 시작/유지/종료에 업무를 주고 복귀·컵 소유권·좌석 정원이 유지되는지 확인한다.
### 이슈 및 수정

### 완료 조건
- [x] 각 인물이 최소 2가지의 구별 가능한 보강 변주를 수행하며 손이 점유된 상황에서는 안전한 대체 동작을 선택한다.

- [x] 고정된 발언 교대에 짧은 생각/멈춤·확인 끄덕임·눈맞춤/노트 보기 변화를 넣는다. 손짓은 준비와 마무리를 포함하고 컵 손을 안정화한다.
### 자체 테스트
- [x] 5명 각각의 손/입/컵 위치와 탁자 접근을 확인하고, 들기/한 모금/탁상 전환의 각 구간에서 업무 도착·취소·정지·큰 dt를 검사한다.
- [x] 컵은 한 사람당 1개, 소유권 전환은 접촉 시점 1회이며 회의 취소 후 각자 책상까지 회수하는지 확인한다.
### 이슈 및 수정
- 5명을 포함한 회의 조합의 양쪽 한 모금·탁상 소유권·전환 중 업무 도착 검사를 통과했다. 빈손이 탁자 아래로 들어가던 구간은 먼저 들어 올린 뒤 내미는 IK 경로로 수정하고 팔 구간 높이 검사를 추가했다. 실제 양쪽 한 모금 캡처와 업무 복귀·예약 반환·컵 5개 desk·오류 0을 확인했다.
### 완료 조건
- [x] 서로 다른 컵/발언 행동의 2인 회의가 이어지고 중단 후 소품과 좌석이 정상 정리된다.

## Phase 4. 상호 응답과 공동 확인 — P1
### 구현 태스크
- [x] 기존 회의 위치와 공유 노트 소품으로 나라·준의 인사→상대 응답, 함께 노트 보기→설명→확인→복귀를 선행 구현한 뒤 가능한 5명 조합으로 확장한다.
- [x] 참가자의 준비/응답을 확인한 뒤 다음 구간으로 진행하고 시간 제한·거절·업무 도착·상대 제거 시 양쪽을 정리한다. 이미 컵/소파/다른 회의에 참가한 사람은 중복 배정하지 않는다.
- [x] 제품의 공개된 업무 인계 요약을 쓰는 경우 시각적 공동 확인으로 표시한다. 실제 서버 인계 완료 시각이나 승인 상태를 새 연출에 맞춰 바꾸지 않는다.
### 자체 테스트
- [x] 먼저 도착한 사람·늦은 상대·상대 취소·동시 업무·반복 cue·공간 이동에서 혼자 인사를 계속하거나 무한 대기하지 않는지 확인한다.
- [x] 동일한 인사/확인 이벤트의 중복 실행과 참가자 중복 점유를 막고, 비참가자 업무·실제 5역할/4회 인계를 유지한다.
### 이슈 및 수정
- 준비된 두 참가자의 자세 적용 시간을 확인한 뒤 greet/respond/note/explain/confirm을 진행한다. 11개 조합, 상대 누락·업무 도착·응답 시간 초과·중복 cue 검사를 통과했다. 실제 공동 노트 캡처와 전 단계 완료·예약 반환·오류 0을 확인했다. 서버 인계 내용/완료 시각을 바꾸지 않는 로컬 연출이다.
### 완료 조건
- [x] 두 사람이 상대의 행동에 응답하고, 상대가 없어져도 안전하게 종료하는 짧은 상호작용을 재현한다.

## Phase 5. 반복·대기·자율 활동 리듬 — P1
### 구현 태스크
- [x] 인물 ID 기반의 재현 가능한 선택으로 직전 동작 반복·같은 순간의 큰 손짓을 줄이고 활동 사이에 휴지 구간을 둔다. 실제 참가 가능 여부와 완료 횟수 기반 공정성을 유지한다.
- [x] 통로/좌석 대기 중 작은 시선·호흡·자세 변화만 허용한다. 컵 손·발 접촉을 지키고 대기 상태를 실제 업무 중으로 표시하지 않는다.
### 자체 테스트
- [x] 같은 seed/입력의 재현성, 각 인물의 활동 도달, 특정 동료의 장기 누락·동기화된 반복·무의미한 즉시 재시도를 확인한다.
- [x] 정지 중 선택/예약이 진행되지 않고, 반복 cue·업무 연속 도착에도 큐·이벤트 이력이 계속 늘어나지 않는지 검사한다.
### 이슈 및 수정
- ID/seed 기반 휴지·주기와 cooldown 사이의 짧은 전신 휴식을 추가했다. 신규 12개·30분 상당 빠른 혼합 시뮬레이션에서 5명 각각 휴식 4~7회·공동 확인 1~2회·각 2변주를 확인했다. 회의 조기 복귀자가 상대 복귀 중 새 활동을 받는 충돌을 재현해, 세션 전체 종료까지 참가자를 배정에서 제외하고 회귀 검사를 추가했다. 나라 선행 모드의 회의 짝 중 적용 대상이 아닌 동료에게 공동 확인을 시도하며 재시도하지 못하던 예외도 수정했다. 수정 전후 5명 혼합 결과가 byte 단위로 동일하고 나라 선행 모드 회귀도 통과했다. 실제 경과 검사는 Phase 6에서 별도로 진행한다.
### 완료 조건
- [x] 5명이 다른 리듬으로 활동하며 중단된 인물도 후속 시도 기회를 얻는다.

## Phase 6. 통합 검수·제품 적용 — P0 게이트
### 구현 태스크
- [x] 기존 비교 페이지에서 현행 활동과 후보를 구분해 같은 카메라·조명·화질·정지 상태로 전환한다. 기본 제품은 후보 검수 통과 전까지 현행을 유지한다.
- [x] 후보 동작/기준점 실패는 현행 활동으로, 그 실패는 원본 v6→v5→v4로 복구한다. 화면 폐기 시 양쪽 참가·컵·예약·이벤트를 정리한다.
### 자체 테스트
- [x] 기존 169개와 신규 전환·접촉·상호 응답·취소·편중 검사를 통과하고 타입/구문/경계/빌드, 실제 5역할/4회 인계·저장·공간 이동·회의 중 로그아웃을 확인한다.
- [x] 최종 동작 설정으로 실제 10분 연속/30분 업무 혼합을 재실행한다. 5명 전원의 활동·반응·중단·정리와 10회 재로딩/20회 화질·시간대 전환의 단일 canvas·자원 안정성을 기록한다. 빠른 시뮬레이션으로 실제 시간을 대체하지 않는다.
- [x] 같은 조건 30초×3회에서 p50≤20ms/p95≤33.3ms, 호출·삼각형은 현행 활동의 같은 측정 대비 각각 +10% 이내, 필수 초기 자산 15MiB 이내를 관리선으로 검수한다.
- [x] 320~1440px·키보드·정지·모션 축소 정책·숨김 복귀 코드를 확인한다. 실제 OS 백그라운드/설정·실물 DPR 2/터치/발열·GPU/heap은 접근 가능한 환경에서 측정하고 나머지는 미검증으로 기록한다.
### 이슈 및 수정
- 전체 자동 181개, 타입/58개 모듈 구문/경계/제품 빌드 통과. 실제 비교·10회 재로딩(48 textures/194 geometries)·20회 전환·후보→현행 활동 복구·WebGL 복원·320~1440px 가로 넘침 0·키보드/모션 축소 에뮬레이션 통과. 실제 10분 연속(601초/활동 599초) 및 동일 조건 30초×3회 교대 비교(p50 16.7ms/p95 최대 16.8ms) 통과. 호출/삼각형 관측 최댓값은 현행/후보 동일했다. 실제 30분 혼합(1,800초/활동 1,799초)도 통과했다. 5명 모두 각 2개 휴식 변주·공동 확인·업무 중단·복귀를 관찰했고 오류/숨김/정지/재시작 0, 최대 자원 48/199다. 초기 GLB+JS+PNG+CSS+HTML 10.35MiB 통과 후 로컬 제품 기본에 적용했다. 최종 기본 경로에서 별도 주입 없는 새 게스트 접속, 5명 전원 실제 업무 중단·복귀, 4회 인계, 저장·재조회, 로그아웃 canvas 0·JS 오류 0을 재확인했다.
### 완료 조건
- [x] 동작·업무·성능·복구를 통과한 후보만 로컬 제품에 적용하고 전후 캡처·비교 웹·QA 기록을 제공한다.

## QA 관점
- [x] 루트/발/좌석/손의 보간과 접촉 보정의 순서가 충돌하지 않는지 검토한다.
- [x] 얼굴·시선 보정이 컵 손·입 위치를 벗어나게 하거나 상대를 잃었을 때 머리를 급회전시키지 않는지 검사한다.
- [x] 참가자 상태 전환·취소·반복 cue가 양쪽에서 정확히 한 번 처리되는지 검사한다.
- [x] ‘업무 복귀’ 연출 때문에 실제 업무가 지연되거나 과거 인계가 현재 진행 중으로 잘못 표시되지 않는지 검사한다.
- [x] 후보 옵션을 끄면 현행 활동이 보존되고 실패/재로드/공간 이동에서 후보 자원이 남지 않는지 확인한다.
- [x] 몸 루트 사이 거리뿐 아니라 새 팔 동작·가구 접촉도 확인한다. 기존 0.44m 몸 거리 검사만으로 전신 충돌이 없다고 결론 내리지 않는다.

## P2 후속 후보와 보류 조건
- 통로 구간별 예약과 양보: 두 경로의 몸·팔·후퇴한 의자가 겹치지 않는 경우에만 최대 2명 동시 이동을 선행 검수한다. 실패하면 현행 통로 1인을 유지한다.
- 창가 짧은 휴식·책상 방문 검토: 목적지/접근/서 있는 공간과 복귀 경로를 확보한 뒤 별도 계획으로 진행한다.
- 전원 착석 회의: 테이블·의자 5개·접근/이탈 공간이 들어가는 배치 검증이 선행돼야 한다. 현 공간에 바로 추가한다고 약속하지 않는다.
- 손가락/표정/추가 소품 리깅: 컵 잡는 고정 손과 현재 눈 노드로 부족한 장면을 먼저 특정한 뒤 에셋 계약·용량·제작 범위를 정한다.
