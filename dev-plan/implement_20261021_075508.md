## 개발 목적
다섯 동료가 실제로 소품을 사용하고, 함께 쉬며, 상대와 상황에 맞춰 반응하도록 행동의 종류를 늘린다. 이미 완료한 전환·접촉·업무 복귀를 기반으로 새로운 장면을 만들고, 기존 동작을 새 기능처럼 다시 제안하지 않는다.

## 개발 범위
- 1차: 손·소품을 연결한 역할별 업무 동작, 소파 2인 상호작용, 눈동자·표정·시선, 창가 휴식 1곳의 공간 선행 검증과 비교 검수.
- 나라 선행 검증 후 5명으로 확장한다. 2인 행동은 나라·준 선행 후 가능한 짝으로 확장한다.
- 기존 노트·연필·스타일러스·체크리스트·문서를 재사용한다. 필요한 손모양과 접촉 기준점만 보강한다.
- 2차 P2: 통로 구간별 예약·양보·최대 2인 이동의 선행 검증. 검증 전 기본 통로 정원은 1인이다.

## Phase 4. 창가 1곳 선행 검증과 짧은 휴식 — P1 조건부
### 구현 태스크
- [x] 창가의 서 있는 지점·정지/회전·접근/복귀 공간을 기존 소파·조명·식물·당겨진 의자와 함께 먼저 검사한다. 확보 전에는 자율 목적지에 추가하지 않는다.
- [x] 유효한 경우 나라 왕복→서서 바깥 보기/작은 체중 이동→업무 복귀를 구현한 뒤 5명 접근 경로로 확장한다. 목적지는 1인 예약, 통로도 기존 1인을 유지한다.
### 자체 테스트와 완료 조건
- [x] 5명 출발점에서 새 경로·경계·회전 중 발·팔 여유, 창밖 보기와 기존 대화의 시선 충돌을 확인한다.
- [x] 접근/대기/휴식/복귀 도중 업무·취소·정지를 검사한다. 공간을 확보하지 못하면 해당 기능을 보류하고 완료로 표시하지 않는다.
### 이슈 및 수정
- 완료: 세계 좌표 (0.4, -3.1)의 창가 정지점 1곳. 기존 경로에서 분기하며 5명 경로 1cm 샘플, 정지/회전 반경 0.34m와 기존 가구·식물·당겨진 의자를 검사했다. 5명 왕복, 대기/접근/회전/휴식/복귀 중 업무·예약 회수를 통과했다. 가구 추가·이동 없이 창가 1명/통로 1명을 유지한다.

## Phase 5. 맥락별 시연·비교·통합 검수 — P0 적용 게이트
### 구현 태스크
- [x] 새 업무 행동은 실제 준비/작성/검토 상태와 연결하고, 휴식/짝 대화는 참가 가능한 때만 선택한다. 기존 seed·휴지·공정성을 확장하며 새 행동의 이력은 유한하게 유지한다.
- [x] v3와 후보를 같은 구도·화질·조명·정지 상태로 비교한다. 검수 버튼은 비교 페이지에 두고 실패 시 v3→v2→v6/v5/v4 복구를 검증한다.
### 자체 테스트와 완료 조건
- [x] 기존 181개와 새 소품·소파 짝·시선·조건부 목적지 검사를 통과하고 구문/타입/경계/빌드, 실제 5역할·4회 인계·저장·공간 이동·소품 사용 중 로그아웃을 확인한다.
- [x] 최종 설정으로 실제 10분/30분을 새로 실행한다. 각 인물의 새 역할 행동과 새 짝 반응·중단/정리 도달을 기록하고 빠른 시뮬레이션과 구분한다.
- [x] 10회 재로딩·20회 화질/조명 전환, 320~1440px·키보드·모션 축소·숨김 복귀를 검사한다. 실물/OS/GPU·heap은 가능한 것만 측정하고 나머지는 명시한다.
- [x] 같은 환경 30초×3회에서 p50≤20ms/p95≤33.3ms, 관측 호출/삼각형은 v3 대비 각각 +10% 이내, 초기 필수 자산 15MiB 이내를 확인한다. 필기·소파 대화 등 새 동작의 부하 구간도 따로 관찰한다.
- [x] 통과한 기능만 로컬 기본에 적용하고 비교 웹·전후 캡처·QA 기록을 제공해야 완료다.
### 이슈 및 수정
- 완료: 전체 190개(기존 181+신규 9) 통과. 실제 앱의 5역할/4인계·저장 재조회·공간 전환·소품 사용 중 로그아웃 통과. 모바일 비교 메뉴 가로 넘침을 2열 배치로 수정하고 반응형·입력·재로딩·복구 검사 통과. 새/기존 자율 선택기를 중복 실행하며 짝이 밀리던 문제를 공통 완료 횟수·휴지 기반 선택과 상대 대기로 통합했다. 전체 자동 검사와 동일 조건 30초×3회 성능·모델/런타임 복구 통과. 실제 10분 실행(601초/활동599초)·종료 후 전원 책상/소품/예약 회수 통과. 실제 30분(검사 1800초/활동 1799초), 종료 후 전원 책상/소품/예약 회수와 기본 제품 v4 적용·실제 업무 검사를 통과했다. 제품 초기 자산 10.35MiB, JS 오류 0.
- 실제 30분 프로토콜: 6분 자율 활동(5명 새 행동 도달) → 20분 업무 도착 혼합(안전 중단) → 4분 자율 회복. 90초마다 업무를 도착시키는 별도 빠른 스트레스에서는 업무 우선 취소를 검증하며 모든 짝의 대화 완료를 강제하지 않는다.

## Phase 6. 구간별 예약·양보·최대 2인 이동 — P2 2차
### 구현 태스크
- [ ] 1차 완료 후 기존 고정 경로의 겹침/독립 구간과 실제로 설 수 있는 대기 지점을 도식화한다. 독립 구간에서만 최대 2명, 교차/협소 구간에서는 1명을 후보 정책으로 검토한다.
- [ ] 나라·준 2명 선행으로 구간 진입 전 획득·안전 대기·복귀 우선·취소 해제를 검증한다. 몸/팔/컵·의자 여유와 정지 거리가 부족하면 기존 전체 통로 1인으로 유지한다.
### 자체 테스트와 완료 조건
- [ ] 마주 오기·같은 방향·교차점 도착·양쪽 업무·정지·상대 취소에서 충돌·교착·굶주림을 검사한다. 몸 중심 0.44m 검사만으로 통과시키지 않는다.
- [ ] 5명 혼합과 기존 소파/회의/창가를 묶어 재검수한 후보만 확장한다. 실패하면 P2 보류를 기록하고 1차 기능은 기존 통로 정책으로 유지한다.
### 이슈 및 수정
- 미착수. 현재 공간에서 두 사람이 안전하게 교행할 수 있다고 가정하지 않는다. 책상 방문·전원 회의는 이 단계의 완료 범위에도 포함하지 않는다.

## QA 관점
- [x] 컵·펜·일반 손짓의 제어 충돌과 소품 단일 소유권·정확히 한 번의 부착/분리를 검토한다.
- [x] 팔·손·소품의 부피와 의자/탁자/옆 사람을 확인하며 몸 중심 거리만으로 전신 안전을 판정하지 않는다.
- [x] 선행 표정/시선이 컵 입 위치·필기 면·좌면/발 접촉을 깨뜨리지 않는지 검토한다.
- [x] 먼저 도착한 참가자·상대 취소·조기 복귀자를 다른 활동이 재사용하며 세션이 남지 않는지 검사한다.
- [x] 새 행동이 실제 업무 완료/승인/인계 시각을 바꾸거나 과거 결과를 현재 행동으로 재생하지 않는지 확인한다.
- [x] 공간 조건을 통과하지 못한 목적지·동시 이동을 구현 완료로 표시하지 않고, 최종 제품의 검증 범위를 정확히 기록한다.
