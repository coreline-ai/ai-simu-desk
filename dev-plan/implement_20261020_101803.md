## 개발 목적
무료 배포 제약에 맞는 공통 실행 경로와 팀 업무 도구, 최대 5명의 독립 게스트 체험을 로컬에서 구현·검증한다.

## 개발 범위
DB 연결 주소가 있으면 로컬/배포 모두 PostgreSQL 어댑터를 사용한다. 연결 전에는 기존 PGlite 데이터를 유지하되 요청 기반 실행/DB presence/SQL 마이그레이션은 동일하게 사용한다. 템플릿·프로젝트 설정, 검색·원본 비교, 댓글·앱 내 알림, 5명 게스트를 순서대로 추가한다.

## 제외 범위
유료 업그레이드·결제, 미승인 외부 DB 연결, 실제 LLM·메일 발송, 공개 배포, 기존 DB 자동 업로드, 무제한 무료 보장.

## 결정 및 확인 사항
- 사용자: 업그레이드 금지, 무료 환경에 맞춘 로컬 개발 우선.
- 현재 DATABASE_URL·프로젝트 연결 없음. Vercel 자체 Postgres 신규 제공은 종료됨. 사용자 답변: 외부 제공 DB 금지, 로컬 개발만. 외부 연결·실배포를 수행하지 않는다. 클라우드 연결 검증은 미완료로 구분한다.

## 검증 결과 기록
- 자동 회귀 101개, 실제 기기 내부 PostgreSQL/TLS/HTTPS 통합 5개 통과. 타입·구문·경계·공백 검사 및 제품/배포용 로컬 빌드 통과.
- PG 반복 시험에서 이전 실행의 동일 시험 IP 요청 카운터가 합쳐진 문제를 시험별 IP 분리/세션 정리로 해결했다. 실제 제한 거절 코드를 GUEST_FULL로 확인한다.
- 화면에서 인원 뒤 쉼표/프로젝트 조건 줄 경계 해석 오류를 발견해 Fake AI 규칙 2.1로 수정하고 전용 회귀를 추가했다. 기존 고정 결과는 유지한다.
- 로컬 제품은 기존 PGlite DB에 migration 008~010 적용. 이전 공용 계정의 공유 세션 종료, 계정/업무/비공개 백업 보존. 새 방문자에게 과거 공간을 재할당하지 않는다.
- 프로젝트 설정 저장→템플릿/조건 적용→업무 완료→댓글→3줄 수정→원본 비교→전체 검색→알림 읽음을 실제 브라우저에서 확인했다.
- 외부 제공 DB 금지 결정에 따라 클라우드 DB 연결/실배포는 범위에서 제외했다. 물리 DB 연결 완료를 가장하지 않는다.

- 390px 모바일에서 페이지 너비 390px로 가로 넘침 없음, 비교 영역 한 열·내부 스크롤, 댓글과 검색 정상 표시. 최종 새로고침 후 브라우저 경고/오류 0개. 데스크톱/모바일/비교 PNG를 product/evidence/work-tools에 보존하고 로컬 제품 탭을 표시했다.
