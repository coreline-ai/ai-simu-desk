# implement_20261020_141148.md

작성 일시: `2026-10-20 14:11:48 KST`

현재 v5의 잔여 항목을 정리하고, 사무실 공간의 시각 품질을 개선하기 위한 후속 제안이다. 초안 작성 후 사용자가 순차 로컬 구현·검증과 v5 비교 웹을 요청하여 본 계획을 실행한다. 기준 커밋은 main의 `e8ea38b`다.

## 개발 목적
9.6×7.6m 사무실의 채광·재질·창밖 깊이·구역별 구성을 보강한다. 따뜻한 미니어처 스타일과 다섯 명의 식별성을 유지하면서 공간의 깊이와 사용감을 높인다.

## 개발 범위
- 기존 v5 잔여 검증, 이미 완료한 생활 동작, 보류한 기능을 구분한다.
- 창가 한 구역에서 빛·접촉 음영·재질을 선행 비교한 후 전체 사무실에 적용한다.
- 작업/휴게/회의 구역, 창밖 환경, 책상·소파·책장의 마감과 역할별 소품 표현을 보강한다.
- 기존 actor ID·105개 클립·이동/복귀 정책을 유지하고 카메라 가림·가독성과 성능을 함께 검증한다.
- 비교 후보는 별도 `studio-room-v6.glb`/manifest로 생성한다. schemaVersion 5의 관절/좌표 계약을 유지하고 modelVersion/환경 버전을 별도로 기록한다. 제품 기본 교체는 최종 게이트 통과 후 진행한다.

## 제외 범위
외부 DB/API/모델 서비스·유료 에셋·공개 배포, 새 AI 기능/결과 보드/DB 변경은 포함하지 않는다. 소파 착석·컵 집기·회의를 위한 새 경로/동작, 손가락 리깅·천/머리카락 물리는 별도 후보로 남긴다. 로컬 구현·검증 완료 후 후속 사용자 요청으로 main 커밋·푸시를 범위에 추가했다. 외부 배포는 포함하지 않는다.

## 현재 화면에서 확인한 개선 지점
- 창밖은 얇은 반복 수관 실루엣이고 모든 창의 배경 구성이 유사하다. 근·중·원경과 낮/저녁 배경 연동 여지가 있다.
- 낮/저녁은 광원 색/세기 변경 중심이다. 창밖 sky 재질의 발광은 별도 고정값이며, 실내 실용 조명과 연동되지 않는다.
- 목재/천/바닥은 256² 절차 색 맵과 공통 roughness 맵 중심이다. 재질별 normal/roughness 세부 표현을 분리할 수 있다.
- 작업 자리 5개는 명확하지만 바닥·벽의 넓은 면이 균일하다. 작업/휴게/회의 구역의 구성과 시선 유도가 약하다.
- 소품/화면은 정적 형상과 선 표현 중심이다. 물건 수보다 마감·간격·역할 식별·표시 정보의 명확성을 개선한다.
- 현재 그림자 포함 전체 비용은 935 calls/810,548 triangles다. 데스크톱 프레임 목표 통과만으로 추가 비용의 여유나 모바일 성능을 보장하지 않는다.

## 품질·성능 게이트
- 형상/실루엣·재질/UV·빛/접촉·관절 연결·배치/식별의 내부 시각 판정 5항목 각각 4/5 이상, 관통/분리/필수 맵 누락 0. 주관적 판정임을 명시한다.
- 기존 데스크톱 목표 p50≤20ms/p95≤33.3ms, 초기 주요 자산 15MiB 이내를 유지한다. 공간용 신규 텍스처 RGBA+밉맵 추정 추가분은 16MiB 이내를 초기 상한으로 제안한다. 모델 교체 중 중복 상주와 shadow/geometry/skin은 별도 집계한다.
- 호출/삼각형은 동일 구도에서 v5 대비 각각 10% 이내 증가를 초기 관리선으로 제안한다. 넘으면 공유/인스턴싱·보이지 않는 세부 단순화를 먼저 적용하고 실측 근거와 함께 재판정한다.
- 실제 GPU 시간/메모리가 관측되지 않으면 브라우저 프레임 간격/자원 수/텍스처 추정치로 명확하게 구분한다.

## 첫 실행과 확장 기록
Phase 1의 **창가·소파·나라 자리 한 구역**을 먼저 비교·검증한 후 공통 재질→공간 구획→창밖/시간대→작업 표현으로 확장했다. Phase 6의 실제 장시간 검수까지 완료하고 v6를 로컬 제품 기본값으로 적용했다. 기존 v5 원본 파일/비교 화면을 보존하고 미검증 실기기 항목은 분리해 기록했다.
