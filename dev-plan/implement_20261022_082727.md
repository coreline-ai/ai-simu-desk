# implement_20261022_082727.md

작성 일시: `2026-10-22 08:27:27 KST`

## 개발 목적

사용자가 첨부해 확정한 크림·오크·세이지 사무실을 실제 회전·확대 가능한 3D 공간으로 구현하고 5명 공통 동작 배속 x1/x1.5/x2/x3을 제공한다. 기준 main은 `ea13047`이다. 콘셉트 이미지를 바닥 배경으로 대체하지 않는다.

## 개발 범위

- 13.2×10.2m(기존 9.6×7.6m 대비 면적 약 1.85배)의 신규 공간 v7. 창가에 앞을 보는 작업 자리 5개, 왼쪽 회의·오른쪽 라운지·커피 바·낮은 수납.
- 현대적인 모니터/책상·의자·소파·회의 가구, 표면·채광·접촉 그림자와 실제 카메라 프레이밍.
- 기존 5명과 105개 클립·역할 소품·컵·방문/전달·소파 대화·창가·업무 복귀를 새 공간의 실제 기준점에 연결한 활동 v9.
- 5명 공통 시각 동작 배속. 정지·모션 축소·숨김 복귀·버전 전환·실패 복구의 시간 계약.
- 독립 비교 웹과 실제 제품 연결, 이전 공간 v6/활동 v8 보존, 로컬 안전 빌드/백업/적용.

## 제외 범위

- 외부 DB/AI·유료 서비스·원격 배포·커밋/푸시, 실제 사용자 데이터 정리.
- 이번 공간/배속 구현에서 3명 동시 통행·5인 동시 회의 진행기까지 확장하지 않는다. 눈에 보이는 회의 가구 정원과 검증된 2인 동작 정원을 구별한다. 다인 진행기는 이전 7번 계획의 별도 후속 단계다.
- 이전의 실사 인물 전면 재설계는 최신 모던 콘셉트 선택으로 대체한다. 현재 5명의 정체성과 리그를 보존하고 공간과 재질을 조화시킨다.
- 실물 휴대폰·발열·VRAM을 데스크톱 검사로 합격 처리하지 않는다.

- 실제 배속과 모델/활동 버전을 표시한다. 새 공간 실패는 검증된 구 공간+활동 조합으로 복구한다.
- 최종 소스 고정 후 근거를 새 폴더에 기록한다. 이전 v8 시간 검수를 신규 합격으로 재사용하지 않는다.
