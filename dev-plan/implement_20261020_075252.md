## 개발 목적
여러 기기의 HTTPS·PostgreSQL 원격 협업 환경을 구현·검증하고 main에 커밋·푸시한다. 사용자 후속 답변에 따라 Vercel Hobby 무료 계정 배포를 우선한다.

## 개발 범위
- Docker 없이 Vercel Node Functions/CDN과 Neon Free 호환 PostgreSQL 연결·마이그레이션·배포 설정. 기본 vercel.app HTTPS부터 사용한다.
- 기존 PGlite 로컬판과 업무 규칙 유지, 원격 Secure 쿠키·명시적 HTTPS 출처·DB 세션.
- 여러 함수 인스턴스의 업무 경합·접속 상태/출입을 PostgreSQL 트랜잭션으로 조정한다.
- 상시 작업자 대신 서버 시각과 저장된 시작 시각으로 요청 때 Fake AI 진행을 반영한다. 화면을 모두 닫으면 다음 조회 때 진행을 반영한다. 유료 큐·Cron·외부 AI를 사용하지 않는다.
- 원격은 업무/접속을 합친 2.5초 sync(숨김 30초), 접속 임대 75초·다중 탭·철회 유지.
- 실제 PostgreSQL·TLS 검증, 로컬 회귀, 배포 빌드와 무료 제약/운영 안내.

## 제외 범위
유료 업그레이드·유료 리소스·DNS 변경·24시간 작업자·상용 운영 보장·기존 DB 자동 덮어쓰기. 계정/프로젝트 연결이 없으면 실제 클라우드 배포와 실물 원격 기기 시험을 완료로 표시하지 않는다.
