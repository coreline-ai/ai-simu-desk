## 개발 목적
다섯 동료가 같은 순서를 반복하는 인상을 줄이고, 이동·기다림·역할 업무·상대 반응이 이어지는 모습을 만든다. 이미 완료한 체중 이동·접촉 보정·소품·대화·시선을 유지하면서 보행의 연속성, 안전한 동시 활동과 동작 변주를 보강한다.

## 개발 범위
- 나라의 보행·대기 선행 → 나라·준의 구간별 이동 → 5명 확장 → 역할 소품 변주 → 상호 응답 → 휴식 변주 → 통합 검수 순서다.
- 고정 경로와 기존 공간·소품·접촉 솔버를 재사용한다. 이동은 검증된 독립 구간에서만 최대 2명이며 협소/교차 구간은 1명이다.
- 후보는 **활동 v5**로 구분하고 현재 활동 v4·공간 모델 v6는 비교/복구 기준으로 보존한다. 공간 모델 v5와 혼동하지 않는다.
- 실행 시 비교 웹을 추가하고 통합 게이트 통과 후 로컬 제품의 기본 동작에 반영한다.

## 제외 범위
- 외부 DB·AI API·계정 연결·유료 서비스·배포. 로컬 PGlite와 로그인·업무·인계·저장 계약은 유지한다.
- 자유 경로 탐색/NavMesh, 자유 교행, 5명 동시 보행, 가구 재배치, 새 커피머신·새 방.
- 사람 사이 컵/문서 직접 전달, 전원 착석 회의, 전체 손가락/표정 리그·립싱크·천/액체 물리.
- 노트/태블릿 필기를 실제 문서 데이터로 저장하는 기능. 이번 동작 변주와 별도다.

- [x] 나라의 직진·회전·정지 사이 보행 위상을 연결하고, 출발/도착의 발 간격·착지와 신발 기울기를 보강한다. 지지하는 발의 기준점을 유지하며 기존 무릎 도달 범위를 넘기지 않는다.
- [x] 대기는 허가된 정지 지점에서 작은 체중 이동·진행 방향 보기만 적용한다. 옆으로 임의 이동하거나 다른 구간에 발을 내밀지 않는다.

## Phase 4. 대화 주도권 교대와 상대 반응
### 구현 태스크
- [x] 기존 `SocialExchange`의 실제 응답 확인 시계를 사용해 소파와 컵 회의의 발화자 교대·짧은 생각 간격·작은 확인 손짓을 추가한다. 동일한 단계 순서가 계속 반복되지 않도록 검증 가능한 소수 패턴을 둔다.
- [x] 시선→상체 방향→손짓→상대 끄덕임 순서를 조율한다. 컵을 마시거나 소품을 쓰는 손에는 대화 제스처를 중복 적용하지 않는다.
- [x] 나라·준 선행 후 가능한 10가지 짝으로 확장한다. 상대가 늦거나 업무를 받으면 자연스럽게 손을 내리고 인사/복귀하며, 없는 상대를 향한 대화는 시작하지 않는다.
### 자체 테스트와 완료 조건
- [x] 10가지 짝 × 좌석 순서에서 주도권 교대·동시 과한 제스처 방지·좌면/발 유지·컵 접촉을 확인한다.
- [x] 상대 미도착·중간 종료·응답 누락·일시정지·업무 도착에서 시간 초과/정리와 양쪽 세션 해제를 확인한다. 실제 업무 내용이나 AI 응답을 생성하는 대화로 표시하지 않는다.
### 이슈 및 수정
- 완료: 3종 순서·교대 주도자와 두 사람의 실제 제시 시간으로 진행하는 응답을 구현했다. 자동 검사에서 10가지 짝×좌석 순서 20회 통과, 양쪽 발언·발/좌면 유지·세션/예약 회수 확인. 응답 누락은 취소 처리한다. 컵 회의도 10가지 짝×좌석 순서 20회에서 양쪽 발언·컵 접촉·발 지지·회수 검사를 통과했다. 브라우저 근접 검수는 Phase 6에 기록한다.

## Phase 5. 인물별 휴식·행동 선택 보강
### 구현 태스크
- [x] 기존 각 인물의 2개 전신 휴식을 보존하고, 책상에서 잠깐 팔/손목 풀기·어깨 내리기, 창가에서 시선 전환 후 호흡 고르기를 추가한다. 손에 소품이 있으면 먼저 정리하고 기존 가동 범위 안에서 설계한다.
- [x] `role-scheduler.mjs`의 기존 완료 횟수·휴지 시간·seed 선택기에 최근 행동 이력과 역할별 선호를 더한다. 연속 반복을 제한하고 휴식 강도·정지 간격을 소폭 다르게 둔다.
- [x] 명시적 시연은 새 동작을 빠짐없이 보여주고 자율 모드는 덜 규칙적으로 배치한다. 새 활동이 기존 활동이나 특정 인물의 기회를 빼앗지 않도록 유지한다.
### 자체 테스트와 완료 조건
- [x] 같은 seed 재현·여러 seed 변주·장시간 업무/회복에서 인물별 기존/신규 행동 도달과 연속 반복 제한을 검사한다. 업무 중단이 반복될 때 완료를 강제하지 않는다.
- [x] 어깨/손목 과회전·안경/머리/책상 관통·휴식 자세 잔류가 없고, 5명의 선호 차이가 화면에서 구별되어야 완료다.
### 이슈 및 수정
- 완료: 인물별 기존 전신 휴식 2종에 앉아서 손목 풀기·어깨 내리기 2종을 더했다. 창가 시선 전환/호흡, 최근 활동 가중치와 역할별 선호를 기존 선택기에 통합했다. 5명 휴식·업무 중단·정지/복구, seed 17 재현 2회와 seed 29 차이, 각 1800초 빠른 업무 혼합의 모든 기존/신규 활동 도달·정리 통과. 실제 경과 검사는 별도 진행한다.
