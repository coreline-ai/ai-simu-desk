## 개발 목적
5명 동료가 소품을 실제로 잡고, 동료 자리로 찾아가 함께 검토하고, 상대의 상황에 반응하는 모습을 만든다. v5에서 완료한 보행·대기·양보·역할 15종·교대 대화에 새 상호작용을 연결한다.

## 개발 범위
- 나라의 펜 쥐기 선행 → 5명 손동작 → 나라·준 책상 방문 → 안전한 짝으로 확대 → 문서 전달 → 상황별 반응 → 짧은 생활 흐름 → 비교·회귀 검수 순서다.
- 후보는 **활동 v6**로 구분한다. 기존 공간 모델 v6/105개 클립은 유지하고 런타임에서 필요한 손 노드·문서 소품만 초기화한다. 모델 재제작이 필요하면 별도 범위로 기록한다.
- 기존 `/demos/activities/expressive/` v5를 비교·복구 기준으로 보존한다. 후보 경로는 `/demos/activities/interaction/`로 계획한다.

## 제외 범위
- 외부 DB·AI API·계정 연결·유료 서비스·배포. 로컬 PGlite와 서버 업무·승인·인계·저장 계약은 유지한다.
- 자유 길찾기, 좁은 통로 자유 교행, 3~5명 동시 보행, 가구 재배치·새 회의실·5인 착석 회의.
- 전체 손가락/얼굴 스키닝, 립싱크·음성 대화, 천·액체 물리, 컵을 사람 사이에 직접 건네기.
- 3D 문서 전달을 실제 업무 승인/인계로 간주하거나 노트·문서 내용을 DB에 새로 저장하는 기능.

## Phase 3. 문서 한 장 전달·확인·반환
### 구현 태스크
- [x] Phase 2의 나라·준 방문 세션에서 기존 종이 재질을 재사용한 문서 1장으로 선행한다. 컵·펜 전달은 추가하지 않는다.

- [x] 응답이 늦거나 누락되면 손짓을 거듭하지 않고 한 번 기다린 뒤 종료한다. 같은 행동 안에서도 역할에 맞는 응답 간격/손짓 강도만 소폭 다르게 둔다.
### 자체 테스트와 완료 조건
- [x] 상대 미도착·응답 누락·양쪽 업무·정지·상대 제거·새 세션에서 시간 초과/정리와 오래된 응답 폐기를 확인한다.
- [x] 두 사람의 큰 손짓 중첩·목 과회전·빈자리 응시·소품 관통이 없고 기존 20개 좌석 순서의 소파/컵 회의 검수가 유지되어야 한다.
### 이슈 및 수정
완료: 기존 응답 시계로 출발 전 초대/수락, 바쁜 호스트 보류, 미응답 취소와 오래된 세션 정리 검사를 통과했다. 현재 얼굴 노드만 보정하며 실제 음성/AI 대화를 생성하지 않는다.

## Phase 5. 생활 행동의 짧은 연결과 개인차
### 구현 태스크
- [x] 기존 단일 선택기에 메모→방문 검토, 검토→문서 정리, 일어서서 어깨 풀기→창가 휴식→복귀 같은 최대 2~3단계 흐름을 추가한다. 필수 업무나 상대의 참여를 강제하지 않고 조건이 사라지면 종료한다.
- [x] 최근 상대·목적지·동작을 길이가 제한된 로컬 이력으로 관리한다. 같은 짝/행동 반복을 줄이면서 기존 전원 대화 기회와 휴식 선호를 유지한다. 새 피로도 시스템·영속 기록은 만들지 않는다.
- [x] 명시적 시연에서는 새 장면을 빠짐없이 보여주고 자율 모드에서는 seed로 재현 가능한 간격·순서를 적용한다. 통로 혼잡 시 자리에서 가능한 행동을 선택한다.
### 자체 테스트와 완료 조건
- [x] 같은 seed 재현·서로 다른 seed 변화·한 명 지속 업무·반복 취소·상대 부족에서 무한 대기와 기회 편중이 없어야 한다.
- [x] 모두 idle인 10분에서 5명 기존 대화 도달을 유지한다. 새 방문/전달은 허용 짝 기준의 별도 시연으로 전원 참여를 확인하고, 실제 업무가 차단한 행동은 미완료 이유를 기록한다.
### 이슈 및 수정
완료: 3개 방문 짝의 명시적 시연으로 전원 문서 검토 참여, 5명 기립 휴식→창가 직접 연결, 3회 1800초(seed 17 재현 2회/29 변화) 혼합을 통과했다. 방문 정지 셀의 좌표 누락을 수정하고 실제 셀 수 검사를 추가했다. 기존 목적지 미참여자가 사용 가능한 파트너를 새 방문이 먼저 가져가지 않도록 우선순위를 보정했다. 문서 중단 후 호스트 팔이 재활성화되던 문제도 실제 업무 경계 검사로 보정했다. 취소 후 문서가 다른 책상에 남아 있어도 방문 시연이 무한 대기하지 않고, 실제 업무/상대 종료는 대기 중인 시연 순서를 해제한다.
