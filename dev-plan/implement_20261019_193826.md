## 개발 목적
여러 계정이 같은 공동 공간에서 나라·준의 업무·승인·답변·3D 상태를 함께 확인하고, 서버 권한에 맞는 조작만 수행하도록 한다. 검증 후 기존 main에 커밋·푸시한다.

## 개발 범위
- 개인 공간을 보존하고 공동 공간 생성·목록·전환, 인증된 사용자의 1회용 초대 코드 참여를 추가한다.
- 소유자는 초대·권한·멤버·모든 업무·승인을 관리한다. 업무 참여자는 업무 생성과 자신이 요청한 실행의 취소/재시도를, 보기 전용은 상태·결과 조회만 수행한다.
- 코드는 서버 해시 저장·1시간 만료·1회 사용이며 재발급 시 이전 미사용 코드를 폐기한다. 기존 멤버는 코드로 자기 권한을 올릴 수 없다.
- 기존 영속 이벤트/스냅샷에 멤버 변경을 포함한다. 500ms 조회(숨김 탭 2초), 재접속·공간 전환·권한 철회에서 현재 권한으로 다시 읽는다.
- 공간당 활성 업무 하나와 Fake AI, 단일 프로세스 PGlite를 유지한다. 참여자 목록은 멤버 목록이며 온라인 접속자로 표시하지 않는다.

## 제외 범위
- 공개 배포·운영 PostgreSQL·WebSocket 도입·Redis·이메일 초대 발송·외부 AI·문서 공동 편집·커서/아바타 위치 공유·회의.
- 소유권 이전·공간/계정 삭제·공개 공간 검색. 실제 사용자에게 메시지나 초대 코드를 전송하지 않는다.
