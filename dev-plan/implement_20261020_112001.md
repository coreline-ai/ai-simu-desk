# implement_20261020_112001.md

작성 일시: `2026-10-20 11:20:01 KST`

이 문서는 5명 캐릭터의 동작과 인계 표현을 개선하는 후속 로컬 개발 범위를 정한다. 사용자 후속 요청에 따라 순서대로 로컬 구현·검증을 진행한다.

## 개발 목적
사용자가 장면만 보아도 누가 준비하고, 작성하고, 검토하며 누구에게 결과를 넘기는지 이해하게 한다. 나라→소라→준→민→레오의 기존 협업 순서와 실제 서버 진행에 맞춰 작은 동작과 인계 표현을 연결한다.

## 개발 범위
- 준비·작성·검토 동작을 구분하고, 역할별 리듬과 짧은 휴지 구간을 추가한다.
- 인계 순간 보내는 동료의 제한된 시선·손짓, 받는 동료의 끄덕임을 연결한다.
- 전달자→수신자와 공개된 전달 요약을 보여주는 인계 카드·단계 표시를 추가한다.
- 정지/재생, 동작 줄이기, 새로고침, 탭 복귀, 취소/실패에서 연출이 실제 업무 상태와 어긋나지 않게 한다.
- 기존 로컬 PGlite, 한 실행의 고정된 Fake AI 결과와 단계 경계를 활용한다. 이 범위에서는 새 DB 테이블·마이그레이션·상시 작업자를 추가하지 않는다.

## 제외 범위
외부 DB·실제 LLM·외부 API·유료 서비스·공개 배포, 걷기·자리 이동·전신 스키닝·음성, 인계 승인/거절을 갖는 새 업무 흐름, 실제 다섯 에이전트의 병렬 실행, 임의의 역할 순서·되돌림 편집은 포함하지 않는다. 커밋·푸시는 별도 요청 때 진행한다.
