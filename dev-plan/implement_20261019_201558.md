## 개발 목적
공동 공간의 계정별 온라인·오프라인과 입장·퇴장을 실시간으로 확인하고, 검증된 변경을 main에 커밋·푸시한다.

## 개발 범위
- 인증 세션·공간·탭 단위 메모리 임대. 기존 500ms 조회(숨김 탭 2초)에서 갱신하며 마지막 응답 뒤 75초에 만료한다. 브라우저의 긴 절전은 연결 끊김으로 취급한다.
- 같은 사용자의 여러 탭/세션은 한 명으로 집계한다. 마지막 연결의 명시적 퇴장 또는 만료만 오프라인으로 표시한다.
- 공동 공간 참여자별 상태, 온라인 인원, 최근 입장·퇴장 20건과 시각을 표시한다. 서버 연결 실패 시 확인 중으로 바꿔 오래된 온라인 표시를 피한다.
- 공간 전환·로그아웃·페이지 종료·권한 철회·세션 만료·서버 재시작을 처리한다. 접속 상태는 영속 업무/권한 revision을 바꾸지 않는다.

다중 서버·Redis·WebSocket·영구 접속 이력·사용자 위치/아바타·공동 편집·운영 배포·외부 AI. DB 구조와 기존 업무/초대 기록을 변경하지 않는다.
