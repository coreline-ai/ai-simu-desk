## 개발 목적
사용자 첨부 v13 화면의 막대형·평행 손가락과 작업에 맞지 않는 손바닥 방향을 재설계한다. 이전 수치 접촉 통과를 자연스러움 통과로 취급하지 않는다.

## 개발 범위
좌우 손 좌표계, 관절 사슬, 기본 손 조형/스킨 가중치, 타이핑·삼점 필기·마우스·종이 지지 포즈, 실제 작업 표면 연동 및 전후 시각 검수.

## 제외 범위
사용자가 구현과 검수용 빌드/서버 실행을 승인했다. Blender 설치·외부 모델 재학습·새 에이전트 실행·커밋/푸시는 하지 않는다. 외부 참고 이미지를 게임 에셋으로 복제하지 않는다. 임상적으로 유일한 정답 자세나 의학적 각도 범위를 주장하지 않는다.

## 코드 관찰과 가설
1. 확인: hand-grips.mjs가 네 손가락에 동일한 두 마디 길이 [.039,.034]를 부여한다. 휴식 끝점 차이는 있지만 실제 마디 길이 차이는 없다.
2. 확인: thumb base만 side sign을 반영하고 나머지 finger base.x 배열은 양손 동일하다. 엄지와 검지의 인접 관계를 올바른 좌우 손으로 재정의해야 한다.
3. 확인: authored curl은 각 손가락 길이의 .97까지 펴진 straight와 bent를 보간한다. 일반 작업/휴식에도 같은 계산을 적용해 전체적으로 길고 평행한 손가락이 되는 설계다.
4. 확인: 손끝 2-link IK와 고정 +Z bend pole을 쓴다. hand-skin.mjs의 손가락별 3개 표시 bone은 모두 palm bone 자식이다. 독립 MCP→PIP→DIP 관절 사슬은 아니다.
5. 유력 가설: palmDown이라는 고정 X -π/2 회전과 +Z 굽힘 방향의 기준이 맞지 않는다. 순수 행렬 계산에서 +Z는 +Y, -Y는 +Z로 변환된다. 실제 양손 palm/dorsal 방향을 캘리브레이션해 확정해야 하며 부호 한 개만 임의 변경하지 않는다.
6. 확인: current grip은 다섯 손가락을 모두 pen shaft contact 대상으로 삼는다. 삼점 필기의 작업 손가락/보조 손가락을 분리해야 한다.
7. 확인: 업무 타겟은 주로 손목과 curl이며 실제 개별 키캡 press/release를 정의하지 않는다. 키보드 위 손 위치와 실제 누름 동작은 별도 구현이 필요하다.

## 공통 진행 규칙
공용 손의 소라 1명 기준 샘플을 먼저 검수하고 다섯 명에게 확장한다. 실제 종이/펜/컵 접촉과 소품 소유권·반납, 업무 선점·정지·공유 장면 재현은 보존한다. 이전 v13 경로를 비교 기준으로 유지한다. 각 Phase의 자체 검증을 통과한 뒤 다음 Phase로 이동한다.

## Phase 1. 공용 손 교정
- [x] palm normal, finger-forward, thumb-side를 명시하고 좌우 전체 배열과 굽힘 방향을 검증한다.
- [x] 검지/중지/약지/소지의 서로 다른 마디 길이와 너클 아치, 엄지 맞섬·엄지/검지 사이 공간을 조형한다. 현재 캐릭터의 부드러운 스타일은 유지한다.
- [x] 네 손가락 MCP→PIP→DIP, 엄지 CMC→MCP→IP를 실제 부모·자식 구조로 구성하고 관절 제한·반대 굽힘·비틀림을 검사한다. 의료 수치 대신 조형에 맞는 검증된 제작 범위를 사용한다.
- [x] Blender 등에서 한 쌍의 손과 가중치/포즈를 직접 확인한 뒤 GLB로 사용하는 방식을 권장한다. 실시간 Blender 연결은 요구하지 않는다. 대안은 같은 관절/가중치 계약을 코드로 재작성하는 것.
- [x] 자체 테스트: 좌우 거울 대응, 엄지-검지 인접, 손바닥 normal, 관절 사슬, 뼈 길이, 스키닝 유한성.

## Phase 2. 정지 포즈 우선
- [x] relaxed / keyboard-hover / key-press / tripod-write / mouse-rest / paper-pinch를 별도 포즈로 만든다. point는 별도 포즈이며 일반 손의 기본값으로 쓰지 않는다.
- [x] 타이핑: 손등이 위로 보이고 손바닥은 키 쪽, 손목과 아래팔은 급격히 꺾이지 않으며 손가락은 둥근 아치. 엄지는 스페이스바 쪽. 손목을 책상에 강제로 눌러 고정하지 않는다.
- [x] 필기: 엄지·검지·중지의 실제 삼점 지지, 약지·소지는 편안하게 접은 보조 그룹. 다섯 손끝을 펜에 억지로 붙이지 않는다. 이는 하나의 제작 기준 그립이며 사람의 모든 유효 그립을 배제하지 않는다.
- [x] 자체 검수: 소라 한 명을 손등/손바닥/측면/사용자 첨부와 같은 사선 카메라에서 비교한다. 실제 참고와 실루엣이 맞지 않으면 확장하지 않는다.

## Phase 3. 동작 합성
- [x] 타이핑은 키캡 기준 눌림 전→접촉→복귀, 비작동 손가락의 미세 연동을 적용한다. 손목 전체 상하 반복이나 동일 위상 5손가락 동작을 피한다.
- [x] 펜은 그립을 안정적으로 유지하고 엄지/검지/중지의 작은 움직임으로 선을 만든다. 경로 이동과 손목 이동, 종이 접촉을 분리한다.
- [ ] 올바른 공용 기본 자세 위에 캐릭터별 입력 밀도·멈춤·시선 차이를 합성한다.
- [x] 자체 테스트: 실제 작업 표면 접촉/관통, 관절 뒤집힘, 소유권, 중단·반납·새 업무·정지.

## 구현 결정
Blender 실행 파일이 없어 설치 없이 승인된 코드 기반 관절/가중치 재작성 대안을 사용한다. 소라만 opt-in hand v14, 다른 네 명과 제품 주 런타임 v13 보존. 컵/전달/공동 활동은 기존 소유권 경로에 양보하고 v13 그립을 명시적으로 사용하며 전원 확대 전 별도 재설계를 남긴다.

### 발생 후보 OCC-003
키 중심만 누르도록 한 초기 검수에서 소지의 도달 오차 7.75mm가 발생했다. 손목의 키보드 상대 위치를 조정하고 실제 키캡 상면 내부의 가장 가까운 유효 지점(모서리 3mm 제외)을 접촉 대상으로 삼아 수정했다. 목표를 빈 공간으로 당기거나 마디 길이를 늘리지 않았다. 최종 회귀 통과. 분류: plan-only (당시 새 회귀 파일이 미추적 상태였으며 Git 영속 참조 없이 정식 교훈을 등록하지 않음).

### 발생 후보 OCC-004
FK 직후 키 접촉 오차는 0.68mm였지만 전체 프레임 후 실제 pad world transform은 자유 팔 책상 회피의 후처리로 최대 81mm 바뀌었다. 검수용 키/손바닥 포즈를 명시적 손 제어로 예약하여 후처리는 팔꿈치만 정리하고 손목 목표를 유지하도록 수정했다. 손끝 검사는 후처리가 끝난 실제 world transform으로 회귀 강화했다. 분류: plan-only (이번 계획과 신규 회귀에 근거 보존).

### 발생 후보 OCC-005
필기 세 접촉점만 맞춘 초기 캘리브레이션에서 검지/중지 중간마디의 보수적 캡슐 겹침이 5.8mm였다. 엄지 CMC에서 시작하는 첫 뼈에 중수골 길이가 충분히 반영되지 않은 것을 교정하고, 세 접촉점을 펜 둘레의 분리된 세 면으로 배치했다. 각도 제한과 손가락간 겹침 패널티를 함께 적용하여 실제 스타일러스 기준 접촉 오차 약0.16mm, 최대 원위 마디 프록시 겹침0.89mm로 줄였다. 전체 피부 충돌 보장을 뜻하지 않는다. 6개 정지 포즈의 원위 마디 분리 회귀를 추가하고 통과했다. 분류: plan-only (이번 계획과 신규 회귀에 근거 보존).
