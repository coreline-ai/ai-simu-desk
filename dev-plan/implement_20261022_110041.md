## 개발 목적

사용자가 승인한 모던 사무실과 나라·소라·준·민·레오 5명을 기준으로 P0~P2 권장 에셋과 활동을 순서대로 보강한다. 나라의 손·노트·연필 선행 검증 후 5명 모두의 보행·착석·컵·문서·역할 소품·표정·휴식에 확장하고, 커피 머신 사용·효과음·5인 착석 회의까지 실제 동작으로 연결한다.

## 개발 범위

- 기존 5명 정체성·13.2×10.2m 크림/오크/세이지 공간, 21기본상태×5명과 업무/API/로컬 DB 계약 유지.
- 신규 공간 모델 v8 / 활동 v10, 독립 `/demos/activities/ensemble/`에서 현재 공간 v7 / 활동 v9와 비교.
- 전신 관절·의복/신발·연속 손, 보행 시작/정지·회전·양보·기립/착석과 좌석별 접촉 보강.
- 역할 5세트, 컵/문서·쿠션/가구·창가, 표정/시선·근접/전체 보기용 디테일 단계.
- 커피 바 예약·컵 놓기/버튼/음료 받기·음료 운반·업무 복귀. 5명 각각 사용 가능.
- 5명 동시 회의 참여: 5개 좌석과 소품, 전원 도착 후 발언/경청/메모/시선, 업무 중단과 전원 복귀.
- 신규 프로필 최대 3명 이동을 경로 여유에 따라 허용. 좁은 통로·정지 인물은 계속 예약/양보한다.
- 사용자 조작 후 활성화되는 로컬 합성 효과음과 음소거. 배속 x1/1.5/2/3과 정지·숨김·모션 축소 보존.
- 검수 후 로컬 웹 적용. 현재 v9 비교/복구와 이전 모든 URL 보존.

## 품질·호환 계약

- 모델 v8에는 5명과 원본 105클립·모든 바인딩·필수 소품·에셋 카탈로그/제작 출처/접점이 있어야 한다.
- 실제 소품과 움직이는 부품은 분리한다. 손·좌면·발·컵/문서 지지면은 실제 형상과 일치한다. 낮은 디테일에서도 접점/움직임은 같다.
- 현 공간 크기는 유지하되 5인 회의 테이블·좌석 간격·접근 통로는 실측으로 조정한다. 회의 가구 6석 중 고유 5석을 예약한다.
- 그룹 회의 중 2인 회의·소파 짝·역할 소품·커피에 같은 인물을 중복 배정하지 않는다. 전원이 실제 착석하기 전에 발언하지 않는다.
- 인체 겹침·손/소품 오차·바닥 지지를 기존 수치 이상으로 검사한다. 보수적 충돌 후보와 실제 메시 문제를 구별한다.
- 성능 초기 예산: 1280×900/DPR1/균형/낮/전체 공간, p95≤33.3ms 및 v9 대비 10% 이내, draw≤1200·렌더 삼각형≤950000·새 GLB≤15MiB. 미달이면 디테일/배치를 수정한다.
- 효과음은 사용자 조작 후 활성화하고 기본 꺼짐·음소거·일시정지/숨김 정지를 제공한다. 마이크/외부 음원/네트워크를 사용하지 않는다.

## 신규 장시간 검수 프로토콜

- 10분 연속: 5명 역할·전원 회의 발언/메모·컵/커피·3명 이동·완료된 소파 대화 및 문서 전달을 관찰한다. 5인 회의에 약 275초가 필요하므로 이 신규 프로필에서는 기존 10분의 전원 소파 짝 회전 대신 전원 그룹 회의를 필수로 하며, 30분 혼합에서는 기존 전원 소파 짝·모든 목적지·3역할 변주 검사를 그대로 수행한다. 접촉·반경·오류·시간·복귀·성능 기준은 유지한다.
- 30분 혼합: 첫 12분을 전원 생활/회의·방문에 배정한다. 이후 168초 간격으로 5명에게 각각 준비 8초·타이핑 182초·완료 2초의 시각 업무를 주어 일부 겹치게 관찰한다. 마지막 업무 종료는 1,584초, 남은 216초는 회복 관찰이다. 이 시간표는 테스트용 표시이며 실제 서버 업무 시간을 바꾸지 않는다.
- 자동 회의는 실제 업무 중인 동료를 기다리는 동안 다른 자유 동료의 생활을 막지 않는다. 회의 해산 중에는 전원 복귀 전 새 자율 활동을 배정하지 않으며, 본인 복귀가 완료된 실제 업무는 먼저 표시할 수 있다.
- 초기 빠른 혼합의 시연 지연/커버리지 부족 기록은 `product/evidence/ensemble-activities/before-autonomy-recovery/`에 보존한다.

- 회의 횟수는 완료된 2인·5인 회의를 함께 집계한다. 5인 회의의 참가·발언·메모·완료 횟수와 이력은 별도 `group` 진단으로 유지한다. 미완료·취소 회의는 완료 횟수에 넣지 않는다.

## 최종 실제 형상 보정

- 손가락 접점과 별도로 실제 손바닥 메시 정점을 검사하니 필기구 집기/반납/손 회수와 회의 손 올리기에서 탁자 겹침이 나타났다. 손바닥을 들어 접근하고, 필기 종료 시 노트 지지면으로 복귀하도록 보정했다. 아래에서 위로 관통하던 회의 손 전환은 무릎 쪽에서 먼저 들어 올리는 순서로 바꿨다.
- 컵 손잡이는 수직 평면으로 수정하고 실제 손잡이 표면의 5개 접점과 손바닥 여유를 신규 자산 메타데이터 revision 2에 명시했다. 기존 자산 v6/v7의 형상·계약은 유지한다.
- 노트를 오른쪽 18cm로 배치하고 오른손은 실제 노트 윗면, 왼손은 컵과 겹치지 않는 탁자 지점을 지지한다. 상체는 16cm 앞·약 10도 기울기로 조정했다. 팔 길이/인체 반경/접촉 합격 기준은 유지한다.
- 빠른 4배속 혼합 검사의 1초 표본은 짧은 완료 동작을 놓칠 수 있어 8/30초 간격으로 관찰한다. 재생/업무 시간이나 완료 표시 길이는 변경하지 않는다. 실제 x1 장시간 검사의 1초 관찰 기준은 유지한다.
- 실패·중단 근거는 `product/evidence/ensemble-activities/before-palm-contact/`에 보존한다. 수정 후 최종 소스 지문을 다시 고정하고 회귀·25개 실제 좌석 조합·장시간 검수를 재실행한다.

## 메모 취소 경계 보정

- 추가 실제 메시 검사에서 메모 도중 취소하면 0.9초짜리 손 지지 종료가 연필 반납/회수(최대 약 1.6초)보다 먼저 끝나 손바닥이 탁자를 통과했다. 실제 침범 정점을 기록했다.
- 신규 5인 회의에서 오른손 소품 제어가 끝날 때까지 지지 종료 시계를 기다린 뒤, 기존 안전 회수 경로를 수행하도록 보정했다. 컵을 운반하는 왼손 때문에 회수 전체가 멈추지 않도록 오른손 소유자에 한정했다.
- 5명 각각 필기/반납 도중 실제 업무 또는 활동 취소의 20개 회귀에서 소품 소유권·실제 손바닥/탁자·전원 복귀를 검사한다. 이전 결과/중단은 `before-cancelled-note-support/`에 보존하고 장시간 검수는 최종 코드로 다시 시작한다.

- 필기 전환 도중 취소할 때 연필의 보간 위치와 손의 실제 위치가 달랐다. 반납 진입 시 현재 손/연필 간격을 보존해 초기/중간/후기 필기와 반납 취소까지 5명×4조건으로 확장했다. 손가락 접점·실제 손바닥 부피·완전 복귀를 함께 검사한다.
