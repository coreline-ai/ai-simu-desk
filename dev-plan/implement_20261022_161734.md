## 개발 목적
v11의 복제된 듯한 움직임과 보행 중 팔이 굳어 보이는 문제를 고친다. 나라·소라·준·민·레오가 자유로운 팔과 자연스러운 손, 서로 다른 보행·대기·경청 습관을 갖도록 로컬에서 구현하고 웹으로 검증한다.

## 개발 범위
- 기존 v11/공간 v9에 인물별 보행·팔꿈치·손목·편한 손 모양과 상체/시선 변주를 추가한다.
- 자유 팔과 컵/문서/마커/지지 손의 소유권을 구분한다. 책상 충돌 보정은 실제 가까운 곳에서만 자유 팔에 적용한다.
- 기존 발 접지·경로·예약·105클립·공동 관찰을 유지한다. 구버전 v11 동작을 같은 모델에서 비교한다.
- 실제 보정 전/후 화면, 5명 수치 검사, 중단/복귀·모션 축소·배속·공동 관찰 회귀를 기록한다.

## 제외 범위
- 외부 DB/AI/유료 에셋·서비스·배포·커밋/푸시, 인물 외형 실사화, 걷는 경로/인원 증가.
- 보행 연구의 정확한 인간 재현이나 모션캡처 수준을 주장하지 않는다. 수치 범위는 현재 스타일과 리그에 맞춘 연출값이다.
- 연결 불가인 실물 모바일 검수는 미완료 유지.
