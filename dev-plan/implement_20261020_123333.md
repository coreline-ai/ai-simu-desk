## 개발 목적
다섯 동료가 앉아서 일하다가 기지개를 켜고, 일어나 휴식 지점까지 걸어갔다가 자신의 자리로 돌아오는 모습을 만든다. 기존 2.5D 사무실 이미지의 따뜻한 재질·빛·가구 디테일을 3D 품질 기준으로 삼는다.

## 개발 범위
- 나라 1명과 책상·바닥 일부를 먼저 보강해 외형과 전신 동작을 검증한 후 5명에게 확장한다.
- 양팔 기지개·목/어깨 풀기·손목 털기, 일어서기·서 있기·다시 앉기를 추가한다.
- 검증된 고정 통로를 따라 휴식 지점으로 이동·서서 쉬기·복귀를 구현한다.
- 5명에게 서로 다른 동작 조합·휴식 간격을 적용한다. 초기에는 동시에 1명만 이동한다.
- 동작 시연 버튼과 업무 대기 중 자동 생활 동작을 제공한다. 실제 업무·DB 상태와 시각 동작을 분리한다.
- 로컬 4180에서 기존 협업·인계와 함께 확인한다. v1~v4는 보존하고 새 에셋은 v5로 생성한다.

## 제외 범위
앞서 제안한 결과 보드·검토 도구, 외부 DB/LLM/API·유료 연결·배포, 새 캐릭터·음성·물리 엔진·임의 위치 자유 이동·범용 길찾기 엔진은 포함하지 않는다. 첫 버전의 휴식은 서서 쉬기와 스트레칭이며 소파에 눕기/컵 집기 등 소품 상호작용은 후속으로 둔다. 계획 단계에서 실행 코드·DB·에셋을 변경하거나 커밋·푸시하지 않는다.

## 현재 확인과 설계 판단
- 현재 다리는 앉은 자세의 고정 메시이고, 어깨와 골반을 중심으로 팔·다리를 회전시키는 전신 구조가 없다. 현재 모델을 위로 이동시키는 것만으로 일어서기를 만들지 않는다.

- 이름표·개별 카메라는 현재 고정된 자리 좌표를 사용한다. 걷는 동안에는 실제 캐릭터의 머리/몸 위치를 기준으로 갱신해야 한다.
- 2.5D는 상세한 이미지에 목재·패브릭·부드러운 그림자 등이 이미 표현돼 있다. 현재 3D는 단순 도형·단색 재질과 실시간 기본 조명 중심이다. 차이는 차원 자체보다 에셋·재질·조명의 완성도에 있다.
- 권장 방향은 현재 3D 공간을 유지하면서 2.5D 이미지의 외형을 기준으로 보강하는 것이다. 이미지 배경 위에 캐릭터를 바로 합성하면 걷는 위치별 가림·원근·그림자를 별도로 해결해야 하므로, 그 방식으로 자동 전환하지 않는다.

- [ ] 각 동료에게 스트레칭 종류·시작 간격·반복 리듬을 고정된 차이로 부여한다. 일정 시간 대기한 동료만 쉬게 하고 프레임마다 무작위 결정을 하지 않는다.
- [ ] 새 업무가 오면 휴식을 끝내고 안전한 경로로 복귀한다. 자리 밖에서는 타이핑 대신 ‘업무 진행 · 자리 복귀 중’을 표시하고, 착석 후 실제 업무 동작으로 전환한다. 서버 실행은 기다리게 하지 않는다.
- [ ] 업무 중 시연 요청을 제한하고, 정지/동작 줄이기는 이동·관절 모두 멈춘다. 재개 시 최신 업무 상태를 확인해 현재 위치에서 복귀하며 과거 휴식을 반복하지 않는다.
- [ ] 공간 전환·모델 재생성·오류 시 예약/타이머/이동 이벤트를 해제한다. 게스트 수와 캐릭터 생활 동작은 별도로 유지한다.
### 자체 테스트
- [ ] 5명별 자리·고유 외형·경로·복귀, 동일 경로 요청과 휴식 지점 점유를 검사한다.
- [ ] 이동 중 새 업무/인계/취소/실패·정지/재생·공간 전환을 검사하고 실제 업무 결과가 바뀌지 않는지 확인한다.
