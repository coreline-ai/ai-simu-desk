## 개발 목적
텍스트 역할만 제공하던 준을 실제 3D 동료로 추가한다. 두 동료를 선택하고 업무를 맡길 때 저장된 실행 소유자와 각 캐릭터의 동작이 일치하게 한다.

## 개발 범위
- 기존 v1 파일럿을 보존하고 같은 미터 단위·광원·카메라 아래 준·책상·의자를 포함하는 제품용 v2 GLB를 자체 생성한다.
- 하나의 장면에서 나라/준의 idle·typing 동작을 독립적으로 재생하고 전체/동료별 카메라, 클릭·키보드 가능한 선택을 연결한다.
- 제품의 서버 스냅샷에서 활성 실행 소유자를 기준으로 동작을 산출한다. 동료 선택과 과거 기록 선택이 실행 담당자를 바꾸지 않는다.
- Fake AI·로그인·DB 계약과 기존 데이터를 유지한다. 공개 배포·외부 AI·메일·공동 편집은 이번 범위에서 제외한다.

## 공통 진행 규칙
- 각 단계 자체 검사를 통과한 뒤 다음 단계로 진행한다. 완료 사실만 체크한다.
- `model.mjs`는 형상·클립, `scene.mjs`는 렌더링·동작·카메라, 제품의 순수 장면 변환 함수는 실행→표현 매핑, `app.mjs`는 UI 연결을 소유한다.
- 기존 순수 도메인과 서버에 Three/DOM 의존성을 추가하지 않는다. 공통화는 두 동료의 같은 책임 안에서만 수행한다.
- v1 GLB와 기존 모의 파일럿을 보존한다. 이미지 생성 대신 기존 절차형 3D 제작을 확장하고 출처·치수·한계를 기록한다.
- DB·서버 비밀값과 QA 계정을 증거·커밋에 포함하지 않는다.
