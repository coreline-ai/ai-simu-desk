## 개발 목적
앞선 DeskRPG 분석을 전문가 관점에서 검토하고, 자체 생성 이미지와 동적 에셋으로 업무 흐름을 확인하는 1차 시각 데모 및 재사용 가능한 실행 프롬프트를 제공한다.

## 개발 범위
- 전문가 검토 결과와 1차 데모 계약을 기록한다.
- 사무실 배경 PNG 1개, 직원 둘의 휴식/타이핑용 4×4 투명 아틀라스 1개를 생성한다.
- 직원 선택, 업무 입력, 정상 완료·승인 대기·실패·취소·재시도를 제공한다.
- 실제 생성 에셋을 사용하는 반응형 로컬 2.5D 데모와 에셋 미리보기를 만든다.
- 상태 테스트, 실제 브라우저 QA, 화면 증거와 통합 프롬프트를 제공한다.

## 제외 범위
- 실제 AI/Hermes 호출, 비밀키, 로그인, DB, 결제, 업로드, 다중 사용자, 회의, 예약 실행, 공개 배포.
- GLB 제작·리깅·실시간 3D 이동과 렌더링. 생성 PNG를 GLB라고 표시하지 않는다.
- 영속 실행 및 새로고침 후 복구. 이번 기록은 현재 탭 메모리에만 유지한다.
