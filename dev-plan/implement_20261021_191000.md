- 마지막에 7번의 공간/예약/경로/회의 설계와 검수 게이트만 별도 계획으로 작성.

## 추가 전환 재현과 수정

보정 전 단기/실제 10·30분 검수 후 추가 25ms 표본에서 책상 팔꿈치 방향 전환의 200.4mm 튐을 발견했다. 팔꿈치 방향을 3.5rad/s로 제한하고, 소품/표면을 제어하지 않는 자유 손만 인물 로컬 좌표에서 완충한다. 소품/지지 손의 원래 목표는 보존한다. 약 36분의 미완료 수명주기와 당시 자료를 `before-elbow-continuity/`에 보관하고 최종 동작 소스를 재고정해 실제 시간 검수를 다시 수행한다. 데이터 운영 검수는 독립된 HTTP/임시 DB이므로 계속 실행한다.
