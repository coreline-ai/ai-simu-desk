# 최종 사무실 선행 렌더 · 2026-10-22

사용자의 최신 요청에 따라 실사 질감을 줄이고 기존 v8의 부드러운 입체감에 모던한 가구·공간 구성을 더한 디자인 선택용 시안이다. built-in `imagegen`으로 생성했다. 아직 실제 3D 모델·이동 경로·성능을 구현하거나 검증한 결과는 아니다.

| 안 | 이미지 | 방향 |
|---|---|---|
| A | [웜 모던 스튜디오](modern-a-warm-studio.png) | 크림·오크·세이지, 기존 스튜디오와 자연스럽게 이어지는 방향 |
| B | [쿨 모던 오피스](modern-b-cool-office.png) | 화이트·그레이·블루, 창가 작업 자리와 명확한 회의·휴게 구획 |
| C | [미니멀 라운지](modern-c-minimal-lounge.png) | 월넛·샌드·테라코타, 낮은 수납과 넉넉한 라운지 중심 |

각 현대형 시안에서 작업 책상/모니터 5개를 시각 확인했다. 회의 공간은 5명이 사용할 5~6석의 콘셉트이며, 실제 배치·의자 후퇴 공간·통로 폭·손 지지·충돌 검사는 모델 제작 단계에서 수행한다. 생성 프롬프트의 약 13.2×10.2m는 초기 목표이며 이미지 자체가 치수 도면은 아니다.

## 사용자 지정 조합 · 최신 수정 이미지

[웜 모던 · 전면 방향 수정](modern-warm-front-facing-v2.png): 화면에서 먼저 표시된 블루·그레이 B안의 배치에, 두 번째 표시된 크림·오크·세이지 A안의 색상을 적용했다. 작업 자리 5개는 의자가 창가 쪽에 있고 사람이 앉으면 화면 아래쪽을 바라보는 방향으로 돌렸다. 카메라에는 모니터 뒷면이 보인다. 실제 3D 구현 전 검토용이며 [수정 프롬프트](modern-warm-front-facing-v2.prompt.json)를 함께 저장했다.

이전 실사 방향은 `previous-realistic-*.png`에 비교 이력으로 보관한다. `prompts.json`에 각 생성 프롬프트를, `manifest.json`에 이미지 크기·지문을 저장했다. 최초 A안의 작업 자리 부족은 재생성으로 보정했고, 폐기한 초기 이미지는 이번 비교 대상으로 사용하지 않는다.

현재 상태: 사용자가 수정 이미지를 첨부하여 구현 기준으로 확정했다. 첨부 원본을 [approved-reference.png](approved-reference.png)에 보존했다. 공간 v7/활동 v9의 실제 구현·시각 배속은 [개발 계획](../../../dev-plan/implement_20261022_082727.md)과 [검수](../../../docs/final-office-qa.md)에서 관리한다. 위의 ‘구현 전’ 설명은 생성 시안 자체의 범위를 뜻하며 실제 GLB 검수와 구분한다.
